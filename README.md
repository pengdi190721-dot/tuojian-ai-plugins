# 拓见AI学员插件市场｜安装说明

当前包含两个可独立安装的双平台插件：

- **自媒体作战室**：从定位、选题、写稿、制作到成片评分和复盘；
- **真实故事短剧化**：把真实经历、客户案例和人物口述改成有冲突、有看点、守住事实边界的AI短剧脚本。

## 插件一：自媒体作战室

“自媒体作战室”帮助已经有产品或服务、但不知道拍什么和服务哪类客户的学员，从首次获客定位开始，逐步完成选题、调研、对标拆解、写稿、视频制作、成片评分、发布包装和数据复盘。

## 安装后会获得什么

- 首次定位诊断：用5道生活化问题了解产品、真实客户、客户原话、可拍素材和拍摄条件，每次只问一个问题。
- 选题、调研、人设、脚本、视频制作、成片评分、对标改写、封面设计等11个内置技能。
- 视频号主版本和小红书适配版本。
- 第一轮十条内容测试和获客复盘方法。
- 成片评分教练：上传拍完的视频，按100分评分并指出“下一遍只改三件事”。
- 对标视频拆解改写：学习优秀视频的结构、节奏和镜头逻辑，再换成学员自己的真实内容。
- 九式封面设计：内置九张风格参考图，可按平台比例、真人照片、标题和附图生成成品；支持严格还原本人、一秒缩略图检查和中文错字复核。

插件内置技能和底层视频解析配置会随插件一起安装。学员不需要申请付费接口密钥，也不需要理解转写、抽帧等技术。第一次分析视频时会联网下载本地识别组件，等待时间取决于电脑和网络；以后会复用本机缓存。

TrendRadar、Agent Reach、HyperFrames、huashu-design、Nuwa和品牌语气工具属于可选增强，不影响首次定位、基础选题、写稿和成片评分流程。

## Codex学员安装

适用于安装了ChatGPT桌面端或Codex命令行工具的学员。

打开终端，依次运行：

```bash
codex plugin marketplace add pengdi190721-dot/tuojian-ai-plugins
codex plugin add self-media-war-room@tuojian-ai
```

安装完成后重启ChatGPT桌面端，新建一个任务，输入：

```text
第一次使用自媒体作战室，请逐题帮我找到最适合获客的自媒体定位，每次只问一个问题。
```

检查是否安装成功：

```bash
codex plugin list
```

列表中应出现 `self-media-war-room@tuojian-ai`。

## 两个最常用的口令

拍完自己的视频后，直接上传原始视频并输入：

```text
请用成片评分教练给这条视频打分，告诉我做得好的地方、最影响播放的三个问题，以及下一遍只改哪三件事。
```

看到值得学习的对标视频后，上传视频文件或发送可公开访问的单条视频链接，再输入：

```text
请拆解这条对标视频。保留它值得学习的结构、节奏和镜头逻辑，再用我的定位、真实经历和说话方式改成原创版本。
```

优先上传原始视频或清晰导出文件。聊天软件压缩过的视频可能影响清晰度、音量和字幕评分。平台链接如果需要登录，直接改为上传本人有权使用的本地视频，不要提供账号密码。

需要做封面时，上传一张清晰主图并输入：

```text
请用九式封面设计，按我的标题和发布平台生成一张可直接发布的封面。没有指定的选项由你决定。
```

系统会从技能清单、粉色杂志、搜索引导、黄色杂志、蓝绿撕纸、复古手写、深色渐变、黑金宣言和电影感拼图九种模板中选择。参考图只用于视觉语言，不复制原人物、原文或品牌。

## 首次使用规则

第一次使用时不要直接索要爆款选题。系统不会要求学员先说清专业定位或90天商业结果，而是依次询问：现在卖什么、谁曾经来买、客户为什么来、手里什么内容最多、哪种拍摄方式能坚持。五题结束后，系统负责归纳客户方向、账号类型、内容栏目和第一轮测试选题。

定位档案会保存在学员自己的项目目录中，不会随插件上传到本仓库。客户姓名、手机号、账号密码等敏感信息不要写入定位档案。

## 常见问题

1. 安装后没有触发首次定位：请新建任务或新建对话，再复制上面的首次使用口令。
2. 环境体检显示可选工具缺失：基础流程仍然可用，不需要一次装齐全部增强工具。
3. 插件安装失败：先确认能够正常访问GitHub，再检查插件市场名称是否为 `tuojian-ai`。
4. 想继续上次项目：在同一项目目录中输入“继续上次的自媒体项目”。
5. 第一次分析视频比较慢：通常是在下载本地识别组件；等待完成即可，不需要购买接口额度。
6. 平台视频链接无法解析：改为上传本人有权使用的本地视频文件。

## 插件二：真实故事短剧化

“真实故事短剧化”会先理解用户提供的故事、采访录音或逐字稿，回传故事大意和主题候选；主题确认后再单独生成事实底稿，等待用户删改确认；事实确认后才用人物行动和自然对话进行短剧化，旁白只在必要处出现。最终交付：

- 故事理解确认单；
- 事实底稿确认单；
- 三个戏剧化方向和推荐方向；
- 完整可拍短剧脚本；
- 角色一致性卡、逐镜分镜和GPT Image 2图片提示词；
- 图片验收项和Seedance图生视频提示词；视频提示词按连续秒数分段，逐段写清景别、机位、运镜、可见情绪和结束状态；
- 改编台账与事实、隐私、因果审查。

它不会为了“有戏”凭空制造坏人、出轨、犯罪、疾病、债务或幕后秘密。默认匿名真实人物和机构。图片未确认前，视频提示词只标记为草案。

