# 封面视觉锤

封面不是把信息全部摆上去，而是让观众在一秒内抓住一个重点。制作或评审封面前，先用一句话写清楚：**观众第一眼必须看见什么？**这句话就是本张封面的视觉锤。

## 先确定唯一重点

- 每张封面只允许一个主视觉锤。可以是冲突型标题、人物表情或关键结果画面，但只能有一个承担第一注意力。
- 标题、人物、信息卡不能同时争抢第一层级。其余元素只能解释或强化视觉锤。
- 视觉锤应占据最大面积、最高明暗反差或唯一强调色；不要平均分配视觉重量。
- 人物作为主体时，优先选择眼神明确、嘴型自然、表情与内容一致的真实原帧，不为追求效果更换人物身份或虚构现场。

## 控制信息层级

默认按三个层级组织：

1. 主视觉锤：主标题或关键画面，缩小后仍最醒目。
2. 人物与真实现场：证明内容来自真实经历。
3. 系列标签和辅助信息：只补充语境，不抢主标题。

- 默认只保留一个主标题、一个系列标签和不超过两个辅助信息点；用户明确指定更多信息时再增加。
- 主标题只强调一个关键词，避免每个词都变色、放大或加装饰。
- 辅助信息应成组放在同一区域，不在四周零散堆放气泡、箭头、贴纸和小卡片。
- 色彩、字体、描边和装饰都必须服务于同一个重点；不能只为了“热闹”增加元素。

## 一秒缩略图检查

交付前把封面缩小到手机缩略图大小，快速看一秒并检查：

1. 能否立刻说出这张封面最重要的一个信息？
2. 第一眼看到的是否正是选定的视觉锤？
3. 是否有第二个元素与视觉锤同样抢眼？
4. 删除一个辅助元素后是否反而更清楚？

如果第一眼出现两个以上重点，或需要读完所有小字才能理解，就先合并、弱化或删除辅助元素，再进入最终成图。
