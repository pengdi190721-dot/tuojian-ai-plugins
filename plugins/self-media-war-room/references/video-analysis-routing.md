# 底层视频解析路由

本文件只供技能内部路由使用。面向学员时统一说“正在解析视频”，不要要求学员选择转写模型、抽帧密度、识别语言或命令参数。

## 输入优先级

1. 本人原始视频或清晰导出文件，使用绝对路径。
2. 可直接访问的单条公开视频链接。
3. 转写、截图或压缩视频只能做降级分析，必须说明缺失项。

聊天软件压缩可能改变清晰度、音量和字幕可读性。评分时注明收到的是原片还是压缩版。

## 内部执行顺序

1. 优先调用插件提供的 `video-analyzer` 工具：完整审片使用 `analyze_video` 的详细模式；只缺某个时间点证据时使用 `analyze_moment` 或 `get_frame_at`。
2. 如果工具返回的转写为空，但本地视频有声音，内部运行 `../../scripts/analyze_video.py` 补做轻量本地转写并合并结果。
3. 工具没有出现但本机有 Python、Node.js和npx时，也运行同一脚本完成完整本地解析。
4. 仍不可用时，使用当前环境已有的媒体读取、FFmpeg、转写或画面检查能力。
5. 最后才降级为基于用户提供的转写和截图分析。不能把降级分析称为完整审片。

默认使用轻量本地语音识别，不请求学员提供任何付费接口密钥。第一次转写会按需下载本地模型，以后复用缓存。不得为了方便而把视频自动发送到未说明的第三方视频理解服务。

## 完整度记录

每次解析都记录：

- 是否取得完整或分段转写。
- 是否取得关键画面和时间码。
- 是否取得时长、尺寸、编码和音轨信息。
- 是否存在下载失败、无字幕、静音、画面缺失或识别不确定。

公开平台链接受登录、地区、反爬和版权限制。需要账号或Cookie时，先请学员改为上传本人有权使用的本地文件；未经明确授权不得读取浏览器凭据。

## 证据边界

- 画面抽样只能证明抽到的时刻，不能断言整条视频都如此。
- 自动转写中的专有名词、数字和人名必须回听或标注不确定。
- 只描述可观察的语速、停顿、镜头朝向、表情和姿态，不做心理诊断。
- 对标视频只提取结构和表现规律，不输出大段原文，不帮助冒充原作者。
