# 工具路由

| 任务 | 首选 | 备选 | 说明 |
|---|---|---|---|
| 热点汇总 | TrendRadar | Agent Reach、网页搜索 | TrendRadar是外部服务，不随本插件复制 |
| 深度调研 | Agent Reach | 当前可用网页工具 | 先体检渠道，不能把未激活平台说成可用 |
| 人设提炼 | 本插件人设与表达 | Nuwa | Nuwa作为方法参考或外部能力，不重复安装两个同名版本 |
| 语言约束 | 本插件人设与表达 | brand-voice-enforcement | 先有真实规范再执行检查 |
| 视频解析 | 插件内置视频解析服务 | 本地解析脚本、当前媒体工具 | 自动取得转写、关键画面和时间线，不要求学员选择技术参数 |
| 对标拆解 | `benchmark-video-remix` | 转写和截图降级分析 | 先判断值不值得学，再迁移结构与节奏 |
| 内容粗剪 | 人工剪辑清单 | 当前视频工具 | 先判断故事和节奏，再执行机械处理 |
| 字幕动效 | HyperFrames | 当前视频工具 | 只负责包装，不替代故事剪辑 |
| 封面配图 | huashu-design | 当前图像工具 | 适合可视化素材，不负责选题和剪辑 |

本插件不复制第三方源码。视频解析服务由插件按锁定版本调用，默认使用本地语音识别且不需要付费接口密钥；其他外部工具缺失时按备选路径继续，并在结果中明确降级。
