# 工作流

| 阶段 | 输入 | 产物 | 通过条件 |
|---|---|---|---|
| 首次定位 | 现有产品、成交经历、资源与经营目标 | 创作者定位档案、十条测试计划 | 信息完整度约95%，优先客户和验证方向明确 |
| 体检 | 当前环境 | 能力清单 | 已知哪些工具可用 |
| 选题 | 想法、热点、真实素材 | 选题卡 | 70分以上且有独特角度 |
| 调研 | 选题卡 | 研究简报 | 关键事实有直接来源 |
| 人设 | 真实表达素材 | 人设档案 | 有边界、例句和置信度 |
| 脚本 | 简报、人设、案例 | 成稿和镜头单 | 可自然说、无虚构 |
| 制作 | 原始素材、脚本 | 粗剪或剪辑清单 | 故事清楚且可复核 |
| 发布 | 成片 | 双平台包装 | 标题、简介、标签适配 |
| 复盘 | 平台数据 | 周期复盘 | 形成下一轮可验证假设 |

首次使用没有创作者定位档案时必须先完成定位诊断；已有且仍适用时直接复用。完整任务默认继续推进，只有以下情况暂停询问：逐题定位诊断尚未完成、缺少必要素材、需要决定公开边界、需要登录或授权、需要产生费用、两种方向会明显改变结果。
