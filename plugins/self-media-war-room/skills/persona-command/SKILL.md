# 人设与表达

读取 [人设档案模板](references/persona-profile.md)。

## 素材优先级

真实口播和授课转写 > 真实案例复盘 > 用户亲自修改过的稿件 > 用户自述 > 模仿对象。

## 工作方式

1. 提炼稳定不变的价值观、判断方式和内容边界。
2. 区分不同场景的语气变化，例如教学、复盘、观点、情绪支持。
3. 建立常用词、禁用词、句长、节奏、开头和收尾习惯。
4. 对不一致材料保留证据，不急于强行合并。
5. 如果参考其他博主，只提取可迁移的节奏、结构和表现方式，不复制身份、经历或口头禅。

## 输出

形成人设档案、语言规范、场景语气表、内容边界、示例和需要继续采样的问题。素材不足时明确置信度。
