# 九式封面设计

目标是交付可直接发布的封面成品，不只给提示词。封面必须建立在用户真实素材上，不虚构人物、客户证明、数据、平台界面或品牌标识。

## 开始前

1. 读取用户已经提供的标题、文案、图片、发布平台和风格偏好，不重复询问。
2. 读取 [九种封面风格](references/styles.md)。用户没有选风格时，用九张参考图和名称让用户选一个编号；参考图只用于选择视觉语言。
3. 用户只有文案、没有标题时，先给三个不同角度的主标题候选，每条四至十四个汉字，让用户选一个或自行修改。
4. 用户要真人出镜时，至少需要一张清晰主图；用户明确要无人物的纯图形封面时可以不提供人物图。附图最多三张，只能使用用户提供的产品图、案例图、课程截图或标志。

## 一次确认清楚

缺少会明显改变成图的信息时，只发一张“封面确认单”，把所有缺项合并成一个问题，不拆成多轮追问：

- 风格：九种模板之一，或交给系统决定。
- 比例：九比十六、三比四、四比三、十六比九、一比一，或交给系统决定。
- 人物表现：捂嘴惊讶、张嘴震惊、开心大笑、兴奋雀跃、自信得意、托腮思考、推荐种草、认真讲解、指向标题、沉思判断、自然微笑，或用户自定义。
- 字体：超粗黑体、柔和圆体、手写涂鸦体、极简无衬线、复古宋体，或交给系统决定。
- 背景：浅色、深色、暖色、冷色、高饱和撞色，或交给系统决定。
- 副标题：根据主标题给三个四至十字候选，用户可选一个、多个、全选、都不要或自行改写。

用户明确说“直接生成”“你来定”或“都交给系统决定”时，视为允许系统补全所有未选项，不再追问。按发布场景选择比例；场景不明时优先三比四。

## 生成规则

1. 一次只使用一种模板，不混搭九种风格。
2. 主标题必须原样、完整、清晰地写进画面；只加入用户选中的副标题。
3. 视觉层级默认是：主标题第一、主图第二、副标题第三、附图第四。封面只允许一个第一注意力。
4. 从文案中提取一至四个具体名词、工具、场景或隐喻，转成物件、插画、卡片或装饰界面。没有文案依据的元素不添加。
5. 中文必须可辨认，不出现乱码、伪文字、拼音替代或无意义外文。
6. 不生成二维码、关注按钮、虚假点赞评论、价格、统计数据、客户评价或未经用户提供的标志。
7. 文字、人物和关键元素避开平台裁切区与字幕安全区，不贴边，不让人物挡住主标题。

## 真人还原

- 真人出镜默认严格还原身份：脸型、五官比例、眼睛、鼻子、嘴型、发际线、肤色、年龄感、眼镜和标志性配饰优先保持。
- 只改变用户指定的表情、视线和动作，不擅自美颜、换脸、年轻化、改变发型或生成“相似但不是本人”的新脸。
- 优先使用图像编辑方式保留原图人物，只生成背景、文字和配图元素。
- 第一次不像本人时，降低人物重绘程度后直接重试；连续两次仍不像，再请用户补充一至三张正面或侧面清晰参考图。

## 生成与重试

调用当前可用的图像生成或编辑工具，按下面顺序组织生成要求：

1. 输出比例、像素和发布平台。
2. 所选模板的版式、字体、配色和装饰。
3. 主图位置、主体保持、人物身份与动作。
4. 主标题原文和分行方式。
5. 副标题原文与位置。
6. 附图编号、用途与位置。
7. 语义配图元素、数量和位置。
8. 安全区、可读性和禁止项。

文字错误、比例错误或人物失真时，保留已经确认的选择直接重试，不让用户从头再选。

## 交付前验收

- 一秒缩略图：缩小到手机信息流尺寸后，第一眼仍能说出唯一重点。
- 标题：原文完整、没有错字、没有被人物或装饰遮挡。
- 人物：能明确认出是用户本人，表情和动作符合最终选择。
- 素材：没有凭空生成截图、标志、数据、客户评价或第二个人物。
- 比例：与发布平台一致，四周保留安全区。

有一项不通过就先修正，再交付最终图。
