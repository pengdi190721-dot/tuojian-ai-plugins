# 对标视频拆解改写流程

## 一、适配判断

先判断四件事：

- 观众是否与本人要成交的客户相近。
- 视频承担的是获客、建立信任、展示案例还是纯娱乐。
- 它的优势主要来自结构与表达，还是来自名人身份、稀缺场景和高成本制作。
- 本人是否有真实素材承接同一结构。

公开播放、点赞、评论、收藏等数据只作为线索，不把单一数字当成内容质量。没有数据就写“无法核实”，不要补造。

## 二、时间码拆解

每一段至少记录：

| 时间码 | 原视频在做什么 | 观众此时得到什么 | 口播与情绪变化 | 画面与剪辑动作 | 可迁移程度 |
|---|---|---|---|---|---|
| 00:00—00:03 |  |  |  |  | 高、中、低 |

重点检查：

1. 第一信息出现在哪一秒。
2. 开头是结果、冲突、反常识、身份、场景还是直接提问。
3. 每隔多久增加一个新信息、证据或画面变化。
4. 哪些停顿、表情和镜头变化承担强调作用。
5. 结尾要求观众做什么，是否与前文价值一致。

## 三、迁移规则

可以学习：

- 信息顺序、段落功能、冲突推进和证明方式。
- 快慢变化、停顿位置、镜头类型和字幕层级。
- 先给结果再解释、先展示现场再复盘等叙事方法。

不能照搬：

- 原作者的身份、经历、客户案例、数据和观点归属。
- 连续长句、独特比喻、口头禅、标志性动作和高度识别的镜头组合。
- 无法由本人真实产品、经验和证据支撑的承诺。

## 四、改写规则

先写“这条结构为什么适合我”，再完成三次替换：

1. 把原作者的观众换成本人的目标客户。
2. 把原作者的证据换成本人的真实经历、案例或演示。
3. 把原作者的表现方式调到本人的语速、句长、价值观和拍摄条件。

改写完成后，反向比较原视频与新稿。如果删掉人名和行业后仍像逐句翻写，继续重构角度、顺序或案例。
