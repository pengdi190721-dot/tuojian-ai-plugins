# 对标视频拆解改写

读取 [拆解改写流程](references/benchmark-workflow.md)、[对标卡模板](references/benchmark-card.md) 和 [底层视频解析路由](../../references/video-analysis-routing.md)。

## 开始前

1. 优先读取当前项目的 `.self-media-creator-profile.json` 和已有的人设表达档案。
2. 没有定位档案时，先调用 `creator-positioning`；没有足够本人表达素材时，可以先做结构版改写，但必须标记“人设贴合度待校准”，不能假装已经像本人。
3. 解析对标视频的转写、关键画面、时间线和公开元数据。解析过程属于底层能力，不要求学员选择技术方案。

## 工作顺序

1. **先判断值不值得学**：目标观众是否相近、内容类型是否相同、信息是否真实、优势来自结构还是仅来自作者知名度。缺少公开数据时不要用想象补齐播放表现。
2. **按时间码拆解**：拆出开头钩子、观众承诺、内容推进、证据、情绪变化、口播节奏、镜头变化、字幕提示和收尾动作。
3. **划清迁移边界**：结构、节奏、镜头逻辑和信息顺序可以迁移；身份、经历、案例事实、原句、口头禅、标志性镜头和独特人设不能复制。
4. **映射到本人素材**：用学员自己的产品、客户问题、真实经历、观点和可拍场景替换原视频内容。
5. **生成原创版本**：先给一句原创角度，再给完整口播稿或Vlog旁白、镜头清单和双平台差异。
6. **做差异检查**：逐项确认没有照搬长句、事实、标题承诺、镜头顺序和标志性表达。

## 固定输出

1. 值不值得学：结论、适配度、判断依据和数据缺口。
2. 时间码拆解表：原视频每一段在完成什么任务。
3. 可迁移与不可迁移清单。
4. “对标结构 → 我的真实素材”映射表。
5. 我的原创稿：开头、正文、收尾，标出预计时长。
6. 拍摄与剪辑清单。
7. 原创差异自检和仍需本人确认的事实。

如果用户同时提供自己的成片和对标视频，先完成对标拆解，再调用 `review-command` 比较“学到了什么、哪些地方失去本人特点”，不能只比较像不像。
