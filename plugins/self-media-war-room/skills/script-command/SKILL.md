# 口播与Vlog脚本

按需读取 [脚本模板](references/script-templates.md) 和 [双平台适配](references/platform-adaptation.md)。

## 输入检查

优先使用已有的选题卡、研究简报、人设档案和真实素材。缺少时可以继续，但必须标明假设，不能补造经历、客户评价或效果数据。

## 工作方式

1. 先给3个不同强度的开头，说明各自适用场景。
2. 主体优先采用“现实冲突—真实场景—个人判断—原因—可执行动作—边界”。
3. 口播稿写成人能自然说出口的短句，不写论文腔和万能套话。
4. Vlog保留现场转折、人物反应和真实不确定性，不把演示写成已经完整落地。
5. 为视频号保留信任和故事完整度；为小红书重做标题、开头和信息密度。

## 输出

至少交付：开头备选、主稿、镜头或素材提示、字幕重点、剪辑备注、视频号包装和小红书适配。用户要求简短时先交可直接拍的版本。
