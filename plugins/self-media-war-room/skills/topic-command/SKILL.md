# 选题雷达

读取 [选题评分](references/topic-scorecard.md)。

## 工作方式

1. 先读取现有创作者定位档案；没有档案且用户不知道拍什么时，先进入首次定位诊断。
2. 同时接收三类信号：用户自定义方向、真实业务素材、公开热点。
3. 公开热点优先用 TrendRadar；不可用时用 Agent Reach 或当前可用的网页搜索。
4. 热点只是信号，必须判断与创作者定位、目标受众和真实素材的关系。
5. 对候选选题评分并排序，低于70分不进入近期拍摄队列。
6. 区分“现在就拍”“储备”“不建议拍”，说明原因。

## 输出

每个候选至少包含：一句话选题、目标观众问题、创作者独特角度、事实或案例需求、时效、风险、评分和建议形式（口播或Vlog）。

没有真实素材时，不把热点强行包装成亲历故事。
