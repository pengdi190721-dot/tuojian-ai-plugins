# 创作者定位档案

把档案保存为当前项目或工作区根目录下的 `.self-media-creator-profile.json`。它属于跨内容项目复用的长期档案，不与单条视频的 `.self-media-job.json` 混用。

```json
{
  "schema_version": 1,
  "status": "ready",
  "confidence": 95,
  "positioning_status": "待验证",
  "business": {
    "offer": "",
    "customer_result": "",
    "price_or_cycle": ""
  },
  "customer_candidates": [],
  "primary_customer": {
    "description": "",
    "urgent_problem": "",
    "buying_trigger": "",
    "trust_evidence": []
  },
  "secondary_customer": {},
  "strategy": {
    "choice": "短期易成交或长期高价值",
    "reason": ""
  },
  "content": {
    "one_sentence_positioning": "",
    "pillars": [],
    "formats": [],
    "primary_platform": "",
    "cadence": ""
  },
  "evidence": {
    "cases": [],
    "repeatable_materials": [],
    "public_boundaries": []
  },
  "first_experiment": {
    "content_count": 10,
    "topics": [],
    "success_signals": []
  },
  "assumptions": [],
  "open_questions": [],
  "updated_at": ""
}
```

不要保存客户姓名、手机号、账号凭据或其他无必要的个人敏感信息。业务、客户或经营目标发生明显变化，或者完成十条内容测试后，把档案标记为需要复查并重新校准。
