# 内容调研

读取 [来源与证据规则](references/source-protocol.md)。

## 工作方式

1. 先明确需要证实的关键问题，而不是无边界搜索。
2. 实际使用当前可用的互联网渠道；需要多平台时先检查 Agent Reach 渠道状态。
3. 优先原始文件、官方数据、论文、项目仓库和当事人原文。
4. 把内容分为：已验证事实、平台样本观察、合理推断、尚未核实。
5. 记录直接支持结论的链接，避免只有搜索结果没有原始页面。
6. 发现与原观点冲突的证据时必须保留，不能为了写稿删掉。

## 输出

交付一份可供写稿使用的研究简报：核心结论、来源、反方或限制、创作角度、可说与不可说、仍需补充的真实素材。
