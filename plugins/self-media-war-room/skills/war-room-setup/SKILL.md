# 作战室体检

运行插件根目录的环境检查：

```bash
python3 ../../scripts/doctor.py --format markdown
```

## 处理规则

- 先报告“已就绪、可选但缺失、需要用户登录”三类结果。
- 缺少系统依赖时说明它会影响哪个环节，不把可选能力说成整个插件不可用。
- 只有用户明确要求安装时才执行安装命令。
- 平台登录、Cookie、账号授权必须由用户本人完成或明确提供；不得自行读取浏览器凭据。
- 安装或配置后重新运行体检，确认状态确实改变。
- 学员版优先给无代码操作；技术细节放在故障排查里。
