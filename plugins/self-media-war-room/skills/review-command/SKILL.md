# 发布与复盘

读取 [发布与复盘评分](references/review-scorecard.md)。

## 发布前

- 先客观评价优点、缺点和事实风险。
- 检查开头、信息价值、人设一致、真实边界、声音画面和平台适配。
- 用户没有明确要求实际发布时，只生成可复制的标题、简介、标签和封面字，不执行发布。

## 发布后

- 记录发布时间、平台、选题来源、开头类型、时长、制作耗时和平台可见数据。
- 看每周中位播放量和内容类型趋势，不用单条爆款代表整体增长。
- 区分内容问题、包装问题、分发波动和样本不足。
- 每轮最多提出三个可验证假设，并为下一批内容设计对照实验。

不得伪造平台数据，也不得在样本很少时下确定性结论。
