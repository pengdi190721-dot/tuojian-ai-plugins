# 成片评分教练

读取 [成片评分表](references/review-scorecard.md) 和 [底层视频解析路由](../../references/video-analysis-routing.md)。用户需要封面字、封面方案或封面评审时，改用内置的 `cover-design` 技能及其 [九种封面风格](../cover-design/references/styles.md)。

## 收到成片后

1. 优先解析原始视频或清晰导出文件，取得转写、关键画面、时长和时间线；不要让学员选择模型、转写方式或抽帧参数。
2. 先核对资料完整度。只有可评分维度达到80分权重时才给正式总分；不足时给“局部评分”，明确缺少声音、画面或转写中的哪一项。
3. 每个扣分必须对应时间码、可观察现象和修改动作。不能只写“节奏不好”“镜头感不强”等主观结论。
4. 语速、停顿、口头语、镜头朝向、表情变化、构图和剪辑节奏可以评价；不得根据表情推断人格、心理状态、疾病或所谓“自信程度”。
5. 先给客观评价：做得好的地方、主要问题、事实与隐私风险；再给总分和分项分。

## 固定输出

按以下顺序输出：

1. 一句话结论：正式总分或局部评分、等级、资料完整度。
2. 三个做得好的地方，每条带时间码证据。
3. 七项评分表：得分、证据、为什么扣分、怎么改。
4. 三个最影响播放的问题，按影响从高到低排序。
5. “下一遍只改三件事”：给学员一次就能执行的动作。
6. 重拍或重剪清单：区分必须改、建议改、可以保留。
7. 用户要发布时，再生成视频号主版本和小红书适配版的标题、简介、标签和封面方案；封面只用一种模板，主标题保持唯一第一注意力。

不要为了凑满七项而编造观察。无法从当前素材确认的项目标记为“未评”。

## 发布前边界

- 事实错误、隐私风险、虚构案例和严重听不清属于发布阻断项，即使总分达到80分也不能直接进入发布候选。
- 用户没有明确要求实际发布时，只生成可复制的发布包装，不执行发布。
- 同一条视频有上一版时，优先做前后版本对比，说明具体哪一项变好或变差。

## 发布后

- 记录发布时间、平台、选题来源、开头类型、时长、制作耗时和平台可见数据。
- 看每周中位播放量和内容类型趋势，不用单条爆款代表整体增长。
- 区分内容问题、包装问题、分发波动和样本不足。
- 每轮最多提出三个可验证假设，并为下一批内容设计对照实验。

不得伪造平台数据，也不得在样本很少时下确定性结论。
