# 创始人 IP 操盘手｜安装

当前版本：**2.4.1**。

给自媒体新手用的短视频操盘手，说的都是大白话，每做完一步都告诉你下一步干什么。第一次用先问几个能语音回答的问题，直接出IP定位；定位没问题，马上找同类对标、给几个选题让你挑，挑了就写好两份文案（拍摄版和直接复制进提词器的纯文字版）；之后每周能出选题（先看同行最近在拍什么，每条附创意拍法让你选）、写口播稿和现场提问卡、拆对标视频（抖音链接直接读，不用注册、不下载视频，说清哪里能借鉴、哪里不能借鉴）、发布前给成片打分和做口播体检、教投流、看后台截图复盘，你采纳的建议以后写稿自动用上。视频号、抖音、小红书分开讲。回答时始终以经验丰富的短视频操盘手身份判断，有问题直接指出，不一味顺着说。

2.4.1 读抖音链接时声音没下全会自己重取，取不全会照实说只读到第几秒；你自己要加的规矩存进资料文件夹，升级不会丢。

2.4.0 发抖音链接，它自己直接读，不用注册，只取说的话，不下载视频；拆对标默认给文案、能借鉴、不能借鉴三样；去掉了得到大脑，读不出来就在抖音里保存视频发过来。

2.3.0 每做完一步都告诉你下一步；做完定位马上找对标、出选题；每条文案出两份，其中纯文字版直接复制进提词器；发链接照样走得到大脑，实在不想注册的，可以在抖音里保存视频发过来；第一次读视频连不上外网时自动换国内下载地址。

2.2.0 新增说白话铁律和行话翻译表、常见问题、两个行业的模拟示例、口播体检、连接得到大脑；删掉了剪辑包装、做封面图、AI画面、正式报告、客户提案和三档服务方案，技能更轻。

## 最简单的安装方式

把本页链接和下面这段话一起发给你的 AI 工具：

> 请从这个仓库安装“创始人 IP 操盘手”2.4.1。插件位于 plugins/founder-ip-operator，独立技能位于 plugins/founder-ip-operator/skills/founder-ip-operator。按你当前环境支持的方式安装，保留所有配套文件。已有旧版时先备份，避免留下两个同时启用的同名版本；旧版技能文件里如果有我自己加过的规矩（版本说明里没有的铁律、自查之类），先挪进我资料文件夹的“写稿规则.md”，再换新版。安装后检查版本及附件完整性，告诉我如何调用；不支持持久安装时如实说明。

## 装好以后怎么用

第一次用：

> 帮我做IP定位。

它会先查已有资料，再问几个问题，按住说话用语音回答就行，答完直接给定位。

之后常用的几句：

> 这周拍什么？按我的定位出几个选题。

> 这个视频帮我拆一下，看值不值得学，再改成我自己的。

> 这是拍好的视频，帮我打个分，告诉我下一遍只改哪三件事。

> 这是后台截图和这条视频，帮我看看为什么数据不好，下一条怎么改。

> 我想给这条视频投流，但我没投过，一步一步教我。

发抖音链接，它自己直接读，不用注册，不下载视频，电脑上要有 Python 3。读不出来，或者是小红书、B站、视频号的视频，在App里点“分享”、再点“保存本地”，把视频发过去。读视频文件、听写说的话要电脑装 Node.js 22.12 以上；第一次会联网下载一个听写组件，不要付费密钥。用不了时说“帮我检查一下哪些功能能用”。

## 使用范围

- 一人一档，客户截图、视频和采纳过的规则存在你自己的电脑里，不放进插件或公开仓库。
- 你要加的规矩，跟它说“以后都这样，记进我的写稿规则”，存在你的资料文件夹里。别让AI直接改技能文件：升级会把整个技能文件夹换掉，改在里面的会丢。
- 每条稿子都配现场提问卡；截图不清、缺视频或证据不够时，会说清缺什么，不编数据和经历。
- 不做剪辑、封面图、AI画面和正式报告；这些用你自己的工具或交给同事。
- **定期联网更新平台规则，要在你自己的 AI 工具里另外建定时任务**，装这个插件不会自动带上。可以这样说：“每周一上午9点检查视频号与抖音官方资料和有依据的运营经验，把变化保存到当前项目。”工具确认建好了才算启用。
- 包里的示例都是编的，不代表真实效果；平台资料快照也不代替每次的当次核查。
