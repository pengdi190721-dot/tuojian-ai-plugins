# 创始人 IP 操盘手｜安装

当前版本：**2.2.1**。

给自媒体新手用的短视频操盘手，说的都是大白话。第一次用先问几个能语音回答的问题，直接出IP定位；之后能出选题（先看同行最近在拍什么，每条附创意拍法让你选）、写口播稿和现场提问卡、拆对标视频（发链接走得到大脑读文字稿）、发布前给成片打分和做口播体检、教投流、看后台截图复盘，你采纳的建议以后写稿自动用上。视频号、抖音、小红书分开讲。回答时始终以经验丰富的短视频操盘手身份判断，有问题直接指出，不一味顺着说。

2.2.1 发视频链接改成只走得到大脑，第一次用直接给注册登录链接，不再自己去抖音下载。

2.2.0 新增说白话铁律和行话翻译表、常见问题、两个行业的模拟示例、口播体检、连接得到大脑；删掉了剪辑包装、做封面图、AI画面、正式报告、客户提案和三档服务方案，技能更轻。

## Codex 插件安装

第一次添加这个工具市场，在终端运行：

```bash
codex plugin marketplace add pengdi190721-dot/tuojian-ai-plugins
codex plugin add founder-ip-operator@tuojian-ai
```

已经添加过的，先刷新再安装：

```bash
codex plugin marketplace upgrade tuojian-ai
codex plugin add founder-ip-operator@tuojian-ai
```

检查：

```bash
codex plugin list --marketplace tuojian-ai --json
```

应看到 founder-ip-operator，版本2.2.1，已安装并启用。安装后新建对话，必要时重启应用。连不上 GitHub 时，先解决网络或改用下载的完整技能包，不能把安装失败当成功。

WorkBuddy 也可以用插件市场方式，在它的对话框里运行（不是电脑终端）：


## 装好以后怎么用

第一次用：

> 帮我做IP定位。

它会先查已有资料，再问几个问题，按住说话用语音回答就行，答完直接给定位。

之后常用的几句：

> 这周拍什么？按我的定位出几个选题。

> 这个视频帮我拆一下，看值不值得学，再改成我自己的。

> 这是拍好的视频，帮我打个分，告诉我下一遍只改哪三件事。

> 这是后台截图和这条视频，帮我看看为什么数据不好，下一条怎么改。

> 我想给这条视频投流，但我没投过，一步一步教我。

发视频链接让它读，要注册得到大脑并开会员（ https://www.biji.com ），第一次发链接时它会带你连上；视频号链接读不了，要发视频文件。读视频文件要电脑装 Node.js 22.12 以上；第一次读视频会联网下载一个听写组件，不要付费密钥。用不了时说“帮我检查一下哪些功能能用”。

## 使用范围

- 一人一档，客户截图、视频和采纳过的规则存在你自己的电脑里，不放进插件或公开仓库。
- 每条稿子都配现场提问卡；截图不清、缺视频或证据不够时，会说清缺什么，不编数据和经历。
- 不做剪辑、封面图、AI画面和正式报告；这些用你自己的工具或交给同事。
- **定期联网更新平台规则，要在你自己的 AI 工具里另外建定时任务**，装这个插件不会自动带上。可以这样说：“每周一上午9点检查视频号与抖音官方资料和有依据的运营经验，把变化保存到当前项目。”工具确认建好了才算启用。
- 包里的示例都是编的，不代表真实效果；平台资料快照也不代替每次的当次核查。
