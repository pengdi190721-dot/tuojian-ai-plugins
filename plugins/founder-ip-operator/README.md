# 创始人 IP 操盘手｜学员安装

当前版本：**2.0.0**。

2.0.0 已并入原“自媒体作战室”：选题评分、选题调研、对标视频拆解改写、剪辑包装与重点大字、九式封面、发布前成片评分、本地视频解析和环境体检都在这一个技能里；另新增付费投流：先问这一轮要纯曝光、获客还是卖货，再按目标测、放、接、复。装过作战室的学员，装好本技能后停用作战室即可。回答时始终以经验丰富的短视频操盘手身份判断，有问题直接指出，不一味顺着说。

第一次使用先自检已有资料，问几个能用语音回答的问题，直接出IP定位报告。帮助创始人完成访谈建档、本人表达提炼、定位与内容计划、口播稿及现场提问卡，开头、结构与封面按期待、维持、兑现检查；上传后台截图和视频后，核对数据、定位问题、修改文案并安排下次验证。用户采纳建议后，保存到该创始人的档案，后续写稿主动沿用。

## 最简单的安装方式

把本页链接和下面这段话一起发给你的智能体：

> 请从这个仓库安装“创始人 IP 操盘手”2.0.0。插件位于 plugins/founder-ip-operator，独立技能位于 plugins/founder-ip-operator/skills/founder-ip-operator。按你当前环境支持的方式安装，保留所有配套文件。已有旧版时先备份，避免留下两个同时启用的同名版本。安装后检查版本及附件完整性，告诉我如何调用；不支持持久安装时如实说明。

## Codex 插件安装

首次添加学员工具市场，在终端运行：

```bash
codex plugin marketplace add pengdi190721-dot/tuojian-ai-plugins
codex plugin add founder-ip-operator@tuojian-ai
```

已经添加过这个市场的学员，先刷新再安装：

```bash
codex plugin marketplace upgrade tuojian-ai
codex plugin add founder-ip-operator@tuojian-ai
```

检查：

```bash
codex plugin list --marketplace tuojian-ai --json
```

应看到 founder-ip-operator，版本2.0.0，已安装并启用。安装后新建对话，必要时重启应用。当前无法访问GitHub时，先解决网络访问或使用下载的完整技能包，不能把安装失败当成功。

## 安装后怎么用

第一次用，先做IP定位：

> 使用创始人IP操盘手，帮我做IP定位。

它会先查已有资料，再问几个问题，按住说话用语音回答就行，答完直接出定位报告。

已有访谈逐字稿时建档：

> 使用创始人 IP 操盘手。客户是【姓名或代号】，业务是【业务】。这是访谈逐字稿，请单独建档，保留真实故事和本人说话方式，完成当前资料支持的策划。每条口播稿都配现场提问或提示卡。

视频复盘：

> 这是【客户】的视频后台截图和对应视频。请核对数据，结合实际视频定位问题，给我完整改稿、配套现场提问卡及下一条验证建议。建议逐条编号；我采纳后再写入这位客户的长期写稿规则。

选题、对标、封面和成片评分：

> 按我的定位档案给我选题，按评分分成现在拍、储备、不建议拍。

> 这是我的对标视频，请拆解结构和节奏，再用我的真实素材改成原创稿。

> 请用九式封面，按我的主图、封面字和发布平台出一张能直接发的封面。

> 这是我拍好的视频，请用成片评分教练打分，告诉我下一遍只改哪三件事。

视频解析需要电脑上有 Node.js 22.12 以上；第一次分析视频会联网下载本地识别组件，不需要付费接口密钥。分析不了时先说“帮我做一下环境体检”。

采纳建议：

> 采纳第【编号】条，今后用于【客户／平台／栏目】；第【编号】条仅下次试用。请保存并在之后写稿时读取。

## 使用范围

- 一人一档，客户截图、视频和已采纳规则保存在学员自己的工作区，不放进插件或公开仓库。
- 核心方法可独立使用。视频解析随包附带本地脚本；联网、图片视频生成等由当前工具提供；没有相应工具时明确已完成范围，不假称看过视频。
- 每条稿件都有现场提问卡；截图不清、缺少视频或证据不足时，明确缺口，不编数据和经历。
- **定期联网更新需要在学员自己的工具中另外创建任务**，安装本插件不会自动获得彭迪账号下的周一更新任务。可发指令：“每周一上午9点检查视频号与抖音官方资料和有依据的运营经验，把变化保存到当前项目，每次复盘再核查相关来源。”只有工具确认创建成功才算启用。
- 包内历史示例不代表真实客户成效；10月13日资料快照也不代替以后任务的当次核查。
