# 创始人 IP 操盘手 · 2.0.0 技能模块清单

本包是一个独立技能，内含以下23个工作模块（第14到21个由原“自媒体作战室”并入，第22、23个为2.0.0新增）。无需分别安装，也无需安装其他插件。

| 序号 | 模块 | 主要交付 |
|---|---|---|
| 1 | 首次面谈 | 必问问题、真实故事追问、记录字段及补件清单 |
| 2 | 逐字稿整理与独立建档 | 每位老板的人物档案、原话索引、事实状态与待补访项 |
| 3 | 人物定位 | 业务目标、目标客户、可验证优势、账号与内容方向 |
| 4 | 本人口语提炼 | 常用词、叙述顺序、表达习惯、试读与改稿依据 |
| 5 | 真实故事挖掘 | 从原则观点追问具体事件、动作、选择和证据，形成可拍故事 |
| 6 | 三平台规则与流量分发机制 | 核查视频号、抖音、小红书的公开机制、规则、日期及适用范围；区分证据与推断 |
| 7 | 三平台内容适配 | 平台选择依据、同题三版、标题封面、拍法、发布要求与观察指标 |
| 8 | 阶段内容规划 | 季度计划、半年计划、首月选题和约定数量的完整文案，每条配套提问卡并沿用客户已采纳规则 |
| 9 | 纯实拍与真人＋AI影像 | 拍摄提问、素材、分镜、人物场景统一、生成提示词与剪辑验收 |
| 10 | 客户操盘报告 | 核心建议、行动安排与配套资料分层；重点导出、完整文案及三平台机制保留 |
| 11 | 三档服务方案 | 策划、成片交付、全案代运营的交付、客户配合与责任范围 |
| 12 | 运营与复盘 | 后台截图核对、视频定位、改稿及提问卡、下次验证、采纳规则沿用及定期资料更新 |

| 13 | 经营诊断与30天验证 | 经营目标、客户决策链、产品交付、内容任务、合作路径、数据成本及岗位；优先卡点、行动与回看条件 |
| 14 | 选题雷达与评分 | 自定义方向、真实素材、公开热点三类信号；100分评分；现在拍／储备／不建议拍 |
| 15 | 选题调研与事实核验 | 研究简报；已验证／样本观察／推断／待核实标记；反方证据和可说不可说 |
| 16 | 对标视频拆解改写 | 值不值得学、时间码拆解、能借不能借、素材映射、原创稿、差异自检、对标卡 |
| 17 | 口播与Vlog结构 | 口播与Vlog骨架、开头备选、字幕重点、视频号与小红书改写、单条内容流程 |
| 18 | 剪辑与包装 | 先剪内容再包装、自动与人工边界、重点大字与音效、透明底与绿幕素材、人工复核清单 |
| 19 | 九式封面 | 九种风格参考图、封面确认单、真人还原、生成要求、一秒缩略图验收 |
| 20 | 成片评分教练 | 七项评分带时间码、发布阻断项、下一遍只改三件事、重拍重剪清单、发布包装 |
| 21 | 视频解析与环境体检 | 本地语音识别取得转写、关键画面和时间线；环境体检脚本；降级与完整度记录 |
| 22 | 付费投流 | 默认老板是新手：先讲清投流和三种目标，再问（每题附在哪看、答不上来怎么办）；视频号、抖音、小红书手把手怎么投；测、放、接、复；按目标算账；合规自查；盯盘与周复盘表；投流规则核查快照 |
| 23 | 平台调性 | 视频号熟人和名片、抖音陌生人和兴趣、小红书搜索和种草；来的是谁、内容怎么被看到、起号、选题开头封面、承接、先看的数据、投流时机；贯穿定位、选题、写稿、封面、评分、复盘和投流 |

## 2.0.0 本次强化

并入原“自媒体作战室”0.4.0的有效方法，学员只需安装一个技能：[选题雷达与评分](references/topic-radar.md)、[选题调研](references/topic-research.md)、[单条内容流程](references/content-production-flow.md)、[对标视频拆解改写](references/benchmark-remix.md)、[口播与Vlog结构](references/script-structures.md)、[剪辑与包装](references/editing-and-packaging.md)、[九式封面](references/cover-design.md)、[成片评分教练](references/pre-publish-review.md)、[视频解析](references/video-analysis.md)和[环境体检](references/environment-check.md)。作战室的人设方法并入[逐字稿与表达规范](references/transcript-and-voice.md)（素材优先级、场景语气、置信度），首次定位的候选人群比较和十条测试配比并入[第一次使用](references/first-use-positioning.md)。作战室“每轮只问一个问题”的五题诊断没有并入，第一次使用继续按1.7.0的一次发完、语音回答。另在技能入口最前面新增铁律：每次回答都以经验丰富的短视频操盘手身份判断，不一味顺着用户。新增[平台调性](references/platform-tonality.md)，贯穿定位、选题、写稿、封面、评分、复盘和投流；新增[付费投流](references/paid-traffic.md)：默认老板是新手，先讲清再问这一轮要纯曝光、获客还是卖货，按平台手把手教怎么投，再按目标定止损、测放接复和算账；附[投流规则核查快照](references/paid-traffic-platform-check-2026-10-25.md)和[投流工作表](assets/paid-traffic-workbook.md)。

## 1.7.0 已有强化

第一次使用改为[先自检，再问，后出定位](references/first-use-positioning.md)：先查已有资料，只问缺的；没资料时问7个能用语音回答的问题，有资料只问缺的，最多追问一轮；替客户做时可直接转发给老板；在对话里直接给IP定位报告，不先交准备包或采集表。

## 1.6.0 已有强化

文案与复盘新增[开头、结构与封面配合](references/opening-and-structure.md)：第一句交代主题、尽早兑现、封面问题在开头回答、关注理由前置，以及期待、维持、兑现的逐段对照。参考视频拆解增加观点适配表和"不能借"清单；交给剪映的图文素材增加透明底与绿幕要求。新增[客户正式提案](references/client-proposal-deck.md)，用于首访后向老板正式汇报。均为默认检查项，不替代客户已采纳规则。

## 1.5.0 已有强化

将截图与视频复盘细化为可执行流程；区分官方依据、运营经验与本账号数据。用户采纳的建议保存到客户目录，后续文案主动读取；保留1.4.1每条文案配套现场提问卡。定期研究通过真实调度执行，不把安装技能当作已建立定时任务。

## 1.4.0 已有强化

经营诊断贯通访谈、档案、定位、内容、报告与复盘；人物信任与真实表达继续保留。成熟业务以证据检查卡点，新业务允许内容与产品共同验证，数据异常须核验原因。

## 1.3.0 历史示例

默认示例改为江苏社区养老项目，首页说明具体业务，页内提示使用“注意事项”。12个选题与3篇文案重新编写；报告继续先看重点、再查细节。新增[分层示例](examples/江苏养老模拟报告-重点分层版.html)及[报告层次规范](references/report-hierarchy.md)。

## 1.1.0 已有强化

1. 完整首访报告必须向客户解释三个平台怎样分发内容，不能只给选题建议。
2. 平台策略增加“核查—匹配—改版—客户说明—发布复核—数据复盘”的执行步骤。
3. 客户报告须列出主辅平台选择依据、同题改版实例、可观察指标和规则来源。
4. 内置书面说明模板、2026年9月24日资料核查及可演示样稿。
5. 平台快照必须保留日期；未生效、未读取和未公开的内容如实标明。
