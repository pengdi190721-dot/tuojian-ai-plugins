# 创始人 IP 操盘手 · 2.4.1 技能模块清单

一个技能，27个模块，不用另外装别的技能或插件。第一次用只看[新手操作卡](新手操作卡.md)就够了。

| 序号 | 模块 | 能帮你干什么 |
|---|---|---|
| 1 | 第一次用出定位 | 先查已有资料，只问缺的（能语音回答），在对话里直接给IP定位；确认后马上找对标、出选题，挑一个就写好两份文案 |
| 2 | 首次面谈 | 给别的老板做时，面谈要问什么、怎么追问、记什么、会后补什么 |
| 3 | 逐字稿整理与建档 | 从面谈录音里整理老板的说话习惯和能拍的真实故事 |
| 4 | 经营诊断与30天行动 | 弄清生意卡在哪、这个月先做什么、谁负责、看什么数 |
| 5 | 定位与内容规划 | 栏目、首月选题、三个月和半年的大致计划 |
| 6 | 平台调性 | 视频号熟人和名片、抖音陌生人和兴趣、小红书搜索和种草，从选平台管到投流 |
| 7 | 三平台规则与同题三版 | 核查当前规则，主辅平台怎么选，同一个题改成三个平台的版本 |
| 8 | 选题雷达 | 先看行情（对标最近发了什么，没对标就联网搜同类博主），再打分分成现在拍、先存着、不建议拍 |
| 9 | 创意发散 | 常规拍法加三个创意拍法，直接给老板选，记下老板的口味 |
| 10 | 选题调研与事实核验 | 写稿前查资料，分清核实过的、推断的、不能说的 |
| 11 | 对标视频拆解 | 值不值得学、一段一段拆开、能借和不能借、改成自己的原创稿，攒成对标卡 |
| 12 | 口播与Vlog结构 | 口播和视频日记的骨架、开头备选、平台改写 |
| 13 | 开头、结构与封面字 | 开头留人、前后兑现、关注理由放哪、封面字和开头怎么配 |
| 14 | 两份文案和现场提问卡 | 每条稿子交拍摄版和纯文字版（直接复制进提词器）；拍摄版一段一段配主问题、回答要点和备用追问，改稿一起改 |
| 15 | 纯实拍拍摄与运营 | 现场怎么问、要准备什么、镜头顺序，发布前核对，运营记录 |
| 16 | 单条内容流程 | 一个想法从选题推到发布，每一步交什么、怎么算过关 |
| 17 | 成片打分与发布包装 | 七项打分带时间点、下一遍只改三件事、标题简介话题和封面字 |
| 18 | 口播体检 | 按声音大小、停顿和语速找出第几秒没劲、哪里卡壳，不判断情绪 |
| 19 | 视频解析与环境体检 | 读出视频里说了什么、拍了什么；检查电脑缺什么、下一步怎么装 |
| 20 | 发链接读视频 | 抖音链接AI自己直接读，不用注册，不下载视频：读出标题文案、作者、互动数和说的话（有字幕读字幕，没有就只取声音听写，听完就删），画面只看封面和预览图；拆对标默认交文案、能借鉴、不能借鉴；读不出来或别的平台的视频，请用户在App里保存发过来；视频号链接请用户发视频文件 |
| 21 | 付费投流 | 先教再问目标，按平台一步一步教怎么投，算账、止损、盯数据 |
| 22 | 视频数据复盘 | 核对后台截图，结合视频找问题，改稿和提问卡，下一条怎么验证 |
| 23 | 建议沿用 | 老板采纳的建议存起来，以后写稿自动用上，也能撤回 |
| 24 | 平台资料更新 | 带日期的官方依据，定期核查 |
| 25 | 说白话 | 对用户说的话一律大白话，附行话翻译表 |
| 26 | 每步提醒下一步 | 每做完一步，告诉用户下一步做什么、直接怎么说 |
| 27 | 常见问题与新手操作卡 | 装不上、读不了、怎么用的白话答案，二十多句现成说法 |

## 2.4.1 本次改动

- **修了**：读抖音链接时，网络中途断了只取到半截声音，文字稿只有前面一段。现在会核对下全没有，没下全就重下或换地址，实在取不全就照实提示只读到第几秒。
- **改了**：用户自己要加的规矩一律存进他的资料文件夹（写稿规则），不改技能文件，升级不会丢；安装指令和常见问题第28条写了升级前怎么挪。

## 2.4.0 改动

- **新增**：[读视频链接](references/video-links.md)和 `scripts/read_douyin_link.py`：发抖音链接或整段分享口令，AI自己直接读，不用登录、不用注册，不下载视频。先领一个抖音发的匿名访问凭证，再打开作品的公开分享页，读出标题文案、作者、时长、互动数和封面、预览图地址；说的话有字幕读字幕，没有就只取声音在本机听写，听完就删。空页面时换凭证再试一次，网络断了自动再试两次。
- **改了**：拆对标时用户只说“拆一下”，默认只交三样：提取的文案、哪里能借鉴、哪里不能借鉴，要改稿再做全套。环境体检加了“能不能连上抖音”。
- **删掉了**：得到大脑（连接、授权、存链接读文字稿、定位后提醒注册）。读不出来或者是别的平台的视频，请用户在App里保存下来发过来。

## 2.3.0 改动

- **新增**：铁律三，每做完一步主动告诉用户下一步，附一张“做完什么、下一步、怎么说”对照表；[文案交付：拍摄版和纯文字版](references/script-delivery.md)，纯文字版只留要念的话，夹在两行标记中间，直接复制进提词器。
- **改了**：第一次做完定位，用户回“没问题”，同一条回复里马上联网找2到3个同类对标、给行情速览和3到5个选题，回数字挑一个就写稿；定位报告里不再放首批选题。读视频第一次下载识别组件连不上外网时，自动换国内下载地址；认画面上的字的组件下载失败时，退一步只读说的话。两个模拟示例改成带“下一步”和纯文字版。
- **多了一条退路**：发链接照样走得到大脑；实在不想注册的，在抖音里点“分享”、再点“保存本地”，把视频发过来。

## 2.2.1 改动

- **改了**：发视频链接一律走得到大脑读文字稿；免费账号就行，不用会员；第一次发链接、还没连上时，直接给注册登录链接，弄好再带他授权，命令行连不上就请他在App里存好把文字稿复制过来；第一次出完定位顺带提一句。环境体检改查得到大脑装没装、授权没有。
- **删掉了**：自己去抖音分享页下载视频的小程序、视频号下载器、让用户改代理分流的说法，实际用下来基本走不通。

## 2.2.0 改动

- **新增**：铁律二“说白话”和[行话翻译表](references/plain-words.md)；[常见问题](常见问题.md)和“别这样用”；[装修公司](examples/模拟示例-装修公司老板.md)和[宠物店](examples/模拟示例-宠物店老板.md)两个模拟示例；技能入口加“新手只看这三步”“直接这样说就行”“能做什么、要配合什么、不做什么”；[口播体检](references/voice-delivery-check.md)和连接得到大脑（2.4.0已删）（原来在 SkillHub 的 2.1.1、2.1.2 里，这次并进来并改成白话）。
- **改了**：学员操作卡改名[新手操作卡](新手操作卡.md)，指令改成白话短句；读抖音链接网络断了自动再试两次（2.2.1已改成只走得到大脑）；读视频、环境体检出错时，提示改成白话的“下一步怎么做”；带日期的平台资料快照挪进 references/snapshots。
- **删掉了**：剪辑与包装（含重点大字）、九种风格封面（含九张样图）、真人加AI画面、正式报告、客户正式提案、三档服务方案，以及配套的模拟报告、三平台说明演示页和生成报告网页的脚本。标题、简介和封面字还在发布包装里。

## 以前版本

- **2.1.0**：出选题前先看行情；创意拍法直接给老板选；发抖音链接读视频。
- **2.0.0**：并入原“自媒体作战室”，只装这一个技能就够；新增平台调性和付费投流；新增铁律一（以操盘手身份判断，不一味顺着用户）。
- **1.7.0**：第一次使用改成先查资料、再语音问答、直接出定位，不交准备包和采集表。
- **1.6.0**：新增开头、结构与封面配合。
- **1.5.0**：截图与视频复盘，老板采纳的建议存进资料文件夹以后沿用。
- **1.4.0**：经营诊断贯穿访谈、定位、内容和复盘。
- **1.1.0**：三平台规则核查和平台选择依据。

所有模块都守同样的规矩：一人一档、依据逐字稿、用本人口语、只讲真实故事。
