# 创始人 IP 操盘手 · 1.6.0 技能模块清单

本包是一个独立技能，内含以下13个工作模块。无需分别安装13个技能，也无需安装其他插件。

| 序号 | 模块 | 主要交付 |
|---|---|---|
| 1 | 首次面谈 | 必问问题、真实故事追问、记录字段及补件清单 |
| 2 | 逐字稿整理与独立建档 | 每位老板的人物档案、原话索引、事实状态与待补访项 |
| 3 | 人物定位 | 业务目标、目标客户、可验证优势、账号与内容方向 |
| 4 | 本人口语提炼 | 常用词、叙述顺序、表达习惯、试读与改稿依据 |
| 5 | 真实故事挖掘 | 从原则观点追问具体事件、动作、选择和证据，形成可拍故事 |
| 6 | 三平台规则与流量分发机制 | 核查视频号、抖音、小红书的公开机制、规则、日期及适用范围；区分证据与推断 |
| 7 | 三平台内容适配 | 平台选择依据、同题三版、标题封面、拍法、发布要求与观察指标 |
| 8 | 阶段内容规划 | 季度计划、半年计划、首月选题和约定数量的完整文案，每条配套提问卡并沿用客户已采纳规则 |
| 9 | 纯实拍与真人＋AI影像 | 拍摄提问、素材、分镜、人物场景统一、生成提示词与剪辑验收 |
| 10 | 客户操盘报告 | 核心建议、行动安排与配套资料分层；重点导出、完整文案及三平台机制保留 |
| 11 | 三档服务方案 | 策划、成片交付、全案代运营的交付、客户配合与责任范围 |
| 12 | 运营与复盘 | 后台截图核对、视频定位、改稿及提问卡、下次验证、采纳规则沿用及定期资料更新 |

| 13 | 经营诊断与30天验证 | 经营目标、客户决策链、产品交付、内容任务、合作路径、数据成本及岗位；优先卡点、行动与回看条件 |

## 1.6.0 本次强化

文案与复盘新增[开头、结构与封面配合](references/opening-and-structure.md)：第一句交代主题、尽早兑现、封面问题在开头回答、关注理由前置，以及期待、维持、兑现的逐段对照。参考视频拆解增加观点适配表和"不能借"清单；交给剪映的图文素材增加透明底与绿幕要求。新增[客户正式提案](references/client-proposal-deck.md)，用于首访后向老板正式汇报。均为默认检查项，不替代客户已采纳规则。

## 1.5.0 已有强化

将截图与视频复盘细化为可执行流程；区分官方依据、运营经验与本账号数据。用户采纳的建议保存到客户目录，后续文案主动读取；保留1.4.1每条文案配套现场提问卡。定期研究通过真实调度执行，不把安装技能当作已建立定时任务。

## 1.4.0 已有强化

经营诊断贯通访谈、档案、定位、内容、报告与复盘；人物信任与真实表达继续保留。成熟业务以证据检查卡点，新业务允许内容与产品共同验证，数据异常须核验原因。

## 1.3.0 历史示例

默认示例改为江苏社区养老项目，首页说明具体业务，页内提示使用“注意事项”。12个选题与3篇文案重新编写；报告继续先看重点、再查细节。新增[分层示例](examples/江苏养老模拟报告-重点分层版.html)及[报告层次规范](references/report-hierarchy.md)。

## 1.1.0 已有强化

1. 完整首访报告必须向客户解释三个平台怎样分发内容，不能只给选题建议。
2. 平台策略增加“核查—匹配—改版—客户说明—发布复核—数据复盘”的执行步骤。
3. 客户报告须列出主辅平台选择依据、同题改版实例、可观察指标和规则来源。
4. 内置书面说明模板、2026年9月24日资料核查及可演示样稿。
5. 平台快照必须保留日期；未生效、未读取和未公开的内容如实标明。
