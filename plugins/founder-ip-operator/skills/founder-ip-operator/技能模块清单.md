# 创始人 IP 操盘手 · 2.2.1 技能模块清单

一个技能，27个模块，不用另外装别的技能或插件。第一次用只看[新手操作卡](新手操作卡.md)就够了。

| 序号 | 模块 | 能帮你干什么 |
|---|---|---|
| 1 | 第一次用出定位 | 先查已有资料，只问缺的（能语音回答），在对话里直接给IP定位 |
| 2 | 首次面谈 | 给别的老板做时，面谈要问什么、怎么追问、记什么、会后补什么 |
| 3 | 逐字稿整理与建档 | 从面谈录音里整理老板的说话习惯和能拍的真实故事 |
| 4 | 经营诊断与30天行动 | 弄清生意卡在哪、这个月先做什么、谁负责、看什么数 |
| 5 | 定位与内容规划 | 栏目、首月选题、三个月和半年的大致计划 |
| 6 | 平台调性 | 视频号熟人和名片、抖音陌生人和兴趣、小红书搜索和种草，从选平台管到投流 |
| 7 | 三平台规则与同题三版 | 核查当前规则，主辅平台怎么选，同一个题改成三个平台的版本 |
| 8 | 选题雷达 | 先看行情（对标最近发了什么，没对标就联网搜同类博主），再打分分成现在拍、先存着、不建议拍 |
| 9 | 创意发散 | 常规拍法加三个创意拍法，直接给老板选，记下老板的口味 |
| 10 | 选题调研与事实核验 | 写稿前查资料，分清核实过的、推断的、不能说的 |
| 11 | 对标视频拆解 | 值不值得学、一段一段拆开、能借和不能借、改成自己的原创稿，攒成对标卡 |
| 12 | 口播与Vlog结构 | 口播和视频日记的骨架、开头备选、平台改写 |
| 13 | 开头、结构与封面字 | 开头留人、前后兑现、关注理由放哪、封面字和开头怎么配 |
| 14 | 现场提问卡 | 每条稿子一段一段配主问题、回答要点和备用追问，改稿一起改 |
| 15 | 纯实拍拍摄与运营 | 现场怎么问、要准备什么、镜头顺序，发布前核对，运营记录 |
| 16 | 单条内容流程 | 一个想法从选题推到发布，每一步交什么、怎么算过关 |
| 17 | 成片打分与发布包装 | 七项打分带时间点、下一遍只改三件事、标题简介话题和封面字 |
| 18 | 口播体检 | 按声音大小、停顿和语速找出第几秒没劲、哪里卡壳，不判断情绪 |
| 19 | 视频解析与环境体检 | 读出视频里说了什么、拍了什么；检查电脑缺什么、下一步怎么装 |
| 20 | 发链接读视频 | 链接一律存进得到大脑读文字稿；第一次用直接给注册登录链接；视频号链接请用户发视频文件 |
| 21 | 连接得到大脑 | 要会员；带老板本人授权，顺带能把资料存到云端 |
| 22 | 付费投流 | 先教再问目标，按平台一步一步教怎么投，算账、止损、盯数据 |
| 23 | 视频数据复盘 | 核对后台截图，结合视频找问题，改稿和提问卡，下一条怎么验证 |
| 24 | 建议沿用 | 老板采纳的建议存起来，以后写稿自动用上，也能撤回 |
| 25 | 平台资料更新 | 带日期的官方依据，定期核查 |
| 26 | 说白话 | 对用户说的话一律大白话，附行话翻译表 |
| 27 | 常见问题与新手操作卡 | 装不上、读不了、怎么用的白话答案，二十多句现成说法 |

## 2.2.1 本次改动

- **改了**：发视频链接一律走得到大脑读文字稿；第一次发链接、还没连上时，直接给注册登录链接和开会员的链接，弄好再带他授权；第一次出完定位顺带提一句。环境体检改查得到大脑装没装、授权没有。
- **删掉了**：自己去抖音分享页下载视频的小程序、视频号下载器、让用户改代理分流的说法，实际用下来基本走不通。

## 2.2.0 改动

- **新增**：铁律二“说白话”和[行话翻译表](references/plain-words.md)；[常见问题](常见问题.md)和“别这样用”；[装修公司](examples/模拟示例-装修公司老板.md)和[宠物店](examples/模拟示例-宠物店老板.md)两个模拟示例；技能入口加“新手只看这三步”“直接这样说就行”“能做什么、要配合什么、不做什么”；[口播体检](references/voice-delivery-check.md)和[连接得到大脑](references/knowledge-base-getnote.md)（原来在 SkillHub 的 2.1.1、2.1.2 里，这次并进来并改成白话）。
- **改了**：学员操作卡改名[新手操作卡](新手操作卡.md)，指令改成白话短句；读抖音链接网络断了自动再试两次（2.2.1已改成只走得到大脑）；读视频、环境体检出错时，提示改成白话的“下一步怎么做”；带日期的平台资料快照挪进 references/snapshots。
- **删掉了**：剪辑与包装（含重点大字）、九种风格封面（含九张样图）、真人加AI画面、正式报告、客户正式提案、三档服务方案，以及配套的模拟报告、三平台说明演示页和生成报告网页的脚本。标题、简介和封面字还在发布包装里。

## 以前版本

- **2.1.0**：出选题前先看行情；创意拍法直接给老板选；发抖音链接读视频。
- **2.0.0**：并入原“自媒体作战室”，只装这一个技能就够；新增平台调性和付费投流；新增铁律一（以操盘手身份判断，不一味顺着用户）。
- **1.7.0**：第一次使用改成先查资料、再语音问答、直接出定位，不交准备包和采集表。
- **1.6.0**：新增开头、结构与封面配合。
- **1.5.0**：截图与视频复盘，老板采纳的建议存进资料文件夹以后沿用。
- **1.4.0**：经营诊断贯穿访谈、定位、内容和复盘。
- **1.1.0**：三平台规则核查和平台选择依据。

所有模块都守同样的规矩：一人一档、依据逐字稿、用本人口语、只讲真实故事。
