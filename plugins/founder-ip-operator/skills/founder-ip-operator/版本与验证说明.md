# 版本与验证说明

版本：1.7.0 完整独立版。更新日期：2026年10月16日。

1.7.0：第一次使用改为[先自检，再问，后出定位](references/first-use-positioning.md)。起因是学员实际使用时，第一步生成了准备包、信息采集表和两份网页报告，流程复杂、内容不能直接用。现在先查工作区、上传文件和可读取的对话记录里已有的信息，只问缺的；什么都没有时问7个能用语音回答的问题，有部分资料只问缺的，最多追问一轮，然后在对话里直接给IP定位报告。替客户做时，分成写给操盘手的说明和可直接转发给老板的一段。7个问题按定位必需要素设计，发布前用三种模拟情况试跑（什么都没有、只有公司介绍、已有完整档案），据此补了服务范围和客户来源、拆分了过长的问题、补了替客户做的说法；真实效果以学员使用反馈为准再调。线下正式首访仍用24组面谈清单。

## 1.6.0（2026年10月16日）

新增[开头、结构与封面配合](references/opening-and-structure.md)：开头检查、期待维持兑现对照、关注理由前置、封面与开头配合、开头备选；写稿、脚本交付卡、自检和复盘"开头留人"均已接入。另补参考视频拆解的交付方式和交给剪映的图文素材要求。新增[客户正式提案](references/client-proposal-deck.md)：首访后向老板正式汇报的演示文稿，六章结构（经营方向、业务架构、分期运营、合作与经营、创始人IP、推进与协作）、三种页型、页底注意事项、用语边界与视觉规范；依据一份真实客户正式版提案提炼结构和样式，未收录该客户的任何内容。依据是一个自有账号三条视频的复盘和一条对标视频拆解，样本有限，作为默认检查项和可验证假设，客户已采纳规则与本人改稿优先。本版未新增自动登录、自动发布或媒体生成服务。

## 1.5.0（2026年10月13日）

新增后台截图核对、视频内容定位、原因假设、完整改稿及提问卡、下一条验证与采纳清单。每次复盘核查相关当前资料；定期研究区分官方依据、署名经验及候选假设。用户明确采纳后，将规则保存到对应客户工作区，后续新稿先读取再应用；采纳状态与效果状态分开。

保留逐条现场提问卡、经营诊断、人物口语、真实故事、三平台、纯实拍与真人加AI影像、分档服务及报告方法。本版未新增自动登录后台、自动发布、付费投放或媒体制作服务。

10月13日实际联网核查覆盖部分视频号、抖音官方资料及署名经验；详见当日来源记录。小红书快照仍为9月24日历史状态。历史网页、PDF模拟案例仅作版式参考，不是含本次复盘全部能力的完整范例。

定期调度依当前用户环境真实创建；本包不包含任何用户任务编号、私有路径、客户资料或账号。结构、安装及分发验证不能证明真实账号流量提升；本次实际验证说明随交付提供。
