# 版本与验证说明

版本：2.0.0 完整独立版。更新日期：2026年10月25日。

## 2.0.0（2026年10月25日）

并入原“自媒体作战室”0.4.0，以后只维护本技能。并入内容：选题雷达与评分、选题调研与来源标记、对标视频拆解改写与对标卡、口播与Vlog结构及视频号与小红书改写要点、剪辑与包装、九式封面（九张风格参考图压缩为较小文件，画面未改）、成片评分教练、视频解析脚本与服务配置、环境体检脚本、第三方声明与许可证。作战室的人设档案方法并入逐字稿与表达规范；首次定位的候选人群比较和第一轮十条配比并入第一次使用。另把一个自有账号做“重点大字加音效”和交剪映素材时的做法写进剪辑与包装（人脸与字幕避让、绿幕层不留半透明像素、成片和分层素材一起交付），属于制作方法，不涉及任何老板的说话方式。

没有并入的：作战室“每轮只问一个问题”的五题定位诊断（与1.7.0一次发完、语音回答的决定冲突，保留1.7.0）；`.self-media-creator-profile.json` 和 `.self-media-job.json` 两个状态文件及其脚本（改为在客户目录记录定位档案和“内容进度.md”，与一人一档一致）；作战室的总调度说明（流程已写进本技能的单条内容流程）。

为能上传SkillHub（只收文字类文件）：许可证改名LICENSE.txt；视频解析的两个脚本从.mjs改成.js，scripts里加package.json声明按模块运行；去掉Windows用的.bat启动文件，改成用到时自动写到缓存目录。图片和PDF会被SkillHub跳过，封面样图缺失时改给GitHub链接。

同时新增平台调性（references/platform-tonality.md）：视频号是熟人和名片（好友推荐和算法推荐并行，依据微信珊瑚安全2025年4月说明和网信办2025-05-22说明），抖音是陌生人和兴趣（依据抖音安全与信任中心推荐系统说明），小红书是搜索和种草（依据2026年WILL商业大会报道，每月约2亿用户寻求购买建议）；“视频号起号期可小额加热做门面数据”“抖音先靠选题跑自然流”“小红书发满几篇再挑好的投”标为操盘经验。调性已写进定位、选题、写稿、开头、封面、成片评分、复盘、三平台流程和投流。

同时新增付费投流方法（references/paid-traffic.md）。默认老板是新手：先用大白话讲清投流和三种目标，再问，每个问题附在哪看、答不上来怎么办，并按视频号、抖音、小红书手把手教怎么投。投流目标不预设，由老板选纯曝光、获客还是卖货，再按目标对应视频号加热、腾讯广告、企业微信获客、DOU+、巨量本地推、千川的用法和该看的指标；只放大跑过自然流量的视频，一次只改一个变量，先定止损再花钱，样本不够只下“暂定”结论；按目标算账，投前过合规；建计划、充值、改预算默认由用户本人操作。平台规则在2026年10月25日核查一次，写成快照（references/paid-traffic-platform-check-2026-10-25.md），每条标明官方原文、转述官方、第三方或待核；视频号加热官方帮助页需要登录，本次没读到原文，以转述官方为主。“一次只改一个变量”“先定预算上限和可承受损失”“扣退款后算保本线”“复盘只说数据看得到的事实”“投放文案先查效果承诺和极限词”这几条思路，参考了 GitHub 上公开的千川实操技能（jiaichoi/Dou-agent）、小红书内容工作流（wwaa34682-lab/xhs-workflow-kit）和投放方法论插件（lhg-plugs/lhg-ads），文字均为重写，没有复制原文。

同时新增一条铁律，放在技能入口最前面：每一次回答都以经验丰富的短视频操盘手身份判断，用户的想法有问题时直接指出并给依据和更好的做法，不一味顺着用户；用户说得对就说对，坚持己见时按用户决定执行、风险只说一次。

验证范围：逐个核对新增资料的链接能打开、版本号一致、技能目录内不含真实客户资料；视频解析脚本和体检脚本做了语法检查并在一台测试环境运行体检。没有在学员电脑上实测视频解析全流程，也没有实测九式封面在各工具里的出图效果；以学员实际使用反馈为准再调。

## 1.7.0（2026年10月16日）

1.7.0：第一次使用改为[先自检，再问，后出定位](references/first-use-positioning.md)。起因是学员实际使用时，第一步生成了准备包、信息采集表和两份网页报告，流程复杂、内容不能直接用。现在先查工作区、上传文件和可读取的对话记录里已有的信息，只问缺的；什么都没有时问7个能用语音回答的问题，有部分资料只问缺的，最多追问一轮，然后在对话里直接给IP定位报告。替客户做时，分成写给操盘手的说明和可直接转发给老板的一段。7个问题按定位必需要素设计，发布前用三种模拟情况试跑（什么都没有、只有公司介绍、已有完整档案），据此补了服务范围和客户来源、拆分了过长的问题、补了替客户做的说法；真实效果以学员使用反馈为准再调。线下正式首访仍用24组面谈清单。
