改了：
- 链接一律存进得到大脑读文字稿，按[读视频链接：得到大脑](references/knowledge-base-getnote.md)执行，免费账号就行，不推会员。用户第一次发链接、还没连上时，直接给注册登录链接（https://www.biji.com ），弄好后带他本人授权。第一次出完IP定位，后面顺带加一句注册登录链接。

- 得到大脑只有文字没有画面：要看镜头、字幕、表情或给成片打分，请用户发视频文件，本地照常读。
- 视频号链接读不了，请用户录屏或下载后发文件。
- `scripts/doctor.py`：去掉抖音链接、视频号下载器和 yt-dlp 的检查，改查得到大脑命令行装没装、`getnote auth status` 有没有授权，按三种情况用白话说下一步。

删掉了：`scripts/fetch_video.py`（抖音分享页直接下载、视频号下载器对接、yt-dlp 下载），以及常见问题、新手操作卡、行话翻译表里关于代理分流和视频号下载器的说法；第三方声明和依赖清单去掉 douyin-mcp-server、wx_channels_download。

## 2.1.2（2026年10月29日）

新增口播交付体检（references/voice-delivery-check.md + scripts/voice_delivery.py）：用 ffmpeg 解出 PCM 算 100ms 窗的 RMS 音量包络，找出停顿、音量明显变小的段和头尾音量差；给了转写 JSON 就再算每秒字数（语速），输出 report.md（发现/证据/怎么改）、curve.png（音量+语速+停顿区间）和 data.json。只用 ffmpeg 和 numpy，不装模型、不联网、不上传、不花钱。

明确划了边界：**它不判断情绪**。声音里的情绪、气场、像不像在演，只有本人和目标观众能给，脚本只负责把"感觉不对"定位到第几秒。这一点写进文档和报告尾部，防止被当成"语气评分"交出去。

起因：用户问能否接入语音情感识别。评估后认为语音情绪识别输出的是"中性/高兴/生气"这类粗标签，解决不了"这段有没有劲、像不像念稿"的实际问题，且要装模型或把音频传第三方；改用音量包络加速度曲线，零成本且更对症。

验证范围：用合成音频（含两段静音）和带音轨的 MP4 各跑一次，报告、曲线图、JSON 均正常；无音轨文件和不存在路径均给出中文错误提示；`--transcript` 传入 segments 后语速曲线正常。**未用真人说话录音验证过阈值合理性**（6dB、4.5字/秒、1.5秒等待调）。
