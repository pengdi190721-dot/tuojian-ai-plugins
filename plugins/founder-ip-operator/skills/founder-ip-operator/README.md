# 创始人 IP 操盘手 · 完整技能包

版本 2.0.0，完整独立版。本版并入原“自媒体作战室”：选题雷达与评分、选题调研、对标视频拆解改写、口播与Vlog结构、剪辑包装与重点大字、九式封面、发布前成片评分、视频解析和环境体检都在本包内，只装这一个就够；另新增付费投流：先问老板这一轮要纯曝光、获客还是卖货，再按目标测、放、接、复。第一次使用先自检已有资料、再问几个能语音回答的问题、直接出IP定位报告；保留开头、结构与封面配合的检查方法；保留后台截图与视频复盘、改稿验证和已采纳建议沿用；每条口播稿固定配套现场提问或提示卡。保留经营诊断与30天验证，保留全部人物、口语、故事与影像能力。全部访谈、策划、选题、对标、封面、审片、投流、报告与 AI 影像工作方法都在本包内，无需另外安装「自媒体作战室」或「AI短剧导演台」。已装过作战室的学员，装好本技能后可以停用作战室，避免两个技能抢同一类任务。

## 给学员的三步操作

1. 解压压缩包，保留完整的 `founder-ip-operator` 文件夹。里面应同时有 `SKILL.md`、`references`、`assets`、`scripts`、`examples` 和 `licenses`，不要只复制入口文件。
2. 将整个文件夹交给支持本地技能的智能体，发送下方安装指令。支持读取压缩包的工具可先解压检查；不支持时请先在电脑上解压。
3. 安装后新开对话，发送“使用创始人IP操盘手，帮我做IP定位”。技能会先查已有资料，再问几个问题，按住说话用语音回答就行。

### 可直接复制的安装指令

> 请将这份“创始人 IP 操盘手”作为独立技能安装。先读取 SKILL.md 和 README.md，再根据当前工具实际支持的技能目录放入完整文件夹，保留所有附件。不要创建插件，不要修改插件市场配置。若已有同名技能，先核对版本和内容并保留旧版备份，再更新这一个技能。安装后检查附件完整性，告诉我如何调用。当前工具不支持安装时，请说明，并读取本包相应资料，在当前对话按技能执行。

Codex 可放入用户技能目录 `~/.codex/skills/founder-ip-operator/`。其他工具以实际支持的目录为准，本包不含通用自动安装程序。独立技能不以出现在“插件列表”为验收标准，应验证是否能读取并执行本包流程。

无法持久安装时，保留完整资料包供当前对话读取；仅复制 `SKILL.md` 的文字会缺少附件方法。新对话无法访问文件时，需要重新提供资料包。

## 工作方法与实际工具

本包提供完整方法、模板、报告生成脚本和视频解析脚本。核心策划只需能读取中文资料；自动生成HTML使用Python 3标准库；视频解析需要Node.js 22.12以上和npx，第一次使用会联网下载本地识别组件。PDF导出、实时联网、图片视频生成、剪辑和发布，使用学员实际已有的工具与授权。本包不附带这些服务的账号、额度或模型。

没有生成工具时，仍可完成分镜、完整提示词、实拍方案和剪辑交接；不能声称实际媒体已生成。
