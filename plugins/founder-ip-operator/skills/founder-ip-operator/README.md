# 创始人 IP 操盘手 · 说明书

版本 2.2.1。给自媒体新手用的短视频操盘手：定位、选题、写稿、拍摄、发布前打分、投流、复盘，一个技能全包，说的都是大白话。

## 新手只看这三步

1. **第一次用**，说“帮我做IP定位”。回答几个问题（按住说话、语音回答就行），拿到定位。
2. **每周**，说“这周拍什么”。先看同行最近在拍什么，再出选题，挑一个拍法，写成稿子，附现场提问卡。
3. **拍完、发完**，说“帮我看看这条视频”，或者发后台截图。会打分、找问题，告诉你下一条怎么改。

其他用法看[新手操作卡](新手操作卡.md)，遇到问题看[常见问题](常见问题.md)。

## 整个流程

```
第一次用：做IP定位
      ↓
每周：看同行在拍什么 → 出选题 → 挑拍法 → 写稿子和提问卡
      ↓
拍完：自己剪好 → 发之前打个分 → 出标题、简介、封面字 → 发出去
      ↓
发完：发后台截图复盘 → 好的建议记下来 → 回到“出选题”
（想花钱推视频：随时说“这条要不要投流”）
```

## 哪些不用装、哪些要装

| 功能 | 要不要装东西 |
|---|---|
| 定位、选题、写稿和提问卡、标题简介封面字、投流教学、看截图复盘、首访准备 | 不用装，直接能用 |
| 读视频文件（拆对标、成片打分、视频复盘） | 要装 Node.js 22.12 以上 |
| 发链接让它读（公众号、抖音、小红书、B站、得到App） | 注册个得到大脑免费账号就行，第一次发链接时会给你注册登录链接 |
| 口播体检（哪几秒没劲、哪里卡） | 要 ffmpeg 和 numpy，画图另需 matplotlib |

不会装就说“帮我检查一下哪些功能能用”，它会一步一步告诉你。

**这个技能不做**：剪辑、做封面图、AI生成画面、正式报告和提案。剪辑和封面图用你自己的工具（比如剪映）或交给同事，它会告诉你要什么效果、封面上写哪几个字。

## 怎么安装

1. 解压压缩包，保留完整的 `founder-ip-operator` 文件夹。里面要有 `SKILL.md`、`references`、`assets`、`scripts`、`examples`，别只复制一个文件。
2. 把整个文件夹交给你用的 AI 工具（比如 WorkBuddy），发下面这段安装指令。
3. 装好以后新开一个对话，说“帮我做IP定位”。

### 可直接复制的安装指令

> 请将这份“创始人 IP 操盘手”作为独立技能安装。先读取 SKILL.md 和 README.md，再根据当前工具实际支持的技能目录放入完整文件夹，保留所有附件。不要创建插件，不要修改插件市场配置。若已有同名技能，先核对版本和内容并保留旧版备份，再更新这一个技能。安装后检查附件完整性，告诉我如何调用。当前工具不支持安装时，请说明，并读取本包相应资料，在当前对话按技能执行。

Codex 可以放进 `~/.codex/skills/founder-ip-operator/`。其他工具以它实际支持的目录为准。

从 SkillHub 安装时，平台不收 PDF，会跳过《首次面谈必问清单》的打印版，文字规则和流程不受影响。要看这份文件，到 GitHub 上本技能的文件夹里打开：https://github.com/pengdi190721-dot/tuojian-ai-plugins/tree/main/plugins/founder-ip-operator/skills/founder-ip-operator

## 文件夹里都是什么

| 位置 | 是什么 |
|---|---|
| `SKILL.md` | 技能入口：三步上手、怎么说、能做什么、铁律和流程 |
| `新手操作卡.md` | 二十多句现成说法，复制就能用 |

| `references/` | 每个功能的详细做法，AI 按需读，你不用看 |
