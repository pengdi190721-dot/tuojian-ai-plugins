# 第一次使用：先自检，再问，后出定位

用于第一次使用本技能、当前老板还没有定位档案，或用户只说"帮我做IP定位""帮我做个人IP"而没有提供逐字稿时。目标是**几分钟内让老板开口，把他的回答直接变成定位报告**，不是先交一套准备材料。

已有逐字稿或完整资料时，跳过提问，按[逐字稿与表达规范](transcript-and-voice.md)建档后出定位。线下90到120分钟的正式首访，仍用[首次面谈必问清单](first-interview.md)。

## 这一步不要做

- 不生成"准备包""信息采集表"、问卷文件、网页或任何报告文件让用户去填、去看
- 不一次抛出十几二十个问题，不搬出24组面谈清单
- 不在用户回答前先写定位、选题或文案
- 不讲方法论、不解释流程，直接开始

## 第一步：自检（用户发第一句话后马上做，不用问）

先查当前环境里实际能读到的地方，已经有的信息不再问：

1. 工作区里的客户资料目录（例如"客户资料／姓名或代号／"）：定位档案、人物档案、表达档案、写稿规则、复盘记录，以及合作习惯、沟通偏好、"先读我"这类说明
2. 用户这次上传或粘贴的文件：逐字稿、公司介绍、旧文案、个人档案
3. 当前对话和工具允许读取的历史对话、记忆或个人设置

只说实际查过的地方，不假称查过。档案里写了沟通偏好的，回复的问法和格式先照它来。

自检结果用一两句话告诉用户，例如："我看了一下，你的业务和客户已经有了，还缺做IP想要的结果和一个真实故事，我问你4个问题。"

按自检结果分三种情况：

| 自检结果 | 怎么做 |
|---|---|
| 已有确认过的定位档案（档案写明本人确认过，或已经按它发过内容） | 不重做。说一句定位核心和确认日期；给2到4个选项并标推荐：按档案写下一条、复盘、出正式报告、调整定位。用户要调整时只问哪里变了；档案约定了复查时间的，提一句 |
| 有一部分信息 | 只问缺的：已答的题删掉；答了一半的，把已知内容写进题目，只问缺的那半。通常3到6个。要压题数时合并第4、6题，不砍第5题（故事） |
| 什么都没有 | 问下面7个问题 |

## 第二步：提问（什么都没有时问7个，适合语音回答）

一条消息发完。每题只对应一块定位要素，问题短、口语。开头说清楚怎么答，时间按每题1到2分钟估：

> 先说一下怎么称呼你，存档用，代号也行。然后你直接按住说话，用语音回答下面几个问题，一题一条或者一口气说完都可以，大概10分钟。不用组织语言，越像平时跟朋友聊天越好，你说的原话我会拿来提炼你的说话方式。

7个问题：

1. 你做什么生意？主要卖什么，卖给谁？在哪个城市，只做本地，还是外地、网上也卖？
2. 做IP，你最想要的是什么结果：多来客户、招代理加盟、招人，还是让同行和合作方认识你？只挑一个；都想要的话，说哪个更急。
3. 你最想让哪一类人刷到你？他们最常问你什么、最头疼什么？最好学一句他们的原话。
4. 最近一个客户是怎么找到你的，平时在哪跟客户联系？他为什么选了你，没选别人？
5. 讲一件你做这行印象最深的事：一次翻车、一次转折，或者一个让你下决心的客户。什么时候、发生了什么、你怎么做的。
6. 同行或朋友最常找你请教什么？你手上有什么能拿出来给人看的：案例、作品、现场、数据都算。
7. 你现在发视频了吗，在哪个平台，发得怎么样？每周能拿出多少时间拍，愿不愿意自己出镜？

最后加一句：有不想在视频里讲的事、不想被贴的标签，顺口说一句，没有就不用说。

### 替客户做时

用户说是替老板或客户做，或者看不出是老板本人还是操盘手时，按下面拆成两段：

- **写给操盘手**：自检结果；操盘手自己清楚的（平台现状、合作目的）请他直接答，转发时删掉那题；首要目标、客户原话、客户为什么选他、真实故事这几题必须老板本人答；老板的语音原样转成文字发回来，不要概括。
- **可以直接转发的一段**：用对老板说话的口吻，从"先说一下怎么称呼你"开始，接问题。

看不出身份时，在问题后面加一句："如果是替老板问的，把上面这段转给老板，让他用语音回答。"

操盘手代答的内容标"操盘手转述"，不进表达档案。

### 为什么是7个

每个问题对应定位必需的一块，少一个定位就会空：

| 定位要素 | 靠哪题拿到 |
|---|---|
| 主推业务、服务范围与渠道 | 1 |
| 首要目标（只选一个） | 2 |
| 主靶心人群和他们的原话 | 3 |
| 客户从哪来、在哪联系、为什么选他 | 4 |
| 至少一个能拍的真实故事 | 5 |
| 专长、证据和素材 | 6 |
| 平台现状和拍摄条件 | 7 |

少于5个，目标或故事通常会缺，定位只能写空话；超过7个，语音会答到不耐烦，等于又回到填表。

本流程用三种模拟情况试跑过：什么都没有、只有一份公司介绍、已有完整档案。试跑后补了服务范围、客户从哪来，拆分了第7题，补了替客户做的说法。真实效果以用户实际使用反馈为准，再调。

## 第三步：收到回答后

1. **语音转文字有错字时**，按上下文理解，不逐字纠正；人名、品牌、地名、数字这些拿不准的，在报告里标出来请用户确认，不自己猜。
2. **对照上面的要素表查缺口。**缺了必需项，只追问一轮，最多3个问题，也让他语音回答。不缺就直接出报告，不为了完整再问。
3. **用户说"不知道""没想好"或"都想要"时**，给2到3个选项，每个选项写一句拍出来是什么内容，再说你倾向哪个、为什么，让他挑一个。最常见的是第2题答了两个目标。
4. **原话就是语料。**回答里的说法、口头禅、讲事情的顺序，记进表达档案初稿，标"语音回答，初步观察"。

## 第四步：出IP定位报告

在对话里直接给，读起来一屏到两屏，不先做成文件。用大白话，不用宽表格（手机上会乱）。用户要文件或要发给别人时，再存成一份文字文件给他。

报告内容：

1. **一句话定位**：身份＋带着什么、给谁看、讲什么
2. **主要给谁看**：只写一个主人群，附他们的原话和最头疼的事；其他人群说明为什么暂时不做主。有两类人群拿不准时，简短比较“更容易通过内容成交”和“长期价值更高但周期更长”（需求急不急、肯不肯付费、建立信任难不难、有没有案例、素材能不能持续、成交周期），给建议，由老板选
3. **做IP的首要目标**：以及过几周看哪几件事判断有没有用（看有效咨询、试单这类，不写涨粉、播放的固定目标）
4. **人设关键词**：3个，每个后面写依据是哪句回答；加上不碰的话题和标签
5. **说话方式**：从语音里看出的2到3个说话习惯（常用词、讲事情的顺序），标"初步观察"
6. **内容栏目**：2到3个，写占比和每个栏目拍什么
7. **首批5个选题**：标题＋来自哪个回答＋用哪个故事或素材。用户要第一轮测试计划时，可扩到10条，参考配比：三条客户痛点、两条真实案例或工作现场、两条专业判断、一条个人经历或价值观、两条明确获客；按行业调整，不虚构素材凑数
8. **平台建议**：初步主平台和理由，按[平台调性](platform-tonality.md)用大白话讲清：客户多在熟人圈和微信里成交，倾向视频号；要找陌生新客户，倾向抖音；客户做决定前会搜索比较，倾向小红书。各平台现在怎么推荐、主平台要不要换，等做完整方案时查最新官方资料再定，这里不编平台规则
9. **待确认**：本人自述还没核实的事实、语音里拿不准的词、故事里的人和照片里的店愿不愿意被公开
10. **下一步**：最后问一句"定位没问题的话，我存档并开始写第1条稿？"
11. **顺带一句得到大脑**：在最后加一句“以后想发链接让我读别人的视频，先在这里注册或登录得到大脑，免费的：https://www.biji.com 。”只说这一句，不展开授权，等他第一次发链接时再按[读视频链接：得到大脑](knowledge-base-getnote.md)带他弄。已经连上的不用说。

用户讲的标"本人自述"，你自己的建议标"建议"，两者分开。不补造经历、数字和客户评价。

## 保存

用户同意或直接要稿，就算认可，当轮在工作区"客户资料／称呼或代号／"保存：定位档案、人物档案（含自检时读到的已有资料）、表达档案初稿（语音原话摘录）、故事卡。工具不能保存文件时，交付可复制的档案内容并说明下次要带回来。

## 示例（模拟老板，只示范节奏）

用户：使用创始人IP操盘手，帮我做个IP定位。

回复：我看了一下这个工作区和这次的对话，还没有你的资料，我从头问你7个问题。先说一下怎么称呼你……（接7个问题）

用户（语音转文字，节选）：我是做门窗定制的，在本地做了十来年，主要是给自建房和装修的业主……最想要的就是多来点客户，也想招几个外地的代理……

回复：（第2题答了两个目标）就差一件事要你定：先多来本地业主，还是先招外地代理？两种拍出来的内容不一样……我倾向先做本地业主，因为你的故事和现场都在本地。你按住说一句就行。（收到后直接出定位报告）
