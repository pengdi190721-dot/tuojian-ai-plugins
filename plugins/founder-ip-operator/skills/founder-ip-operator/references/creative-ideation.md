# 创意发散：创意拍法直接给老板选

用于两种情况：

- 出选题时，“现在就拍”的每条都附上创意拍法（见[选题雷达](topic-radar.md)第4节）。
- 老板说“想不出新花样”“太普通了”“这个题怎么拍才有意思”，或对标拆完要改出自己的版本。

创意拍法**直接给老板看，用不用、用哪个由老板定**。操盘手可以说推荐哪个、为什么，但不替老板筛掉，也不替老板拍板；老板说不用，就按常规拍法写，不再劝。

## 先讲清楚：AI为什么"脑洞不够"

AI给的默认答案，是大多数人最常写的那几种，所以读起来顺，但不新鲜。这不是换一个更聪明的AI能解决的，原因有两个：

1. **原料不够**：只给一个题目，AI只能从网上的平均做法里挑。真正让人眼前一亮的创意，多半来自老板自己的真事、现场和反差，这些AI不知道，得先问出来。
2. **没逼AI离开平均答案**：不给方法，AI第一轮想到的就是最常见的。要用固定招式把方向拉开，再用数量换质量。

所以分工是：**AI负责想得宽，老板负责挑。** 不能为了有创意去编事件、编数字、编结果。

## 第一步：找创意原料

先从客户目录（定位、表达档案、真事和现场素材）和这次对话里找，找得到就不问。缺的跟着创意一起问，不单独多问一轮：

- 这条要讲的那件真事：谁、在哪、当时发生了什么，最意外的一个细节是什么
- 现场能拍到什么：一个物件、一块屏幕、一个数字、一个人、一个地方
- 老板身上的反差：经历、身份、做法里"按理说不该这样"的地方
- 观众说过的一句原话：评论、私信、客户、同行问过的原句

## 第二步：先划掉平均答案

先列出"这个题别人最常见的十种拍法"（行情里看到的对标和同类拍法也算进去），全部划掉。后面想出来的创意，跟这十种撞了就重想。

## 第三步：用十二招各想两三个

每招至少出两个，总数三十个左右，先不评判。

| 招式 | 怎么想 | 例子方向 |
|---|---|---|
| 反差身份 | 让平时不干这件事的人来干 | 财务来做短视频、仓库主管来写文案 |
| 物件开口 | 让一个物件当主角或用它的视角讲 | 一张发票、一个产品、一张表格的一天 |
| 极端条件 | 把条件推到极端 | 只给一分钟、只说一句话、一分钱不花 |
| 人和AI比一场 | 同一个活儿，人和AI同时做，现场出结果 | 谁先做完、谁做得对 |
| 时间压缩或拉长 | 把很长的事压短，或把一瞬间拉长讲 | 一年数据一眼看完、一秒钟决策背后的十分钟 |
| 换场景 | 把这件事搬到不相干的地方讲 | 在仓库开会、用菜谱的格式讲流程 |
| 反着来 | 故意按错的做法做一遍，看会怎样 | 不给AI规矩、只给一句话，看AI做成什么样 |
| 让AI扮角色 | AI扮客户、扮老板、扮挑剔的同行 | 让AI扮最难缠的客户来问 |
| 借别的格式 | 借其他领域常见的视频格式 | 开箱、测评、探店、挑战、街头采访、新闻播报、一日记录 |
| 掀开后台 | 拍平时看不到的那一段 | 出货前一晚、改稿第五遍、开会吵起来那一刻 |
| 一个真数字当主角 | 用一个真实、具体的数字开场 | 必须是测过的数，没测过不用 |
| 拆成连续剧 | 一件事拆成几集，每集留一个没说完的点 | 第一集立目标，最后一集交结果 |

再换三个视角各补一个：综艺导演会怎么拍、纪录片导演会怎么拍、这个行业的客户最想看什么。

## 第四步：挑出三个最好的放前面

每个创意按四问打分，每问0到2分，用来排顺序：

1. **第1秒有画面吗**：能不能一开头就给出具体的东西，而不是道理
2. **跟这个账号有关吗**：贴不贴人设和主线
3. **看完能说给别人听吗**：有一句能复述、能转发的话
4. **我们真拍得出来吗**：素材、时间、成本、风险是不是现成或可控

再按[平台调性](platform-tonality.md)过一遍：视频号要熟人愿意转、转了有面子；抖音要陌生人前两秒停下来；小红书要能收藏、能照着做。

碰到底线的直接拿掉，不给老板看：要编事件或数字的、拿人或旧做法垫底的、涉及价格承诺却没人拍板的。

## 第五步：直接给老板

给老板的样子（每个创意四行，分数不用给老板看）：

> **常规拍法**：一句话说怎么拍
>
> **创意拍法一**（推荐）：一句话创意
> 第1秒画面：……
> 为什么适合你：……
> 要准备：素材、人、时间
>
> **创意拍法二**、**创意拍法三**：同上
>
> 用哪个，还是按常规拍？想看全部三十个也可以说。

- 老板选了哪个，就按哪个写稿，写稿按[开头、结构与封面配合](opening-and-structure.md)和[口播与Vlog结构](script-structures.md)。
- 老板说“都不用”，按常规拍法写。
- 老板要看全部，按招式分组全部列出，同样直接给老板挑。
- 缺原料的创意，标清“要你补一句：……”，老板补了再写。

## 越用越懂这个老板

老板选中和否掉的创意，连同他说的原因，按[客户建议与沿用](client-learning.md)记进该老板的目录。下次先读这份记录：他喜欢的招式往前放，他明确否过的方向不再推。老板连着几次都说不用，就把创意拍法缩成一行“要不要来点新鲜拍法？”，他要再展开。对标拆解时，把对方用到的招式（不是内容）记进同一份记录，当作这个老板的创意库。

## 边界

- 创意可以大胆，事实不能编；需要真事的地方，没有就问，不替老板编故事。
- 借格式只借形式，不搬别人的身份、案例和原句。
