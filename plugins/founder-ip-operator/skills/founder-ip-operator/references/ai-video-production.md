# AI影像制作：真人融合与真实故事演绎

本文件与[制作工作表](../assets/ai-video-workbook.md)已包含从事实、人物到分镜、提示词、连续性与剪辑验收的必要方法。直接在当前技能内完成，不要求读取另一个技能，也不绑定固定生成平台。

## 先确定画面用途

| 需求 | 本技能的处理方式 |
|---|---|
| 纯实拍采访、工作纪录或实物讲解 | 输出现场提问、口语稿、动作及镜头清单；不额外增加 AI 制作流程 |
| 少量环境、物件或回忆补充画面 | 说明每个镜头补充什么信息，安排对应参考、分镜与提示词；没有人物就不做人物参考页 |
| 真人讲述与 AI 回忆画面融合 | 沿用本人声音和口语主线，明确真实影像与生成影像的性质，设计前后动作、视线、构图或声音衔接 |
| 完整故事情景演绎 | 先确认事实边界，再按需求形成人物小传、剧情、统一参考、分镜和制作文件 |

AI 镜头的数量与长度取决于表达任务、可用素材和预算，不默认固定占比。旧物、照片或当下实拍足以表达时，可直接使用。客户拒绝 AI 时执行纯实拍方案。

## 阶段与推进依据

| 阶段 | 当前应交付的内容 | 推进依据 |
|---|---|---|
| 内容与事实 | 视频目的、本人讲述、故事卡、来源、可公开范围、允许演绎与不可编造项 | 用户确认方向与涉及演绎的事实边界；已有确认沿用 |
| 人物与剧情 | 当前出镜人物小传、本人语言依据、各场次动作与必要对白 | 用户确认本次所需的人物与剧情版本，不重做已有档案 |
| 统一参考 | 人物造型、场景布局、产品与道具参考 | 相关参考已确认；只做项目确实需要的资产 |
| 分镜与图片 | 镜头对照表、图片清单、独立完整提示词、实际成图检查 | 用户确认本批实际图片；无关镜头可并行推进准备工作 |
| 视频提示词 | 根据确认成图安排动作、表演、镜头、声音和结束状态 | 图生视频依赖已确认图片；尚无图片时只能给动作草案 |
| 生成与验收 | 实际生成文件、画面与声音检查、定向修改记录 | 已有具体生成及费用授权；实际看过、听过后记录结果 |
| 剪辑交付 | 素材映射、剪辑对照稿、音画衔接、实际时长及文件 | 根据真实可用素材与用户要求完成检查 |

阶段用于组织工作，只做当前任务需要的部分。用户明确调整流程时按其要求执行，准确标明未确认依赖。已确认的步骤不重复询问。无生成或剪辑工具仍完成文本、参考要求、执行清单与交接；不能称媒体已经制作完成。

## 人物小传与场景档案

人物小传先承接本人档案：业务身份、真实经历、判断方式、语言样本、动作习惯与人物关系。仅补充当前场景所需的年龄阶段、衣着、表情起点、行动目的及视觉不变项。资料缺失写待核实；不凭人物动机猜测心理，不给真实老板编人生。

需要跨镜头固定人物时，先确认单个人物参考，再逐一扩展。三视图可采用正面、严格侧面、背面，同尺度、服装与配饰一致；需要多种表演时再做情绪参考页。情绪参考只改变表情与合理姿态，不能悄悄改变身份、衣服或道具。已有照片和确认图够用时直接沿用。

场景档案记录布局、光线方向、通道、桌椅、产品和道具位置。产品外形与规格来自实际资料。多人混淆时补充小组或空景参考；反打应符合真实空间，不靠水平镜像改变文字、配饰和左右关系。

AI 场景不充当真实订单、工资单、客户评价或经营结果的证据。记忆中的环境不确定时按示意处理，不写成精准历史复原；肖像与声音用途按实际授权执行。

## 分镜与真人融合

使用[制作工作表](../assets/ai-video-workbook.md)建立统一对照表，逐镜注明：对应口语／动作、实拍或 AI、来源与事实状态、景别机位、起止画面、前后衔接、声音、目标时长、依赖及状态。

实拍镜头写清现场提问、视线、动作、道具、环境声与剪辑预留。AI 镜头说明它补充的信息，以及与真人素材的构图、光线、声音或动作关系；先保证叙事成立，再选择转场方式。保持本人自然口语，不为迎合镜头改写成统一的电影独白。

图片与视频分开编号，一段视频可以使用多张参考图，同一张图也可以服务不同片段。正式分镜图每张表现一个瞬间，参考页可以多格。连续运镜只需要关键视角，不将每张参考图硬切成幻灯片。

复用前核对清晰度、前景人物、视线、服装、产品、空间与光线。局部补图保留原编号，新增补图或版本，同步修改下游映射，不重排全项目。

## 图片提示词与成图检查

固定交付顺序：

1. 先列实际上传素材、标签、用途、优先级和操作说明。缺失素材写待提供或待生成。
2. 再给一整段可复制的模型指令，包含画幅与风格、场景光线、人物产品、景别机位、构图、单一瞬间的动作、可见情绪、参考关系及必要限制。

指令正文不混入“请上传”“保存文件”等操作步骤，不让用户自行拼公共设定。每个素材标签必须确有对应素材，不伪称已上传。图片提示词描述一个瞬间，不描述连续秒数和运镜轨迹。

实际成图逐项检查身份人数、服装、手部、产品、视线、空间、光线及可见文字；细节需放大查看。记录可用／需改／未检查，另记用户确认。图间有冲突，明确哪张锁身份、哪张只取动作，并写入后续指令。

## 视频提示词、表演与声音

先看本段实际成图，再写最终视频提示词。只有文字策划或未确认图片时可以继续做动作草案，状态须清楚。

沿用“素材说明在前、完整指令在后”的格式。正文至少包含：目标时长与画幅、场景人物、起始状态、按时间推进的动作与表演、摄影机路径、准确归属的台词、声音要求、参考优先级、结束状态及衔接要求。

时间段连续、不重叠；依据本人自然朗读、停顿与动作估算。内容放不下就调整长度或拆段，不依靠倍速。模型的时长、参考数量及声音支持须以当前实际能力为准，目标时间码不等于生成保证。

表演写清“起始状态、触发事件、可见反应、结束状态”，包括听话者。多人动作安排先后，情绪变化有依据；不能额外生成真实人物并未发生的激烈反应。运镜方向、角度与空间兼容，遮挡须有真实物体及进出过程，人物不瞬移。

老板真人讲述优先保留原录音。确需生成角色声音时，音色、年龄感、语速和说话人对应，声音克隆另按授权；不承诺只靠文字完全锁定声线。专名和多音字给读法，备注不朗读，实际听音后才能验收。旁白、对白、环境声、音效与配乐分别记录需求。

用户要求原生中文时写明精确文本、位置、出现时间和稳定要求，并检查实际效果；同意后期字幕或替换时另交文字与出现时点。不能编造产品参数、报价、客户消息和成绩。

## 修改、剪辑与验收

问题先分类：参考、身份与空间、动作表演、声音、中文、节奏或剪辑衔接。按问题局部修正，必要时补图，不无依据地整段反复重做或持续消耗费用。

替换保留编号、增加版本，并同步更新：执行登记、图片视频映射、剪辑对照稿、前后镜头起止状态与总长。用户本轮明确修改优先，其次为已有确认及对应版本；文件名叫“最终版”不代表已经确认。

先顺本人讲述与故事逻辑粗排，再调整动作、反应、呼吸、环境声和补充画面。目标长度、素材实际长度、剪辑采用长度分别记录；插入、替换、减速和转场后重新计算。承诺可编辑工程时核对工程与素材关联完整，成片按当前约定交付。

| 检查层级 | 能得出的结论 |
|---|---|
| 文本和分镜 | 方案及指令是否完整，不能证明生成效果 |
| 实际图片 | 身份、构图、手部、产品、光线和文字是否可用 |
| 视频全过程 | 连续性、动作、镜头、人物数量和文字稳定性 |
| 实际听音 | 台词、读音、声线、音量与音画同步 |
| 完整时间线或成片 | 叙事、节奏、衔接、总长、字幕标注及可播放性 |

无法检查的部分明确标注未验证。最后回查人物与口语是否像本人、事实和公开边界是否准确、AI 画面是否暗示不存在的事实、交付是否符合所选服务与平台要求。提示词已交付、待生成、待确认、待剪辑、已验收、已导出分别记录。
