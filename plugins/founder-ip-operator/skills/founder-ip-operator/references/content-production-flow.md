# 单条内容：从选题到发布

用于老板已有定位，要把一个想法推进成一条能发的视频，或者一次涉及三个以上环节（例如选题、写稿、封面、审片）。把一条内容当成有进度的小项目，不当成一次性生成文案。已经完成且有可靠产物的环节直接跳过，不重做。

| 环节 | 输入 | 产物 | 通过条件 | 方法 |
|---|---|---|---|---|
| 选题 | 想法、真实素材、热点 | 选题卡 | 70分以上，有这位老板独有的角度 | [选题雷达与评分](topic-radar.md) |
| 对标拆解（可选） | 单条对标视频、档案和素材 | 对标卡、原创映射 | 只迁移结构与节奏，已换成本人真实素材 | [对标视频拆解改写](benchmark-remix.md) |
| 调研 | 选题卡 | 研究简报 | 关键事实有直接来源 | [选题调研与事实核验](topic-research.md) |
| 写稿 | 简报、表达档案、案例、已采纳规则 | 完整稿、开头备选、提问卡 | 能自然说出口、无虚构，开头和结构检查通过 | [口播与Vlog结构](script-structures.md)、[开头、结构与封面配合](opening-and-structure.md)、[现场提问与提示卡](on-set-interview.md) |
| 拍摄 | 稿件、提问卡 | 原始视频 | 收音清楚、本人认可 | [影像与运营执行](production-and-operations.md) |
| 剪辑包装 | 原始素材、稿件 | 粗剪或剪辑清单、字幕和重点大字 | 故事清楚，实际文件可播放 | [剪辑与包装](editing-and-packaging.md) |
| 封面 | 封面字、主图 | 封面成品或方案 | 比例、真人身份和一秒缩略图可复核 | [九式封面](cover-design.md) |
| 成片评分 | 成片 | 评分、时间码证据、三项优先修改 | 无发布阻断项，关键问题已处理 | [成片评分教练](pre-publish-review.md) |
| 发布包装 | 通过评分的成片和封面 | 各平台标题、简介、话题 | 和内容一致，平台规则复核过 | [三平台执行流程](platform-distribution-and-rules.md) |
| 投流（可选） | 已发布且跑过自然流量的视频、老板定的目标和预算 | 投前确认卡、投放方案、盯盘表 | 目标由老板选定，止损线和观察时间写清，合规自查通过 | [付费投流](paid-traffic.md) |
| 数据复盘 | 后台截图和视频 | 核对表、改稿、下一条验证 | 形成可验证假设，采纳后保存 | [视频数据复盘](video-performance-review.md) |

## 推进方式

每完成一个环节：保存产物或摘要，更新进度，做这个环节的检查；没有需要用户决定的事，就继续下一个环节。

只有这些情况才停下来问：缺必要素材；需要决定公开边界；需要登录、授权或产生费用；两种方向会明显改变结果。只有缺失信息会实质改变结果时才问，每次只问必要的，其余做合理假设并标明。

## 进度记在哪里

在当前客户目录（默认“客户资料／客户代号／”）的“内容进度.md”里，一条内容一节，记：标题、当前环节、各环节状态（待开始／进行中／完成／跳过）、产物位置、采用的假设和待确认问题。不写进技能目录。没有对标视频时，对标拆解标“跳过”；不投流时，投流标“跳过”。
