# 口播体检：声音大小、停顿和语速

用途：看一条片子“说出来有没有劲”。不判断情绪，只给能量化的证据，把“感觉不对”定位到具体第几秒。

跟老板这样说：“我把你这条的声音大小、停顿和语速画成曲线，看看哪几秒没劲、哪里卡了。好不好听最后还是你自己听了定。”

工具：`scripts/voice_delivery.py`。要电脑装好 ffmpeg 和 numpy（画曲线图另需 matplotlib，没装就只出文字报告）；不装模型、不联网、不上传、不花钱。缺 numpy 时脚本会用白话告诉怎么装：在终端输入 `python3 -m pip install numpy matplotlib`。

---

## 一、先说清能力边界

**能测：**

| 指标 | 对应什么问题 |
|---|---|
| 音量动态范围（dB） | 整条是不是平的、有没有起伏 |
| 停顿位置与时长 | 哪里卡壳、哪里忘词 |
| 音量明显变小的段 | 哪里没底气、像在念稿 |
| 语速（字/秒，需转写） | 哪里拖、哪里赶、节奏稳不稳 |
| 头尾音量差 | 收尾是不是泄气了 |

**不能测：**

- **情绪本身**（生气／疲惫／兴奋）。要这个得用专门的语音情绪识别，本脚本不做。
- **音色、口音、气场**。听不出来。
- **表演好不好**。这是主观判断，只有老板本人和目标观众能给。

> 一句话：这是**证据工具**，不是**裁判**。它负责指出"第 37 秒声音掉了 8dB"，至于这段该不该重录，由人定。

---

## 二、怎么跑

```bash
# 只测音量、停顿、起伏（不需要转写）
python3 scripts/voice_delivery.py 视频.mp4

# 加语速：先转写，再把 JSON 传进来
python3 scripts/analyze_video.py 视频.mp4 --detail standard --json-output 转写.json
python3 scripts/voice_delivery.py 视频.mp4 --transcript 转写.json

# 指定输出目录
python3 scripts/voice_delivery.py 视频.mp4 --transcript 转写.json --out ./体检
```

转写 JSON 只要含 `segments`（每项有 `start`、`end`、`text`）即可，脚本会自己往里找，不挑格式。

**输出四样：**

| 文件 | 内容 |
|---|---|
| `report.md` | 白话报告：发现 + 证据 + 怎么改 |
| `curve.png` | 蓝线音量、红线语速、黄色区间停顿（装了 matplotlib 才有） |
| `data.json` | 全部原始数据，便于对比不同版本 |
| 终端摘要 | 直接把问题打在屏幕上 |

## 三、判读阈值（脚本内置，可解释）

| 指标 | 阈值 | 结论 | 建议 |
|---|---|---|---|
| 动态范围 | < 6 dB | 整条太平 | 挑最重要一句做重，前一句压低制造落差 |
| 停顿 | 单处 ≥ 1.5 秒 | 卡壳式停顿 | 拆长句，或这几句单独练三遍 |
| 音量段 | 低于中位数 45%（约 -5 dB）且持续 ≥1 秒 | 像没底气／在念 | 单独重录，身体前倾、下巴略低 |
| 平均语速 | < 4.5 字/秒 | 偏慢，容易走神 | 不是加快，是删字，每句压到 15 字内 |
| 平均语速 | > 7.5 字/秒 | 偏快，跟不上 | 结论前加 0.3 秒停顿 |
| 语速标准差 | > 均值 × 0.55 | 忽快忽慢 | 先定断句再录，每次在同一批位置停 |
| 头尾差 | 结尾比开头低 > 6 dB | 收尾泄气 | 结尾单独录，站起来说或凑近镜头 |

阈值是可调的常识值，不是行业标准，**还没拿真人录音验证过，先当“待调”用**。客户自己听出问题、给出时间点时，以客户的判断为准，数据只用来佐证。

## 四、和审片其他环节怎么配合

| 环节 | 谁负责 |
|---|---|
| 画面构图、光线、字幕、背景 | [视频解析](video-analysis.md) 抽帧 → 看图 |
| 说了什么、有没有废话、逻辑跳不跳 | 转写文字 |
| **说得有没有劲、哪里卡** | **本脚本** |
| 情绪、气场、像不像在演 | **只有老板本人和目标观众能给**，不假称能判断 |

标准流程：转写 → 本脚本 → 把问题点报给老板 → 老板亲耳听一遍确认 → 决定重录哪一段。

## 五、边界与坑

- **压缩过的音轨会影响判断**。聊天软件传过的片子，动态范围会被压扁，测出来"太平"可能是转码导致的。判断前先问一句"是原片还是压缩版"。
- **音量小不等于差**。刻意压低是常见手法，要结合上下文看。报告里写"该段比中位低 X dB"，不下"这段不行"的结论。
- **纯音乐、无口播的段落**会被算进语速空洞，看曲线时要人工排除片头片尾。
- **不要把这份报告当作"语气好坏"的结论**交给老板。它是"第几秒发生了什么"，判断权永远在人。
- 脚本不写文件到云、不发第三方，全本地。
