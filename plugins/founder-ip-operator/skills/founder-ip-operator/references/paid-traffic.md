# 付费投流：先教，再问目标，然后测、放、接、复

用于老板要给视频号、抖音、小红书的视频、笔记或直播花钱加热、投广告，或问“这条要不要投”“怎么投”“投了没效果怎么办”。

**默认老板什么都不懂**：没投过、不知道这些词、不知道去哪看数据、不知道怎么点。操盘手先用大白话讲清楚，再问；每个问题都告诉他在哪看、看不懂怎么办；他答不上来就按推荐的默认做法走，并说明为什么。不要甩一串术语让他选。

本篇给方法、方案、操作步骤和复盘。建计划、充值、改预算由用户本人在手机或后台操作，操盘手一步一步教；用户明确授权且工具能操作时，也先列出完整变更清单再执行，执行后回读后台确认实际状态。平台规则以[投流规则核查快照](snapshots/paid-traffic-platform-check-2026-10-25.md)为起点，平台调性见[平台调性](platform-tonality.md)。

## 一、先教：投流是什么、三种目标怎么选

先发给老板一段这样的说明（按他的平台和行业换例子，不照抄）：

> 投流就是花钱让平台把你的视频多推给一些人看。花钱之前要先想清楚：这次花钱，到底想要什么。一般就三种：
> 1. **纯曝光**：让更多对的人看到你、关注你、点进你的主页。适合刚起号、想先把名气和门面做起来。
> 2. **获客**：让人来私信你、留电话、加你微信。适合已经有人在评论里问“怎么做”“多少钱”，而且你有人能马上回复。
> 3. **卖货**：让人点商品、直接下单。适合视频挂了商品或者开了小店。
>
> 不同平台适合的也不一样：视频号来的多是熟人，起号时可以先花点小钱把播放、点赞、关注做得好看一点，像把名片印体面；抖音来的多是陌生人，先靠选题让陌生人愿意看，自然流量好的那条再花钱放大；小红书是大家搜索找参考的地方，先发几篇，挑数据最好的一篇再加热。

讲完再问，不要一上来就问“你要哪种目标”。

## 二、再问：一条消息问完，能语音回答

先查客户目录里的定位档案、已采纳规则和以前的投流记录，已经知道的不再问，只问缺的。每个问题后面附“在哪看”和“不知道怎么办”。

1. **这次想要哪一种？** 纯曝光、获客，还是卖货，选一个最想要的。
   - 不知道怎么选：视频号刚起号，默认选纯曝光；抖音、小红书还没跑过自然流量的，先不投，我陪你挑一条好的再说。
2. **想给哪条视频（或笔记、直播）花钱？** 把这条发给我，或者告诉我标题。
   - 在哪看这条的数据：视频号在“视频号助手”或手机上视频号的“创作者中心”里看这条的播放、点赞、转发、关注；抖音在“创作者服务中心”或这条视频的“数据分析”里看播放、完播率、新增粉丝；小红书在“创作中心”的“笔记数据”里看阅读、点赞收藏、涨粉。看不懂就截图发我，我帮你看。
   - 不知道选哪条：把最近5到10条的数据截图发我，我帮你挑。
3. **这一轮最多花多少钱？花到多少还没效果就停？**
   - 不知道花多少：第一次建议先拿一两百元试，按平台最低起投金额来，不够再加；亏损上限默认就是这笔试的钱。
4. **在哪个平台投？**（视频号、抖音、小红书）有没有做企业认证、开过广告账户？
   - 不知道有没有：个人号也能投视频号加热、DOU+、薯条，不需要广告账户；要投表单留资、加企业微信这类，才需要企业认证和广告账户，到时候我再教你开。
5. **选了获客才问：谁来接？** 有人私信或加你微信时，谁回复、多快能回、回完下一步做什么（发资料、约时间、报价）？
   - 没想好：先别投获客，没人接的话钱就白花了，先按纯曝光投。
6. **选了卖货才问：** 这个商品卖多少钱、每卖一单大概赚多少、退货多不多？
   - 不清楚：先按售价和你估的利润算，我会标成估算，跑一周再用真实数据改。

老板只答了一部分，就按“不知道怎么办”的默认做法补上，告诉他补了什么，然后往下走。

按铁律直接指出的几种情况（说一次，老板坚持就按他的来）：
- 抖音、小红书上，自然数据明显低于账号平时水平，还想花钱救（视频号起号期为门面数据小额加热不算在内）；
- 选获客但没人接、接了也没有下一步；
- 账号定位是“纯曝光、不卖东西”，却想投私信或留资；
- 预算只够测一条，却想同时测好几样。

确认后，把目标、预算上限、止损线、观察时间写进客户目录的投流记录，作为这一轮的约定。

## 三、目标定了，用什么、看什么

| 目标 | 视频号 | 抖音 | 小红书 | 主要看 | 只作参考 |
|---|---|---|---|---|---|
| 纯曝光 | 视频号加热（微信豆），目标选关注、点赞评论或播放 | DOU+，目标选粉丝或点赞评论 | 薯条，目标选涨粉、点赞收藏或阅读 | 单个新增关注成本、新粉里目标人群的比例、带具体问题的评论、主页访问、收藏转发 | 总播放量 |
| 获客 | 腾讯广告（要企业认证和广告账户）的表单留资、加企业微信；企业微信获客助手的视频号组件（有行业限制） | DOU+商家目标里的私信或获取客户（以投放页实际选项为准）；巨量本地推的私信、表单 | 聚光（企业广告平台） | 单个有效线索成本、回复速度、线索到成交的比例 | 私信总数 |
| 卖货 | 带商品视频的加热，目标选商品点击或成交；微信小店相关投放 | 巨量千川（抖店卖货） | 电商相关投放（以小红书当期产品为准） | 保本投产比、扣掉退款后还剩多少 | 支付金额本身 |

入口、目标选项和起投金额以投放当天手机上显示为准；快照里标“待核”的，不当规则讲。

## 四、按平台：什么时候投、怎么投（手把手）

### 视频号：起号可以先把门面做好看

**为什么**：视频号来的多是熟人，熟人和新客户会点进主页看你，播放和点赞太少会让人觉得“没人看”。起号期花小钱把门面数据做起来是合理的；之后按每条视频的质量慢慢调整，好内容再加热放大。

**怎么投**（大致路径，以手机上实际显示为准）：
1. 打开微信 → 我 → 视频号 → 创作者中心，找到“加热工具”；或者打开自己发的那条视频，找“加热”或“上热门”。
2. 选要加热的视频。
3. 选目标：起号做门面，选“关注”或“点赞评论”；只想多点人看，选“播放”。
4. 选人群：第一次选系统智能推荐；客户集中在某个城市或年龄段，再用定向。
5. 选金额：短视频单笔500微信豆起，按500的倍数加（第三方转述官方说法，以页面为准）。第一次用最低档试。
6. 付款后等审核，一般约20分钟。
7. 投完看：新增几个关注、每个关注花了多少钱、评论里有没有目标客户在问问题。

**边界**（说一次）：加热买的是曝光，买不来内容质量；复盘时把加热带来的数据和自然数据分开看；门面做起来以后，回到“好内容再加热”。

### 抖音：先靠选题跑自然流，好的再投

**为什么**：抖音来的多是陌生人，按兴趣推荐。起号期先用陌生客户关心的选题把自然流量跑出来，花钱救不了陌生人不想看的内容。

**什么时候投**：这条的开头留存、完播率、新增粉丝明显高于账号平时，评论里有人在问具体问题，再投。

**怎么投**（大致路径，以手机上实际显示为准）：
1. 打开抖音 → 我 → 点开要投的那条视频 → 右下角“…” → “上热门”（就是DOU+）。
2. 第一次建议用定向版，人群先选系统智能推荐；有明确的地区或人群，再选自定义。
3. 目标：做IP、要涨粉，选“粉丝量”；想先看大家反应，选“点赞评论量”。商家号有私信、获取客户等目标时，选获客要先确认有人接。
4. 时长：先选能覆盖你客户活跃时段的时长，一般6到24小时。
5. 金额：先用最低档或接近最低档试。
6. 投完看：每个新增粉丝花了多少钱，跟账号平时比；成本低的追投，成本高的停。

**注意**：促销优惠、引导加群下载、承诺效果的素材，DOU+内容加热一般不过审。

### 小红书：先发几篇，挑最好的一篇加热

**为什么**：小红书是大家搜索找参考、种草的地方，笔记能被搜到、被收藏，才有长尾流量。没跑过自然流量就投，钱花在没人想收藏的内容上。

**什么时候投**：同一方向发满几篇（常见建议是5篇左右），挑点击、收藏最好的一篇投。

**怎么投**（第三方2026年5月教程，以手机上实际显示为准）：
1. 打开小红书 → 我 → 点开要投的笔记 → 右上角图标 → “薯条推广”；也可以从 我 → 左上角 → 创作中心 → 薯条推广 进去。
2. 选目标：阅读量、点赞收藏量或粉丝关注量。做种草选点赞收藏，做IP选涨粉。
3. 选人群：智能推荐，或者自己设性别、年龄、地域、兴趣。
4. 选金额和时长：有教程写最低75元；金额小就选短一点的时长（比如6小时），放在客户活跃的时段。
5. 只能投近90天发的笔记（第三方说法，以页面为准）。
6. 投完看：点击、收藏、涨粉的成本，跟其他笔记比。

企业要做规模化，再用聚光，需要企业资质。

## 五、测：挑哪条投

- 抖音、小红书：只把已经跑过一轮自然流量、数据高于账号平均的内容放进投流池。
- 视频号：起号期可以给质量过得去的视频小额加热做门面；起号后同样挑数据好的加热。
- 用本账号自己的平均值当及格线，不套网上的万能数字。
- 视频本身有发布阻断项（事实错误、隐私、未标注的AI画面、夸大承诺）的，先改再投，按[成片评分教练](pre-publish-review.md)排查。

## 六、放：小额测，赢了再加

1. **先写边界再花钱**：本轮总预算上限、可承受损失、每条起投金额、观察时间、达标线和止损线。预算是上限，不是必须花完。
2. **一次只改一样**：同一条视频比两种目标，或同一目标比两条视频，或同一视频比两种人群，三选一。几样一起换，结果说不清原因。
3. **小额起投**：先按平台最低档或接近最低档测；金额建议标为“估算”，按客户自己的数据替换。
4. **样本不够只能叫“暂定”**：花费或结果太少时，结论写“暂定，需再测”，不为了凑样本无限加钱。
5. **追投条件**：单个关注或线索的成本在止损线以内、观察时间内没有明显变贵、承接还接得住，再追投。追投前写原值、新值和理由。
6. **花不出去先查原因**：审核、余额、时段、人群是不是圈得太窄，再看素材；不因为一小时没花出去就推倒重来。

每条动作按“对象→证据→动作和金额→预算或损失边界→观察时间→达标或停止条件→什么时候复查”写清。

## 七、接：接不住，投多少都白投

- **纯曝光**：主页简介、置顶视频和关注理由说清“关注你能得到什么”；投完要有下一条内容接住新来的人。视频号还要发朋友圈、客户群，让熟人圈接着转。
- **获客**：私信和加微信要有人接，回复越快越好，夜间可用平台客服或自动回复兜底，但要真人跟进。话术按客户自己的业务写：先回答对方问的，再问一两个判断需求的问题，再给下一步（看案例、约时间、发资料）。不编客户案例和效果数字，不承诺结果。
- **卖货**：价格、优惠、库存、发货、详情页和客服都要和视频里说的一致。

## 八、复：每周一次，只说数据看得到的

- 核对口径：时间、平台、计划、花费、结果是不是同一批；账户、计划、单条视频的成交可能重叠，不直接相加。
- 关掉成本超过止损线的；把赢的那条拆开：开头、选题、结构、封面，各自再拍一两条同类，进下一轮测。
- 只写数据呈现的事实，原因解释不了就写“待验证”；不把投流后的自然流量变化全算成投流带来的。
- 把加热带来的数据和自然数据分开记，判断内容好坏看自然数据。
- 用户采纳的投流规矩按[客户建议与沿用](client-learning.md)存进客户目录，下一轮直接用；内容本身的问题按[视频数据复盘](video-performance-review.md)查。

## 九、算账：按目标算，不混着算

- **纯曝光**：看单个新增关注成本和单个目标评论成本。上限按“这一轮愿意为多少个对的人花多少钱”定，不硬套投产比。
- **获客**：可承受的单个线索成本 = 每成交一单的毛利 × 线索到成交的比例。示例：每单毛利1000元、10条线索成交1单，单个线索成本保本上限是100元，想留利润就控制在更低。前两周先拿真实数据算出自己的成交比例，再定成本线。
- **卖货**：保本投产比 = 支付金额 ÷ 广告前贡献（扣掉退款、商品成本、运费、平台费后剩下的）；贡献小于等于零时，投多少都不赚钱。

所有金额都是示例，按客户自己的数据替换，并标明哪些是估算。

## 十、投之前过一遍合规

- **不承诺效果和收益**：“保证涨粉”“学完业绩翻倍”“投一百回一千”都不能说。教育培训广告不得对培训效果作保证性承诺。
- **不用绝对化用语**：“最”“第一”“国家级”这类，用具体事实代替。
- **不编案例**：客户案例、收入、前后对比必须真实可查，留好授权；限量、限时必须真实。
- **AI内容要标**：用AI生成或合成的画面、声音，发布时主动声明并按平台要求标注，不删改平台加的标识。
- **抖音内容加热不接营销内容**：促销优惠、引导下载、加群、点头像、去第三方平台的，DOU+内容加热一般不过；医疗、金融、加盟创业等行业不接。
- **授权**：用到别人的肖像、音乐、影视片段，先有授权。
- **前后一致**：视频开头、标题和落地页（表单、主页、商品页）说的是同一件事。

## 十一、交付什么

按需选，不全部堆给用户：
1. 一句话结论放最前面：这条投不投、在哪投、投多少、看什么、什么时候停。
2. 手把手操作步骤：按他的平台写，从打开手机哪个页面开始。
3. 投前确认卡、投放方案、盯盘表和周复盘表：见[投流工作表](../assets/paid-traffic-workbook.md)。

## 什么时候要重新核平台规则

出完整投流方案、客户问“现在规则是什么”、手机上显示和快照不一致、或者快照超过一个月时，按[平台核查与定期更新](platform-research.md)重新查当期官方说明，并把核对日期写进方案。查不到官方原文的，标“待核”，让用户以投放页为准。
