# 文案交付：拍摄版和纯文字版

用于每次写新稿、改稿、对标改写和平台改版。**每条文案都交两份**：一份拍摄版，拍之前看；一份纯文字版，直接整段复制进提词器（拍的时候在镜头旁边滚动显示稿子的软件）。两份的口播内容一字不差，只是给的东西不一样。

## 第一份：拍摄版

照[现场提问与提示卡](on-set-interview.md)、[口播与Vlog结构](script-structures.md)和[开头、结构与封面配合](opening-and-structure.md)写，包括：

1. 完整口播稿，第1秒是什么画面写在最前面
2. 要准备的东西和画面提示（放在括号里，跟口播分开）
3. 现场提问卡或独自录制的提示卡，一段一段对上
4. 开头检查：第一句是不是画面或冲突、答案在第几句说出来、封面字和开头有没有重复
5. 适合哪个平台，标题和封面字可以等拍完再出

## 第二份：纯文字版（提词器用）

只留要念出来的话，照下面7条：

1. **跟拍摄版的口播一字不差。** 改了拍摄版，纯文字版跟着改；不许两份各说各的。
2. **全部去掉**：标题、编号、时间、画面提示、括号里的动作说明、屏幕上要出的字、提示卡、开头检查，还有 #、*、-、表格、引用符号和表情符号。
3. **一段一个意思**，段和段之间空一行；一段两三句，别太长，提词器上好翻。
4. **数字和符号写成念出来的样子**：43%写成“百分之四十三”，2026年写成“二零二六年”，3·15写成“三一五”。AI、IP这类本来就这么念的照写。
5. **不放进代码框和表格**，手机上会乱，也不好复制。
6. **用两行标记夹住**，用户从上面那行的下一行复制到下面那行为止：

   ```
   ▼ 纯文字版（约320字），从下一行开始复制到提词器
   ……要念的话……
   ▲ 复制到这里为止
   ```

   上面加框只是示范格式，交给用户时不放进框里。字数写在上面那行；老板的[表达档案](transcript-and-voice.md)里有实测语速，再加一句“念完约几秒”，没测过就只写字数，不估秒数。
7. **能存文件就另存一份**：在老板资料文件夹的“稿件”里存一个文字文件，名字写成“日期-标题-提词器.txt”，告诉他存在哪。存不了文件就只给对话里这一份。

## 放的顺序

一条回复里按这个顺序放：拍摄版 → 纯文字版（两行标记夹住）→ 下一步（按[铁律三](../SKILL.md)）。下一步写在标记外面，免得被一起复制进提词器。

一次写多条时，每条都是“拍摄版＋纯文字版”一组，编号对上；不要把几条的纯文字版拼成一大段。

## 改稿

- 老板改了哪句，两份都改；纯文字版每次都整份重出，不只给改动的那一句，因为他要整段复制。
- 老板自己发来改过的稿，先按他的改法更新表达档案（见[客户建议与沿用](client-learning.md)），再出两份。
- 只改了画面或提问卡、口播没动时，纯文字版不用重出，说一句“口播没改，纯文字版用上一份就行”。

## 交付前核对

- 两份都在，口播逐句一致
- 纯文字版里没有任何画面提示、括号、符号和标题
- 数字都写成了念法
- 下一步放在纯文字版的标记外面
