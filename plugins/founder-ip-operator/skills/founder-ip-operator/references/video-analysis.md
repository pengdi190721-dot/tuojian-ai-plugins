# 视频解析

本篇只供技能内部路由使用。对用户统一说“正在解析视频”，不要让用户选择转写模型、抽帧密度、识别语言或命令参数。对标拆解、剪辑包装、成片评分和视频复盘都靠这一步拿到转写、关键画面和时间线。

## 输入优先级

1. 本人原始视频或清晰导出文件，使用绝对路径。
2. 抖音分享链接或整段分享口令：先用 `scripts/fetch_video.py` 免登录下载成本地文件，再解析（见下文“发来链接时”）。
3. 视频号分享链接：本机装了视频号下载器时走下载器，没有就请用户录屏发文件（见下文）。
4. 其他平台的单条公开视频链接：本机有 yt-dlp 时下载后解析。
5. 转写、截图或压缩视频只能做降级分析，必须说明缺了什么。

聊天软件压缩可能改变清晰度、音量和字幕可读性；评分时注明收到的是原片还是压缩版。

## 内部执行顺序

1. 以插件方式安装时，优先调用插件自带的 `video-analyzer` 工具：完整审片用 `analyze_video` 的详细模式；只缺某个时间点的证据时用 `analyze_moment` 或 `get_frame_at`。
2. 工具返回的转写为空，但本地视频有声音时，运行本技能的 `scripts/analyze_video.py` 补做本地转写并合并结果。
3. 以独立技能方式安装（没有 `video-analyzer` 工具），但本机有 Python、Node.js 22.12 以上和 npx 时，直接运行同一脚本完成本地解析：

   ```bash
   python3 scripts/analyze_video.py 视频绝对路径 --detail standard --json-output 输出路径.json
   ```

4. 仍不可用时，用当前环境已有的媒体读取、FFmpeg、转写或看图能力。
5. 最后才降级为用户提供的转写和截图。降级分析不能称为完整审片。

默认使用本地语音识别，不向用户要任何付费接口密钥。第一次转写会按需联网下载本地识别组件，以后复用缓存，需要提前告诉用户可能要等一会儿。不得为了方便把视频自动发到未说明的第三方视频理解服务。环境是否就绪用[环境体检](environment-check.md)查。

## 每次记录完整度

- 是否取得完整或分段转写
- 是否取得关键画面和时间码
- 是否取得时长、尺寸、编码和音轨信息
- 是否有下载失败、无字幕、静音、画面缺失或识别不确定

## 发来链接时

用户发来的常是整段分享口令（“复制打开抖音，看看……”加一串链接），整段原样交给脚本即可：

```bash
python3 scripts/fetch_video.py "整段分享口令或链接" --analyze --json-output 输出路径.json
```

- **抖音**：脚本打开作品的公开分享页，读出标题文案、作者、时长、点赞评论收藏分享数，下载不带水印的视频，再交给本地解析出转写和关键画面。不需要登录、不要密钥。图文作品会把每张图存下来，直接看图。作品删除、仅自己可见或平台改版时会报错，请用户改为上传文件。电脑开着代理或VPN软件的全局模式、出口在境外时，抖音只给空页面，脚本里绕不过：请用户把软件切到按规则分流（国内网站直连），或给 douyin.com、iesdouyin.com、douyinvod.com、douyinpic.com 加直连规则。
- **视频号**：视频号链接只能在微信里打开，网页拿不到视频。脚本会先看本机有没有在运行开源的视频号下载器（wx_channels_download，默认地址 127.0.0.1:2022，且电脑版微信里的视频号页面开着）：
  - 有：用下载器提供的 MCP 工具，先 `fetch_content` 解析链接，再 `download_content` 存成本地文件，然后对文件运行 `analyze_video.py`。下载器第一次使用要以管理员身份运行、安装它自带的证书，并让电脑的网络经过它，这是用户自己的决定，操盘手只说明代价，不代为安装，也不改系统设置。
  - 没有：请用户在手机上打开视频，用手机自带的录屏录下来，把视频文件发过来。录屏会带进状态栏和通知，解析时注明“录屏版”。
- **其他平台**：本机有 yt-dlp 时脚本会尝试下载；需要登录的平台失败时请用户上传文件。

公开平台链接受登录、地区、反爬和版权限制。需要账号或 Cookie 时，先请用户改为上传本人有权使用的本地文件；未经明确授权不得读取浏览器凭据。下载的视频只用于本次拆解学习，不转发、不搬运。

## 证据边界

- 抽帧只能证明抽到的那几个时刻，不能断言整条视频都如此。
- 自动转写里的专有名词、数字和人名必须回听，或标注不确定。
- 只描述可观察的语速、停顿、镜头朝向、表情和姿态，不做心理诊断。
- 对标视频只提取结构和表现规律，不输出大段原文，不帮人冒充原作者。
