# 对标视频拆解改写

用于用户上传或发来对标视频、单条视频链接（链接一律存进得到大脑读文字稿，见[读视频链接：得到大脑](knowledge-base-getnote.md)；要看画面就请用户发视频文件），要学别人的结构和节奏，改成当前老板自己的原创版本，或建立对标素材库。只迁移结构、节奏和镜头逻辑；对方的身份、经历、案例事实、原句、口头禅和标志性表达一律不搬。

## 开始前

1. 读取当前老板的定位档案、人物与表达档案和已采纳的写稿规则。没有定位档案时先按[第一次使用](first-use-positioning.md)出定位；表达素材不够时可以先做结构版改写，但标明“本人表达待校准”，不能假称已经像本人。
2. 按[视频解析](video-analysis.md)实际读取视频，取得转写、关键画面、时间线和公开信息，并记录已看范围。读取不了就如实说明，不凭标题或文件名“看懂”视频。

## 1. 先判断值不值得学

- 观众是否和这位老板要成交的客户相近。
- 视频在做获客、建立信任、展示案例，还是纯娱乐。
- 优势来自结构和表达，还是来自名人身份、稀缺场景和高成本制作。
- 老板手里有没有真实素材承接同一结构。

播放、点赞、评论、收藏只当线索，不把单个数字当内容质量。拿不到数据就写“无法核实”，不补造。

## 2. 按时间码拆解

| 时间码 | 对方在做什么 | 观众此时得到什么 | 口播与情绪变化 | 画面与剪辑动作 | 可迁移程度 |
|---|---|---|---|---|---|
| 00:00—00:03 | | | | | 高／中／低 |

重点看：

1. 第一条信息出现在第几秒。
2. 开头用的是结果、冲突、反常识、身份、场景还是直接提问。
3. 每隔多久加一个新信息、证据或画面变化。
4. 哪些停顿、表情和镜头变化在承担强调。
5. 结尾要观众做什么，是否和前面给的价值一致。

同时按时间列出对方的观点，逐条写和当前老板合不合适、为什么。

## 3. 能借和不能借

可以借：

- 信息顺序、段落功能、冲突推进和证明方式。
- 快慢变化、停顿位置、镜头类型和字幕层级。
- 先给结果再解释、先展示现场再复盘这类叙事方法。
- 开头、期待制造、举例、转场、换画面的具体写法。从中推荐2到3项，写清怎么换成本人真实内容。

不能借：

- 对方的身份、经历、成绩、客户案例、数据和观点归属。
- 连续长句、独特比喻、口头禅、标志性动作和高度可辨认的镜头组合。
- 未经核实的数字，以及当前老板的产品、经验和证据撑不起来的承诺。

## 4. 改写

先写一句“这条结构为什么适合这位老板”，再做三次替换：

1. 把对方的观众换成这位老板的目标客户。
2. 把对方的证据换成这位老板的真实经历、案例、现场或演示。
3. 把表现方式调到这位老板的语速、句长、常用词和拍摄条件。

改完反向比较：删掉人名和行业后，如果还像逐句翻写，继续换角度、顺序或案例。新稿照常按[开头、结构与封面配合](opening-and-structure.md)检查，并配套[现场提问或提示卡](on-set-interview.md)。

## 固定交付

1. 值不值得学：结论、适配度、依据和数据缺口。
2. 时间码拆解表：对方每一段在完成什么任务。
3. 观点适配表、可以借和不能借的清单。
4. “对标结构 → 本人真实素材”映射表。
5. 原创稿：开头、正文、收尾，标预计时长，附提问卡。
6. 拍摄与剪辑清单。
7. 原创差异自检，以及还要本人确认的事实。

可复用的结论按[对标卡模板](../assets/benchmark-card.md)存进当前客户目录（默认“客户资料／客户代号／对标卡.md”），不写进技能目录。用户同时给了自己的成片和对标视频时，先拆对标，再按[成片评分教练](pre-publish-review.md)比较“学到了什么、丢了哪些本人特点”，不只比像不像。
