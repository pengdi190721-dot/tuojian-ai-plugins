# 选题调研与事实核验

用于写稿前查来源、验证观点、找案例、拆公开讨论，或用户要一份研究简报。只加工用户已经给的资料、不需要联网时，不必单独走这一步。平台规则和分发机制的核查走[平台核查与定期更新](platform-research.md)，本篇管的是单个选题里的事实和说法。

## 工作方式

1. 先写清这条稿子需要证实的两三个关键问题，不做无边界搜索。
2. 实际使用当前可用的联网工具检索；需要多平台时先确认渠道真的能用，不能把未激活的渠道说成查过。
3. 优先原始来源：官方文件、原始数据、论文、项目仓库、当事人原文。
4. 记录直接支持结论的原始页面链接和日期，不只留搜索结果页。
5. 发现和原观点相反的证据，必须保留，不能为了好写删掉。

## 来源优先级

1. 官方文件、原始数据、项目仓库、论文和当事人原文。
2. 有明确作者、日期和引用链的专业媒体。
3. 平台公开内容和评论，只代表样本观察。
4. 聚合摘要只用来发现线索，不能当关键结论的唯一来源。

## 四种标记

- **已验证**：来源直接支持。
- **样本观察**：来自有限的平台样本。
- **推断**：结合多条信息得出的解释。
- **待核实**：目前证据不足。

涉及效果、金额、客户评价、合作和“已经落地”的功能，必须拿到真实材料确认。报道里只有个别商家在做的事，稿子里不能说成“大家都在做”。

## 研究简报

交给写稿用，篇幅随选题调整：

- 核心结论（每条带标记）
- 来源和日期
- 反方证据或限制条件
- 这位老板可以切入的角度
- 可以说的和不能说的
- 还缺的真实素材，由谁补

老板本人的经历和公司数据不靠联网核实，按[逐字稿与表达规范](transcript-and-voice.md)标本人自述或待核验。
