# 九式封面

用于做视频号、抖音、小红书、公众号等中文封面，换封面风格，用真人照片出封面，或评审封面。目标是交付能直接发布的成品，不只给提示词。封面必须建立在老板的真实素材上，不虚构人物、客户证明、数据、平台界面或品牌标识。只要封面字、不要画面时，按[开头、结构与封面配合](opening-and-structure.md)出封面字即可。封面按[平台调性](platform-tonality.md)定方向：视频号像一张体面的名片，熟人点进主页先看它；抖音主页格子要统一好认；小红书封面和标题决定点不点，封面字写清解决什么问题、放用户会搜的词。

## 开始前

1. 读取用户已给的标题、文案、图片、平台和风格偏好，不重复问。
2. 读取[九种封面风格](cover-styles.md)。用户没选风格时，用九张参考图和名称让他选一个编号；界面看不到图时说明限制并给名称，不假装用户已经看见。参考图只用来选视觉语言。
3. 只有文案、没有封面字时，先给三个不同角度的主标题，每条四到十四个字，让用户选或改。封面字和视频开头一起定：封面提出的问题，开头要尽快回答；开头不重复封面那句话。
4. 要真人出镜时，至少要一张清晰主图；用户明确要纯图形封面时可以不要。附图最多三张，只用用户提供的产品图、案例图、截图或标志。没有单独照片时，可以从本人视频里挑一帧：选没有烧录字幕、表情自然、眼睛睁开的画面。

## 一次确认清楚

缺少会明显改变成图的信息时，只发一张“封面确认单”，把缺项合在一条消息里，不拆成多轮：

- 风格：九种之一，或交给系统决定
- 比例：九比十六、三比四、四比三、十六比九、一比一，或交给系统决定
- 人物表现：捂嘴惊讶、张嘴震惊、开心大笑、兴奋雀跃、自信得意、托腮思考、推荐种草、认真讲解、指向标题、沉思判断、自然微笑，或自定义
- 字体：超粗黑体、柔和圆体、手写涂鸦体、极简无衬线、复古宋体，或交给系统决定
- 背景：浅色、深色、暖色、冷色、高饱和撞色，或交给系统决定
- 副标题：按主标题给三个四到十字的候选，可选一个、多个、全选、都不要或自己改

用户说“直接生成”“你来定”时，系统补全所有未选项，不再追问。按发布场景选比例，不明确时优先三比四；竖版视频可以同时出九比十六和三比四两张，主要内容放在两种比例都不会被裁掉的中间区域；各平台主页和分享卡片实际用什么比例，以当期发表页为准。

## 生成规则

1. 一次只用一种风格，不混搭。
2. 主标题原样、完整、清楚地写进画面；只加用户选中的副标题。
3. 层级默认是：主标题第一、主图第二、副标题第三、附图第四。一张封面只有一个第一注意力。
4. 从文案里提取一到四个具体名词、工具、场景或比方，做成物件、插画、卡片或装饰界面；文案里没有依据的元素不加。
5. 中文必须可辨认，不出现乱码、伪文字、拼音替代或无意义外文。
6. 不生成二维码、关注按钮、虚假点赞评论、价格、统计数据、客户评价或用户没提供的标志。
7. 文字、人物和关键元素避开平台裁切区和字幕区，不贴边，人物不挡主标题。

## 真人还原

- 默认严格还原身份：脸型、五官比例、眼睛、鼻子、嘴型、发际线、肤色、年龄感、眼镜和标志性配饰优先保持。
- 只改用户指定的表情、视线和动作，不擅自美颜、换脸、改年轻、改发型，不生成“像但不是本人”的新脸。
- 优先用图像编辑方式保留原图人物，只生成背景、文字和配图元素。没有图像生成工具时，可以用原图或视频截帧加网页排版直接出图，人物完全不重绘。
- 第一次不像本人时，降低人物重绘程度直接重试；连续两次仍不像，再请用户补一到三张正面或侧面清晰照片。
- 不默认克隆或改动他人肖像；用别人照片前确认有使用授权。

## 生成与重试

调用当前可用的图像生成或编辑工具，按这个顺序组织生成要求：

1. 输出比例、像素和发布平台。
2. 所选风格的版式、字体、配色和装饰。
3. 主图位置、主体保持、人物身份与动作。
4. 主标题原文和分行方式。
5. 副标题原文与位置。
6. 附图编号、用途与位置。
7. 语义配图元素、数量和位置。
8. 安全区、可读性和禁止项。

文字错、比例错或人物失真时，保留已确认的选择直接重试，不让用户从头再选。

## 交付前验收

- 一秒缩略图：缩到手机信息流大小，第一眼仍能说出唯一重点。
- 标题：原文完整、没有错字、没被人物或装饰挡住。
- 人物：能明确认出是本人，表情和动作符合最终选择。
- 素材：没有凭空生成截图、标志、数据、客户评价或第二个人物。
- 比例：和发布平台一致，四周留出安全区。

有一项不通过，先改再交付最终图。
