# 平台研究与更新

视频号与抖音最近一次包内核查见[2026年10月13日资料记录](snapshots/platform-research-2026-10-13.md)；小红书仍以[9月24日资料记录](snapshots/platform-research-2026-09-24.md)为历史线索。这些都不是永久有效的算法手册。[9月23日快照](snapshots/platform-research-2026-09-23.md)为历史参考。完整报告和平台策略按[三平台执行流程](platform-distribution-and-rules.md)完成核查、平台选择、内容适配、客户说明、发布复核及复盘。投流加热的规则另见[投流规则核查快照（2026年10月25日）](snapshots/paid-traffic-platform-check-2026-10-25.md)，按同样的方法定期复核。

## 需要最新结论时

1. 以当前实际日期为基准，优先核查平台协议、官方安全／创作中心及监管原文；受众资料用研究机构原报告或明确样本观察。
2. 分开记录发布日期、生效日期、查阅日期。已公布未生效的内容标为待生效；查询日在生效日之后也应再次核验有没有后续修订。
3. 将算法公开原理、平台规范、人口或内容研究、当前账号观察、运营推断分别呈现。不能将隐私政策的信息收集范围推导为精确排序权重。
4. 公众号或站内原文无法读取时，可用可信媒体交叉核实，明确证据等级；不把平台域名下的用户投稿当官方政策。
5. 不杜撰“初始流量池固定多少”“完播达标必增推”“点赞收藏评论固定分值”“养号多少天”等公式。
6. 登录、工具或联网不可用时，交付带日期的策略假设与待核验项，不假称已完成最新平台内调研。

## 本项目的思考维度

抖音：陌生受众发现内容时，如何迅速识别与自身有关的问题；用实物、结果或具体场景解释，保留必要因果。不得把平台等同于只能娱乐。

视频号：好友传播与算法推荐都应考虑；内容是否能帮助现有客户及同事理解业务，是否也让陌生人看懂。不得把受众简化为单一年龄群。

小红书：可测试具体任务、搜索问题、经验比较与收藏场景，使用客户实际语言组织封面和信息。不得把整体平台调性直接等同于某个行业的客户密度。

以上为选题实验方向，不是固定算法法则。主平台由客群、已有渠道、服务目标和资源决定，不默认所有老板都用视频号。

## 视频号与抖音的定期更新

仅在用户要求定期跟踪后，使用当前环境真实可用的自动化工具创建任务并回查状态；频率、时间与时区依用户选择。没有调度工具时说明尚未建立，不以文字承诺代替执行。技能包转交给别人不会自动复制当前用户的定时任务，不能声称安装后自行联网。

周期研究存放在用户工作区“运营资料库／平台更新／”，保留日期记录并维护“最新索引.md”；索引写最近成功核查时间、覆盖来源、失败来源及其最后成功日期。客户端内的更新时间只是检索时间，不代表平台文件也在该日修订。写稿和复盘从当前工作区读取该索引，不硬编码开发者目录。尚未建库时使用本包快照作线索，并进行当次联网核查。

每轮先比较前次成功记录，再查看官方原文、创作／安全公告及近期高质量运营经验。官方以微信视频号运营规范、微信官方视频号创作与安全账号、抖音安全与信任中心、社区及规则中心为入口；账号站内通知由用户提供。监管原文作为补充，不能冒充平台新增公告。第三方媒体域名即便属于腾讯，也不等于微信官方来源。

运营经验优先原作者、原始访谈或具体项目复盘，记录作者、发布时间、行业、账号阶段、自然／付费、内容／直播、操作过程、样本和是否提供可核对的数据。近期优先搜索近90天，找不到可靠资料可扩展至一年，长期方法保留实际旧日期；这些窗口是检索策略，不是平台有效期。只读到搜索摘要算候选，打不开原文就标未核验。流量高、头衔大、声称最新都不是证据等级。

把官方规则、算法公开原理、运营经验、当前账号观察与本次实验假设分开。给每条经验写“可借鉴的具体动作、适用条件、不可外推的部分、怎样用当前账号验证”；自然口播不能直接套直播电商或广告投放结论。多个网站转载同一篇不算多来源证据；样本与作者收益只记自述，未独立核实不写为已验证成效。来源间矛盾先查时间与范围，不能投票取多数。

每轮只记录会影响判断的差异、待核验缺口及少量有价值的候选实验；没有可靠新发现可以为空，不凑数量，不把旧页面重新抓取包装成新规则。未经证据支持的固定流量比例、统一完播阈值、所谓权重公式或包涨粉做法不进入复盘标准。页面超时、登录或验证受限，停止绕过并保留最后成功日期，只降低相关结论，不阻断其他已读取资料。

研究结果可更新公共依据库，不能自动写入客户“已采纳”规则。新官方依据与旧建议冲突时，指出具体影响并在当前任务避免继续使用不适用方案；客户的偏好修改仍按[采纳与沿用](client-learning.md)处理。

## 每次正式复盘的时效检查

检查最新索引并打开与本次建议直接相关的官方页面；同一会话已成功核查且无新变更信号的来源可以复用，注明时间。遇处罚提示、界面变动、标识要求、经营场景切换或用户要求最新时，重新核查对应公告。周期研究不能替代任务当次核查，单次打开页面也不能宣称已覆盖全平台新规。无法联网时如实提供受限复盘，清楚区分仍能判断的数据与暂不能核验的规则。
