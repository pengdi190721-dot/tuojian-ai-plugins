# 读视频链接：得到大脑（原 Get 笔记）

**用户发来的视频链接，一律走得到大脑读。** 不再自己去抖音分享页下载，也不用视频号下载器、代理分流这些办法，实际用下来基本走不通。

得到大脑是得到出的笔记软件：把视频链接存进去，它会自动转成带分段的文字稿；连上以后，操盘手能帮老板存链接、搜和读里面的东西。

## 第一次用：直接把链接给他

用户第一次发视频链接、而得到大脑还没连上时，不讲原理、不列别的办法，直接这样说（按他的情况改字，别改意思）：

> 读视频链接要用得到大脑。先点这里注册或登录（微信或手机号就行）：https://www.biji.com
> 读链接要开得到大脑会员，在这里开：https://www.biji.com/checkout ，价格以页面上写的为准。
> 弄好了跟我说一声“帮我连上得到大脑”，剩下的我带你一步一步弄。

- 手机上想装 App：在应用市场搜“得到大脑”；电脑版在 https://www.biji.com/download 。不装 App 也行，网页版能用。
- 不替用户注册、不替他付钱、不替他点确认，这三件都要他本人来。
- 他暂时不想开会员：照实说读不了链接，请他把视频文件直接发过来（抖音里点“保存到相册”，或者用手机自带的录屏），本地照样能读文字和画面。别的功能都不受影响。

第一次做完IP定位时，在定位后面顺带加一句：“以后想发链接让我读别人的视频，先在这里注册或登录得到大脑：https://www.biji.com 。”只说这一句，不展开。

## 连上得到大脑（命令行，2026年10月29日在装了WorkBuddy的电脑上实测跑通）

前提：老板本人有得到大脑会员。命令行、MCP、开放接口官方都写着要会员账号。电脑上要有 Node.js（读视频本来就要装 22.12 以上，够用）。

```bash
npm install -g @getnote/cli
getnote auth login
```

执行后会给出一个 `https://biji.com/openapi/oauth/authorize?code=...` 链接和一个8位确认码。跟老板这样说：

> 我这边给你一个链接和一个8位码。你用手机或电脑打开链接，看看码是不是一样，一样就点确认。几分钟内要点，过期了我再发一个。

**必须老板本人点确认**，操盘手不能代点。授权成功后命令自己结束，凭证只存在老板这台电脑上。这条命令会一直等老板确认，可以放到后台跑；过期就重新执行 `getnote auth login`。

验证：

```bash
getnote auth status    # 显示 Authenticated 就连上了
getnote doctor         # 显示 READY 就全部能用
```

也能用 MCP 方式接（`npx -y @getnote/mcp`，在对话里说“请帮我授权 Get笔记”会打开浏览器登录），能跑命令的工具优先用命令行，实测最稳。

## 发来链接时怎么读

1. 用户发来的常是整段分享口令（“复制打开抖音，看看……”加一串链接）。从里面挑出那条 `https://` 链接。
2. 存进得到大脑：`getnote save "链接"`。这一步是排队处理的，要等一会儿。
3. 找到这条笔记：先 `getnote notes --limit 5` 看最新几条；找不到就按标题关键词 `getnote search "关键词" --limit 5`。
4. 读全文：`getnote note <ID> -o json`，拿到带分段小标题的逐字稿。
5. 拿到文字后照常做事：拆结构按[对标视频拆解改写](benchmark-remix.md)，看行情按[选题雷达](topic-radar.md)。

对用户只说“正在读这条视频”，不让他看命令。读出来的稿子要注明“只有文字，没有画面”。

**支持哪些链接**（以得到大脑官方说明为准）：抖音、小红书、B站的视频，公众号文章、小红书图文和普通网页。**视频号不在官方列的范围里**：用户发视频号链接时，照实说读不了，请他用手机录屏或下载后把视频文件发过来。

**要看画面时**（镜头、字幕、表情、成片打分）：得到大脑只给文字，请用户直接发视频文件，按[视频解析](video-analysis.md)在本地读。审自己的成片本来就该发原片。

**读失败时**（存了半天没出笔记、提示非会员、额度用完）：先 `getnote quota` 看用量，再 `getnote auth status` 看授权还在不在；会员过期或额度用完就照实告诉老板，并请他先发视频文件，不卡住出稿。

## 顺带能做：资料存到云端

```bash
getnote notes --all -o json
```

能把笔记、知识库、标签全部导出来。老板想把档案、素材、对标视频存到云上、换电脑也不丢时，用这个。

## 常用命令

| 要干什么 | 命令 |
|---|---|
| 存链接、文字或图片 | `getnote save <链接>` |
| 列最近的笔记 | `getnote notes --limit 10` |
| 按意思搜 | `getnote search "关键词" --limit 5 --response-mode snippet --max-snippet-chars 600` |
| 读某条笔记全文 | `getnote note <ID> -o json` |
| 列出知识库 | `getnote kbs` |
| 列出订阅的知识库 | `getnote kbs-sub` |
| 查还剩多少用量 | `getnote quota` |

注意：`notes` 的条数参数是 `--limit`，不是 `-n`（`-n` 会报错）。

## 边界与风险

- **凭证不能外泄**：授权凭证和 API Key 不写进聊天，不提交到公开仓库；走开放接口要用就放环境变量 `GETNOTE_API_KEY`、`GETNOTE_CLIENT_ID`。
- **笔记是老板自己的**：存进去、搜到的内容只用于当前任务，不跨客户引用，不把A老板的素材写进B老板的档案。
- **文字稿会听错**：得到大脑的文字稿是机器转的，人名和专有名词会错（比如把博主的名字写成同音字）。引用人名、数字、机构名之前要问老板，标“待核实”。
- **会员有用量限制**：一次读很多条之前，先 `getnote quota` 看一眼；连着存新链接，每条隔1分钟以上。
- **价格不写死**：会员价格会变，一律说“以开通页面为准”，不在稿子和聊天里报具体数。
- **别人的视频只拿来学**：读到的对标内容只学结构和节奏，不搬原话，不转发、不搬运。
