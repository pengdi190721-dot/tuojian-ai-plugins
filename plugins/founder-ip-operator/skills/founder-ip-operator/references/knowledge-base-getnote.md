# 知识库接入：得到大脑（原 Get 笔记）

这是可选功能，不装也不影响定位、选题、写稿和复盘。

## 先跟老板说清楚（大白话）

> 得到大脑是得到出的一个笔记软件，能把视频链接、文章、录音存进去，自动转成文字稿。连上以后，我能帮你搜、帮你读里面存的东西。用它要开得到大脑的会员，是要花钱的；你没有会员也没关系，不影响别的功能。

用在两件事上：

1. **抖音链接读不出来时兜底**：把链接存进得到大脑，再读出带分段的文字稿。
2. **老板的资料备份到云端**：档案、素材、对标视频存在云上，换电脑也不丢。

老板没提、也没有会员时，不主动推荐开通。

2026年10月29日在一台装了WorkBuddy的电脑上实测跑通：命令行方式，老板本人扫码确认授权，搜到存进去的抖音链接笔记并读出全文转写。

---

## 一、三种接入方式

| 方式 | 安装/地址 | 适合谁 |
|---|---|---|
| **命令行（推荐）** | `npm install -g @getnote/cli`（命令是 `getnote` 或 `gnote`） | 在 WorkBuddy 这类能跑命令的 AI 工具里用，实测最稳 |
| **MCP** | `npx -y @getnote/mcp`（要 Node.js 20 以上） | 支持 MCP 的 AI 工具 |
| **开放接口** | `https://openapi.biji.com/open/api/v1` | 公司自己的系统对接 |

前提：老板本人有得到大脑会员（命令行、MCP、开放接口都属于会员权益）。走开放接口要在 biji.com/openapi 建应用拿 Client ID 和 API Key；走命令行的授权不用手动建 Key。

---

## 二、命令行怎么授权（实测通过）

```bash
npm install -g @getnote/cli
getnote auth login
```

执行后会给出一个 `https://biji.com/openapi/oauth/authorize?code=...` 链接和一个8位确认码。

跟老板这样说：“我这边会给你一个链接和一个8位码。你用手机或电脑打开链接，核对码一样就点确认，几分钟内要点，过期了我再发一个。”**必须老板本人点确认**，操盘手不能代点。授权成功后命令自己结束，凭证只存在老板这台电脑上。

验证：

```bash
getnote auth status    # 显示 Authenticated 就成功了
getnote doctor         # 显示 READY 就全部能用
```

授权链接只管几分钟，过期就重新执行 `getnote auth login`。这条命令会一直等老板确认，可以放到后台跑。

## 三、常用命令

| 要干什么 | 命令 |
|---|---|
| 列出知识库 | `getnote kbs` |
| 列出订阅的知识库 | `getnote kbs-sub` |
| 列最近的笔记 | `getnote notes --limit 10` |
| 按意思搜 | `getnote search "关键词" --limit 5 --response-mode snippet --max-snippet-chars 600` |
| 读某条笔记全文 | `getnote note <ID> -o json` |
| 存链接、文字或图片 | `getnote save <url>` |
| 查还剩多少用量 | `getnote quota` |

注意：`notes` 的条数参数是 `--limit`，不是 `-n`（`-n` 会报错）。

## 四、两个用法

### 1. 抖音链接读不出来时兜底

先按[视频解析](video-analysis.md)“抖音读不出来时”的顺序走：先请老板把代理切到按规则分流再试；还不行、而且老板有得到大脑会员，再用这里：

1. 请老板把抖音链接**存进得到大脑**（App 里一键保存），或者跑 `getnote save <url>`
2. 等一会儿，得到大脑会抓取并生成笔记（有逐字稿、分段小标题、标签）
3. 用 `getnote search` 按标题关键词搜，再用 `getnote note <ID> -o json` 读全文

拿到的是带分段的完整文字稿，比录屏省事；但**只有文字没有画面**，要看画面还得请老板发视频文件。

### 2. 老板的资料备份到云端

```bash
getnote notes --all -o json
```

能把笔记、知识库、标签全部导出来。老板想把资料存云端、不只放在电脑里时，用这个。

## 五、边界与风险

- **凭证不能外泄**：API Key 不写进聊天，不提交到公开仓库；要用就放环境变量 `GETNOTE_API_KEY`、`GETNOTE_CLIENT_ID`。
- **笔记是老板自己的**：搜到的内容只用于当前任务，不跨客户引用，不把A老板的素材写进B老板的档案。
- **连不上不耽误事**：这是可选功能。连不上就按原来的办法（请老板发文件、录屏或口述），不卡住出稿。
- **文字稿会听错**：得到大脑的文字稿是机器转的，人名和专有名词会错（比如把知名博主的名字写成同音字）。引用人名、数字、机构名之前要回听或问老板，标“待核实”。
- **会员有用量限制**：一次读很多条之前，先 `getnote quota` 看一眼，别把用量用爆；连着存新笔记，每条隔1分钟以上。
