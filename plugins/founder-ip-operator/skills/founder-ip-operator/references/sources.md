# 方法与材料来源

此版本依据彭迪在本次任务中明确的工作方式设计：一人一档、依据逐字稿提炼本人表达、真实故事取材、纯实拍与真人＋AI 双路径、书面报告与口语文案分开，以及策划／成片交付／全案代运营三档服务。

曾阅读自媒体作战室 0.4.0 的人物表达与脚本方法；本技能已将需要的工作原则独立组织，不调用或要求安装该插件。用户身份不作为其他老板的默认身份。

AI 影像部分结合用户指定的「AI短剧导演台」0.1.0 所采用的阶段、人物参考、分镜、连续性与媒体验收方法，针对创始人真实故事重新整理为本包的独立内容。所需规则和工作表均已内置，不要求学员访问原技能、开发者路径或插件市场；未捆绑其插件程序、账号或生成服务。
