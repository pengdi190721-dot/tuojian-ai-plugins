# 选题雷达与评分

用于“今天拍什么”“这个热点要不要跟”“从业务真事里挖选题”“建选题池和内容日历”。出选题前先看行情（第0步）。沿用当前老板的定位档案、内容栏目和已采纳的写稿规则；没有定位档案且用户不知道拍什么时，先按[第一次使用](first-use-positioning.md)出定位，不直接给热点清单。只要选题、不要成稿时，不顺手写完整文案。

## 0. 出选题前先看行情

每次出新选题之前，先看清楚外面这几天在发什么，再结合老板自己的素材出题。只有改稿、或用户已经指定了题目时跳过。

**有对标时**（老板这次给了对标，或客户目录里记过对标账号）：

1. 先看每个对标最近发了什么：近14天，每个至少看5条，不够就全看。记下标题或第一句、讲的什么事、什么形式（口播、现场、录屏、混剪）、能看到的点赞评论收藏转发。
2. 怎么看：
   - 老板给了作品链接：用 `scripts/fetch_video.py` 读文字和画面，见[视频解析](video-analysis.md)。
   - 只给了账号名：用当前可用的联网搜索查"账号名＋平台"的最新作品；有能打开网页的工具就直接看账号主页。
   - 都看不到：请老板把对标最近3到5条的链接发过来（手机上点分享、复制链接）。不凭记忆说对标最近在发什么。
3. 挑出数据明显高于这个账号平时的那几条，各用一句话拆：讲的什么事、开头怎么起的、为什么能火。"为什么能火"是推断，要标出来。

**没有对标时**：

1. 联网搜同类型博主这几天在讲什么：同行业、同身份、同题材的账号，看近7天。查各平台的搜索结果和热榜、行业媒体近7天的报道、同类博主最新作品的标题。
2. 列出3到5个"这几天同类博主都在讲的点"，每个附来源和日期。查不到就如实说，不编"最近很火"。
3. 顺手记下两三个值得长期看的同类账号，问老板要不要设成对标；同意了按[客户建议与沿用](client-learning.md)记进客户目录，下次直接看。

**给老板的行情速览**（放在选题前面，五六行就够）：

- 对标或同类这几天在讲什么（附来源、日期）
- 哪条数据最好、为什么（标明是推断）
- 我们能接的：哪个点能用老板自己的真事来讲
- 不建议跟的：跟定位不符、要拿别人垫底、要编经历的

看完行情再按下面三类信号和评分出选题。对标和同类只学方向和形式，不搬对方的事、原句和身份，细拆按[对标视频拆解改写](benchmark-remix.md)。

## 1. 同时看三类信号

1. **老板自己想讲的方向**：最近有感触的事、正在做的决定、准备推进的计划。
2. **真实业务素材**：客户原话和常见问题、工作现场、交付过程、案例前后变化、本人踩过的坑。
3. **公开热点、行业变化和对标动态**：用第0步看到的行情，以及当前可用的网页搜索或热点工具（如 TrendRadar、Agent Reach）实际检索的结果，附来源和日期；工具不可用就如实说明，不凭记忆冒充最新。

热点只是信号。先判断它和老板定位、目标客户、手上真实素材有没有关系；没有真实经历时，可以做观点解读，但不能包装成亲历故事。

## 2. 评分

| 维度 | 分值 |
|---|---:|
| 是否击中目标客户的真实问题 | 30 |
| 是否符合老板长期定位和当前经营目标 | 20 |
| 是否有真实案例、现场或可靠资料 | 20 |
| 是否能表达鲜明且有边界的判断 | 20 |
| 是否有时效性或持续价值 | 10 |

- 80分以上：近期优先拍。
- 70到79分：进入储备，补素材后再拍。
- 70分以下：暂不进入拍摄队列。

分数是排序工具，不是播放预测。分数相近时，优先老板亲身经历过、能拿出现场或实物的那条。

## 3. 每个候选写清

- 一句话选题和可能的封面方向
- 目标客户的哪个问题，最好附一句客户原话
- 这位老板独有的角度，来自哪段语料、哪个故事卡或哪次现场
- 还需要补的事实、案例或画面
- 时效与风险（行业资质、夸大宣传、客户隐私、平台规则）
- 评分和建议形式：口播、现场Vlog、录屏演示或混合
- 适合哪个平台、换什么角度：按[平台调性](platform-tonality.md)，视频号讲真事和判断，抖音讲陌生人的具体问题，小红书讲能收藏、能被搜到的方法
- 和行情的关系：接的是对标或同类哪个点，还是老板自己独有、外面没人讲的

## 4. 输出

先放行情速览，再按“现在就拍／储备／不建议拍”三组给出，每组写原因。“现在就拍”的每条，附一个常规拍法和两三个创意拍法（按[创意发散](creative-ideation.md)），直接给老板看，用不用、用哪个由老板定。做月度选题或内容日历时，先对齐定位里定好的栏目和每周发几条，再排序；数量依据老板的时间、预算和素材，不套示例数字。

用户选定后再写稿；写稿时开头、结构与封面按[开头、结构与封面配合](opening-and-structure.md)检查。复盘发现某类选题持续有效或无效，按[客户建议与沿用](client-learning.md)记录，由用户决定是否写进该客户的选题规则。
