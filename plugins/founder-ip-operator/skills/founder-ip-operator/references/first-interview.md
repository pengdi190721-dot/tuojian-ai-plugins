# 创始人 IP 首次面谈必问清单

配套技能：创始人 IP 操盘手 1.4.0。保留24组访谈主题，按项目加入经营诊断追问。打印PDF为原始基础问题参考，新增诊断以本文件和诊断工作表为准。

**建议预留 90—120 分钟，共 24 组核心问题。** 目的不是一次把老板的人生问完，而是拿到足以判断方向、提炼本人表达、安排首轮拍摄的材料。

“必须问”指必须触达这个主题并记录状态；不要求所有问题当场得到确定答案。老板不愿公开、记不清或需要查资料时，分别记为“不公开”“待核实”“会后补件”。已有明确答案不重复盘问。详细故事较多时，另约补访，不为赶进度替他总结。

## 面谈节奏

- 开场与业务：约 20—25 分钟（01—08）。
- 真实经历与故事：约 30—35 分钟（09—14）。
- 本人表达采样：约 10—15 分钟（15—17）。
- 拍摄形式与公开边界：约 10—15 分钟（18—20）。
- 资源、服务与结束确认：约 20—25 分钟（21—24）。

## 把“大道理”问成真实故事：通用追问顺序

老板说“做人要诚信”，不要马上写成口号。可以顺着问：

1. “最近哪件事，让您觉得这话必须这么做？”
2. “那天具体出了什么问题？谁在场？”
3. “您当时第一步做了什么？接着呢？”
4. “您也可以不这么做，为什么最后还是这样选？”
5. “多花了什么、放弃了什么？没有钱的损失也可以说时间和麻烦。”
6. “最后实际怎么样？后来还有没有发生过？”
7. “有没有当时的物件、单据、聊天或者照片？哪部分能拿出来看？”
8. “这件事如果拍出来，有谁或哪段内容需要避开？”

以上是追问路径，不是每个故事都必须凑齐八段。本人记不清对白，就记录大意，不能让他配合编出一句戏剧化台词。

## 离场前核对：至少带回这些材料或明确补件安排

- 一项优先业务、一类优先客户和一个首要目标。
- 一份简要经历线；尽量取得三条有具体动作的故事，不足时写明补访。
- 产品解释、日常回应等自然语言样本，而不只是对“风格”的自我评价。
- 可拍场景、实物、业务过程及历史材料线索。
- 纯实拍／真人＋AI 意向、明确的公开边界与审核责任人。
- 时间、人员、预算、三档服务意向和咨询承接负责人。
- 每个重要未知项对应补件人和时间；未确定的不用勾成已完成。
