# 环境体检

用于用户要求安装检查、初始化、体检、排查某个工具为什么用不了，或确认学员电脑能不能跑整套流程。不在未获授权时自动安装系统软件或登录平台账号。

## 怎么查

在本技能目录运行：

```bash
python3 scripts/doctor.py --format markdown
```

没有 Python 时，如实说明，并直接检查当前工具能不能读文件、联网、看图和读视频。

## 怎么报告

- 先用学员听得懂的话报告三类结果：**核心策划**（访谈、定位、文案、报告，只要能读中文资料就能用）、**视频解析**（对标拆解、成片评分、视频复盘要用）、**可选增强**（热点、调研、程序化包装等外部工具）。只有排障时才展开组件名称。
- 缺少某个依赖时，说明它影响哪个环节，不把可选能力说成整个技能不能用。
- 只有用户明确要求安装时才执行安装命令；装完重新体检，确认状态确实变了。
- 平台登录、Cookie、账号授权必须由用户本人完成或明确提供；不得自行读取浏览器凭据。
- 视频解析默认走本地识别，不要付费接口密钥。第一次使用可能要联网下载本地识别组件，提前说明要等，但不让学员选模型。
- 报告文件生成用 Python 标准库，PDF 导出需要可用的浏览器或 PDF 工具；没有就交 HTML 并说明。
- 学员版优先给无代码操作，技术细节放在故障排查里。
