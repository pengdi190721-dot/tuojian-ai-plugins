# 客户正式提案（演示文稿版）

首访之后，向老板及其团队正式汇报"企业经营方向＋创始人IP方案"的演示文稿，用于面谈演示、打印或发给客户决策层。

与[报告主次与阅读顺序](report-hierarchy.md)的关系：提案是给客户看的正式主文件，讲经营判断、IP方案和推进安排；完整文案、现场提问卡、三平台机制全文、研究来源和服务范围放在配套资料（完整阅读版或附件），提案里说明在哪里查看。

## 何时使用

- 首访完成，经营方向和IP方向已有初步判断，需要向老板正式汇报
- 客户企业有多项业务或处在筹建期，需要先把经营路径讲清楚，再讲创始人IP
- 用户要"客户正式版""提案""演示文稿"

只要一条文案、一份面谈清单或一次复盘时，不使用本篇。

## 总体结构

默认六章，二十多页，按项目删并。**企业经营在前，创始人IP在后**：IP为经营目标服务。客户已有清晰经营方案、只需要IP方案时，前四章压缩为两三页"经营背景与IP任务"。

| 章 | 约页数 | 回答的问题 | 常用页面 |
|---|---|---|---|
| 01 经营方向 | 3—4 | 企业要成为什么，发展主张，阶段目标 | 发展主张（三点）、发展目标表（发展维度／重点方向／阶段成果）、企业定位大字页 |
| 02 业务架构 | 2 | 各项业务做什么、怎样相互支持，先服务谁 | 业务协同表（板块／主要任务／对其他板块的支持）、优先服务对象表（对象／需要解决的问题／建议首个接触点） |
| 03 分期运营 | 3—4 | 先做哪个试点，什么条件下推进下一步 | 首期试点（三步）、推进顺序表（方向／首期重点／进入运营前的条件）、最小运营流程（三步）、切入点表（方向／建议先做／可以验证的成果） |
| 04 合作与经营 | 2—3 | 和谁合作、怎么筛选，收入从哪里来、成立条件是什么 | 合作筛选表（合作类型／希望共同解决的问题／优先核验）、收入方向表（收入方向／付费对象与价值／成立条件）、近中远期三步 |
| 05 创始人IP | 5—7 | 创始人是谁、讲什么、每月拍什么、先拍哪几条、怎么拍、在哪个平台 | IP定位大字页、品牌内涵表（内容方向／表达内容／与事业的联系）、月度内容规划表（栏目／建议条数／选题作用）、置顶内容表（置顶主题／核心问题／准备内容）、首轮选题表（栏目／可用选题）、镜头表达与专业分工（三点）、平台选择与理由 |
| 06 推进与协作 | 4—5 | 咨询谁来接，90天怎么走，看什么判断成效，谁负责什么，怎么启动 | 咨询分类承接表（咨询类型／后续安排／建议负责人）、90天安排表（阶段／企业侧重点／IP团队重点）、成效判断表（维度／重点观察／希望回答的问题）、分工表（角色／主要职责／需要共同确认）、启动三步＋结尾大字页 |

"平台选择与理由"一页写主辅平台和选择依据；三平台机制全文按[三平台执行流程](platform-distribution-and-rules.md)放配套资料，不在提案里展开。

## 每页怎么写

以下举例均为模拟，不来自任何真实客户。


- **页眉**：章节编号和章节名，如"03 分期运营"
- **标题**：一个决策或安排，用书面语，如"首期重点：老客户回访试点"
- **副标题**：一句话交代原则或取舍，如"先用表格和人工跟进跑通流程，再决定是否购买系统"
- **主体**，三选一：
  - 三点编号页：01／02／03，每点一个小标题加两行以内说明
  - 三列表格页：表头一行，正文三到四行，每格两行以内
  - 大字页：一句定位加一句主张，用于封面、企业定位、IP定位、结尾
- **页底注意事项**：一句条件、边界或责任说明，如"首批门店按人手和交付能力确定，安装服务由合作服务商负责"
- **页脚**：客户公司名和页码
- 每页只讲一件事；内容放不下就拆页，不缩字号硬塞

## 用语与事实

- 正式书面语，称呼企业全称或简称；不用口语、感叹号和营销口号
- 不写未核实的数字、规模、收入预测和排名；收入只写"方向、付费对象、成立条件"
- 规划类用"拟议""建议""首期""条件成熟后再评估"，不把筹划写成已建成
- 客户亲口定下的方向（例如回避某个行业标签）全文遵守，配图说明也不例外
- 示意图片标"概念示意，非项目实景"；不用虚构的人物肖像冒充客户
- 涉及医疗、金融、教育等内容，写明由具备资质的专业机构提供或审核
- 成效以经营和信任信号为主，播放量、粉丝量作辅助观察；第一个月建立基线，不预设涨粉或成交目标
- 报价和服务范围不在提案正文展开，写"按合作协议执行"；[三档服务](report-and-services.md)放配套资料或另行沟通
- 创始人IP部分沿用当前客户的人物档案和本人语料，不套用其他老板的经历和说话方式

## 视觉规范（默认，可按客户品牌调整）

- 宽屏16:9
- 配色：深墨绿用于封面、大字页、结尾页和表头；暖米白作正文页底色；金棕用于编号和页眉；正文用灰绿，标题用深绿。参考值：深墨绿 `#153B30`、暖米白 `#F5F3EB`、金棕 `#AD8651`、正文 `#65746A`、标题 `#193B31`
- 字体：一种无衬线中文字体；标题约33磅，副标题约13磅，正文和表格约10.5到12磅
- 封面左文右图，配图选与业务相关的环境或生活场景
- 留白充足，不加装饰性图表和花哨图标

## 制作与检查

1. 先出逐页大纲（章、页标题、页型、要点），用户确认后再排版
2. 用当前环境可用的演示文稿工具生成可编辑文件；没有工具时，交付逐页文字稿和版式说明，不称已生成文件
3. 转成图片或PDF逐页检查：无溢出、重叠、错字、缺字，页码连续
4. 事实检查：每个数字、资质、合作方名称都有来源或客户确认；未确认的写"拟议"或"待确认"
5. 真实客户提案只保存在客户自己的项目目录，不放进技能包或公开仓库；示例只用模拟客户
