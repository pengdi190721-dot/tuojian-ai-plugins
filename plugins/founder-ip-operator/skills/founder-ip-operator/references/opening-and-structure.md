# 开头、结构与封面配合

用于写新稿、改稿，以及复盘"开头留人""中段理解"类问题。以下是默认检查项和可验证假设，来源于一个老板口播账号（视频号）连续三条视频的数据复盘和一条对标视频拆解，样本有限；不是平台规则，也不要求每位老板在同一秒数完成钩子。客户已采纳的规则、本人改稿和当前用户要求优先。

## 1. 开头检查

1. **第一句交代这条讲什么。** 优先"问题＋答案"或"原话＋冲突"。删去寒暄、自我介绍和"前两天一个朋友跟我说"类铺垫；原话出处可交给屏幕字。
2. **不为制造冲突说一句虚话。** 观众听不懂这条要讲什么，比没有冲突更容易离开。
3. **尽早兑现一部分。** 默认检查10秒内是否已给出答案或第一部分结论；先铺道理、后给答案的稿件，复盘时重点看该时段留存。
4. **封面与开头配合。** 封面提出的问题，开头应尽快回答；开头不要与封面重复同一句话，应在前段给出封面以外的新信息。
5. **压缩第二轮铺垫。** 接着出现的背景交代控制在一两句，直接接到解释。
6. **关注理由前置。** 本人真实的长期计划或持续更新内容（如"按新方法重做一家店，过程持续更新"）默认检查是否在前30秒出现，并写进主页简介；只放在结尾时，多数观众听不到。关注理由必须是真实计划，不虚构。

## 2. 结构：期待、维持、兑现

| 环节 | 要求 |
|---|---|
| 许诺 | 封面与第一句共同说明观众会得到什么 |
| 先兑现一部分 | 前段回答封面问题或给出第一层答案 |
| 制造新期待 | 抛出下一个值得等的问题，例如"其中只有一条真正拉开差距" |
| 维持 | 默认检查每15到20秒是否出现一个新信息；优先录屏、现场、实物、客户原话、本人做过的改动，避免连续堆观点 |
| 兑现 | 结尾回答的与开头许诺的是同一件事，不转成别的话题 |

- 一条只立一个主观点；密集的是真实素材和具体动作，不是观点数量。
- 借鉴对标账号的"信息密度"时，借其结构与节奏，不借观点、身份、经历、成绩和口头禅。
- 写完按下表逐段对照，填不满说明结构有缺口：

## 3. 时长与语速

按本人已发布视频实测：正文字数 ÷ 成片时长。没有实测时注明为估算。时长区间只是测试起点，不是平台规则。

## 4. 开头备选

每条新稿可提供2到3个开头：问题＋答案（较稳）、本人习惯说法、更强冲突，并说明各自风险。最终以本人试读和数据验证为准；本人提出的说法优先保留，可调整位置而不删除。

## 5. 复盘时怎么用

复盘"开头留人""中段理解"时，可把本篇检查项作为原因假设，配合[视频数据复盘](video-performance-review.md)的证据要求核对实际台词、画面与留存区间；写入下一条验证卡，用户采纳后按[客户建议与沿用](client-learning.md)保存。不能把单个账号的教训当作对所有客户成立的规律。

## 示例（仅示范结构，不示范说话方式）

下例来自一个电商老板账号的改稿，说话方式属于该老板本人，不得套用到其他客户。

```
（许诺＋先兑现，约0到7秒）我问淘宝的AI，为什么推荐这几家？
                         AI给了4条理由：材质，免费刻字，造型镇得住桌面，店铺靠谱。
（新期待，约7到12秒）这4条里，有3条，做奖杯的商家老早就做好了，真正拉开差距的，只有1条。
（关注理由，约12到20秒）我准备新开一家店，就按AI的这套逻辑，把电商重做一遍，过程都会拍给大家看。
（维持，约20到31秒）【录屏：AI追问"颁奖台上灯光出片，还是摆在桌子上有纪念感"】
（兑现，约31秒起）拉开差距的就是这一条：场景。接着讲场景从哪来、具体分三步怎么改。
```
