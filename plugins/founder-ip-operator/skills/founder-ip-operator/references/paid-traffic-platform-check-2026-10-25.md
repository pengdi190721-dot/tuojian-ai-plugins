# 投流规则核查快照（2026年10月25日）

配合[付费投流](paid-traffic.md)使用。这是一次核查的记录，不是长期有效的规则；出完整方案前按[平台核查与定期更新](platform-research.md)重新核。

标记说明：
- **官方原文**：本次直接读到平台或政府页面正文。
- **转述官方**：第三方文章写明摘自官方帮助页，本次没读到官方原文。
- **第三方**：服务商、代理商或作者的说法，没有官方出处。
- **待核**：没找到当期可靠出处，不能当规则讲给客户，以投放页为准。

本次限制：视频号加热的官方帮助页需要登录和网页脚本，本次工具读不到正文；巨量本地推两篇2026年的文章打不开。这两块以“转述官方”和“待核”为主。

## 一、视频号

### 视频号加热（微信豆）

| 规则 | 内容 | 标记和出处 |
|---|---|---|
| 入口 | 手机端创作者中心的加热工具，或自己视频上的“上热门”；电脑端登录网页版加热平台 | 第三方（海螺社，2026-08-21；deepege，2026-10-16核对） |
| 起投 | 短视频单笔500到300000微信豆，要是500的倍数 | 转述官方（deepege，2026-10-16核对，10-22复核下单金额） |
| 微信豆价格 | 常见说法是1元10豆；官方充值协议写的是以充值页显示为准，不同系统、渠道价格可能不同 | 转述官方（引《微信豆充值协议》第5.2条） |
| 短视频目标 | 点赞评论数、关注数、播放数；带商品的视频可选商品点击数、商品成交数 | 转述官方（引《视频号内容加热使用手册》） |
| 直播目标 | 直播间观众、直播间互动、直播间涨粉 | 第三方（海螺社，2026-08-21） |
| 投给谁 | 智能加热由系统找人；定向可按粉丝、群聊、兴趣、性别、年龄、地域、时段圈人；官方手册建议新作品先用智能加热 | 转述官方（deepege） |
| 时间限制 | 发表超过3个月的视频不能推广；同一条视频加热次数不限 | 转述官方（deepege，2026-10），和以前的官方常见问题一致 |
| 审核 | 短视频一般约20分钟，直播约5分钟 | 第三方转述（海螺社称官方约20分钟） |
| 常见不过审 | 搬运、低成本创作、夸张混剪、视频内容和商品不一致 | 第三方转述（海螺社，2026-08-21） |
| 退款 | 主动停止或审核中止约20分钟后，没花掉的微信豆和券退回；充值的微信豆不能退成人民币 | 转述官方 |
| 对自然流量 | 官方说法是加热不影响自然流量 | 第三方转述（海螺社） |

### 腾讯广告投视频号

| 规则 | 内容 | 标记和出处 |
|---|---|---|

| 能选的目标 | 表单留资、加企业微信、商品转化为主 | 第三方（搜狐，2026-05-09） |
| 出价 | 支持智能出价（如按转化出价） | 第三方 |
| 内容助推 | 腾讯广告互选平台给视频号内容加热的方式，2026年4月中旬全量上线；底层调用微信豆加热，多了人群包定向；小店商品可选商品点击、成交、投产比，其他场景可选播放、关注、点赞、组件点击；起投：其他场景50元起，商品点击和成交100元起，商品投产比300元起，上限300000元 | 第三方（代理商页面，2026-06-17） |

| 成本保障和赔付 | 以前资料说有赔付政策，本次没核到当期条款 | 待核 |

### 视频号挂企业微信获客

| 规则 | 内容 | 标记和出处 |
|---|---|---|
