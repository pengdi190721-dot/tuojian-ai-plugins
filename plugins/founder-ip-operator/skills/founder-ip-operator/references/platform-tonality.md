# 平台调性：视频号、抖音、小红书

操盘手要比老板更清楚三个平台“来的是谁、为什么来、内容怎么被看到”。定位选平台、选题、写开头、做封面、发布、复盘、投流和承接，都先过一遍这里。老板不懂时，用他听得懂的话讲给他，不默认他知道。

一句话记住：**视频号是熟人和名片，抖音是陌生人和兴趣，小红书是搜索和种草。**

调性讲的是“来的人跟老板什么关系、内容靠什么被看到”，不是“抖音年轻、视频号中老年、小红书女性”这类人群标签；某位老板的客户在哪，还要看他自己的客户和后台数据。

下面“依据”一栏分三种：官方（平台或监管的公开说明）、权威报道（引用平台数据的媒体）、操盘经验（实操判断，可以用，但要按账号数据验证）。具体入口、数字和规则会变，用到时按[平台核查与定期更新](platform-research.md)复核。

## 一、三个平台对照

| | 视频号 | 抖音 | 小红书 |
|---|---|---|---|
| 来的是谁 | 起号时大多是熟人：微信好友、客户、同行、员工，再从熟人往外扩 | 大多是陌生人，按兴趣被推荐过来 | 带着问题来找答案、找参考的人，很多是主动搜索 |
| 内容怎么被看到 | 好友推荐和算法推荐两套机制并行：好友点赞、评论、分享后，视频进入对方的“朋友♥”，多位好友推荐会提升曝光，再往算法推荐扩 | 按用户兴趣和行为推荐，经过召回、排序和打散；陌生人刷到后几秒内决定看不看 | 兴趣推荐加主动搜索；笔记被搜到、被收藏，能长期带来流量 |
| 依据 | 官方：微信珊瑚安全“一图读懂视频号的算法推荐”（2025年4月）；网信办算法治理说明（2025-05-22）写明视频号“好友推荐”和“算法推荐”双重机制 | 官方：抖音安全与信任中心推荐系统说明（2026-09-24读取） | 权威报道：小红书2026年WILL商业大会，引用小红书数据中台，每月约2亿用户在小红书寻求购买建议（2025年1到11月）；官方：网信办说明里小红书有内容偏好调节功能 |
| 账号像什么 | 名片：熟人会点进主页看你，主页和数据就是门面 | 橱窗：陌生人只看这一条有没有用、有没有意思 | 说明书和口碑：别人搜到你，是来抄作业、做决定的 |
| 起号怎么起 | 先把熟人圈激活：发到朋友圈、客户群，让认识的人先看到；起号期可以小额加热，把播放、点赞、关注做得好看一点，再按每条的质量慢慢调 | 先靠选题吸引陌生人：选陌生客户关心的具体问题，开头几秒说清“这跟你有什么关系”；自然流好的再投流 | 先发满几篇同一方向的笔记，标题和封面带用户会搜的词；挑数据最好的一篇再小额加热 |
| 选题偏向 | 熟人愿意转发、客户愿意讨论的：行业里的真事、老板的判断、公司正在做的事 | 陌生人也能看懂、跟自己有关的：具体问题、反常识、结果先给 | 能被搜到、值得收藏的：清单、步骤、对比、避坑、价格和选择方法 |
| 开头和封面 | 熟人认人，开头可以直接是老板本人在说事；封面要像一张体面的名片 | 前几秒定生死，第一句就是冲突或结果，不铺垫；封面在主页格子里统一好认 | 封面和标题决定点不点，封面字写清“解决什么问题”，标题放搜索词 |
| 承接 | 私域：主页、企业微信、朋友圈、微信群，熟人信任转化快 | 公域：主页、私信、评论区，先让陌生人关注，再慢慢建立信任 | 收藏和关注；私信和引流规则严，按当期社区规范来 |
| 数据先看什么 | 朋友推荐带来的播放、转发、熟人圈外的扩散；关注和主页访问 | 开头几秒留存、完播、新增关注；推荐流量占比 | 点击（封面标题）、收藏、搜索来源；笔记长尾流量 |
| 投流怎么用 | 起号期可以为好看的门面数据小额加热，之后按视频质量调整，好内容再加热放大 | 起号期先不投，靠选题跑自然流；自然流高于账号平均的再投，并教老板怎么投 | 发满几篇后，挑数据最好的一篇用薯条小额加热；商家规模化再用聚光 |
| 常见误区 | 以为发了就有陌生人看；不发朋友圈、不激活熟人；只看播放不看转发 | 用熟人口吻对陌生人说话，开头铺垫太长；没跑自然流就砸钱 | 只做好看不做有用；标题封面没有搜索词；当成短视频平台只拼前几秒 |

“视频号起号期可以为好看的数据加热”“抖音先靠选题、自然流好的再投”“小红书发满几篇再挑好的投”属于操盘经验，背后的原因有官方依据（熟人推荐机制、兴趣推荐机制、搜索种草场景），具体效果按账号数据验证。

## 二、视频号

**为什么熟人多**：视频号长在微信里，好友点赞、评论、转发就会推给他的好友，起号时最先看到的就是认识你的人。账号也会挂在老板的微信资料上，客户加了微信、点开视频号，看到的就是“这个老板在做什么”。

**名片效应**：熟人和新客户点进主页，第一眼看的是有没有在持续更新、数据看起来活不活。播放和点赞太少，会让人觉得“没人看”。所以起号期小额加热，把门面数据做得好看一点，是合理的做法；加热的目标优先选关注或点赞评论，播放只作参考。

**边界**（说一次）：加热买来的是曝光，买不来内容质量；每条加热完都要看完播、转发和评论，按质量慢慢调；复盘时把加热带来的数据和自然数据分开看，不拿加热后的数字当内容好的证据；门面数据做起来以后，回到“好内容再加热”。

**承接**：熟人信任转化快，主页、企业微信、朋友圈、客户群要接得住；内容里少用对陌生人的推销口吻，多讲真事和判断。

## 三、抖音

**为什么陌生人多**：抖音按兴趣推荐，刷到你的大多不认识你，他们只关心这一条跟自己有没有关系、有没有用、有没有意思。

**起号先靠选题**：先做陌生客户关心的具体问题，开头几秒说清“这跟你有什么关系”，结果先给，不铺垫自我介绍。熟人那套“我是谁、我们公司怎么样”放到后面，或者放主页。

**自然流好的再投**：起号期先不花钱，看哪条自然数据高于账号平均（开头留存、完播、新增关注、评论里有人问具体问题），再用DOU+小额加热放大。怎么投要一步一步教老板，见[付费投流](paid-traffic.md)。

**承接**：先让陌生人关注、进主页，再靠持续内容建立信任；私信、留资按平台规则来，内容加热不接受引导加群、引流到第三方的素材。

## 四、小红书

**为什么是种草**：大家在小红书找参考、做决定、抄作业，很多人带着问题主动搜索，看完会收藏，过几天再回来找。

**内容要有用、能被搜到**：标题和封面写清解决什么问题，放用户会搜的词；正文给清单、步骤、对比、价格和避坑；真实体验比口号重要。

**投流**：发满几篇同一方向的笔记，挑数据最好的一篇用薯条小额加热（自己的笔记，目标可选阅读、点赞收藏或涨粉）；企业做规模化再用聚光。具体门槛以投放页为准，见[投流规则核查快照](paid-traffic-platform-check-2026-10-25.md)。

**承接**：收藏和关注是第一步；私信和站外引流规则严，按当期社区规范来。

## 五、贯穿到每一步

| 环节 | 平台调性怎么用 | 方法文件 |
|---|---|---|
| 定位选平台 | 客户在熟人圈、私域里成交多，主平台倾向视频号；要找陌生新客户，倾向抖音；客户做决定前会搜索比较，倾向小红书。主辅平台写清各自的任务 | [第一次使用](first-use-positioning.md)、[三平台执行流程](platform-distribution-and-rules.md) |
| 选题 | 同一个选题按平台换角度：视频号讲真事和判断，抖音讲陌生人的具体问题，小红书讲能收藏的方法 | [选题雷达与评分](topic-radar.md) |
| 写稿和开头 | 视频号可以本人直接开口讲事；抖音第一句就给冲突或结果；小红书文案按问题、方法、清单组织 | [口播与Vlog结构](script-structures.md)、[开头、结构与封面配合](opening-and-structure.md) |

| 发布前评分 | “人设、收尾与平台适配”一项按这里对照 | [成片评分教练](pre-publish-review.md) |
| 复盘 | 视频号先看朋友推荐和转发，抖音先看开头留存和推荐，小红书先看点击、收藏和搜索 | [视频数据复盘](video-performance-review.md) |
