# 读视频链接

用户发来抖音链接或整段分享口令时，AI自己直接读，**只取说的话，不下载视频，不让用户注册任何东西**。拿到文字稿后，按用户要的做拆解、看行情或改写。

## 抖音链接：直接读

要电脑上有 Python 3，在终端里运行（整段分享口令原样放进引号里就行，不用自己挑出链接）：

```bash
python3 scripts/read_douyin_link.py "整段分享口令或链接" --json-output 输出路径.json
```

它做这几件事：

1. 从分享口令里找出链接，短链接跟着跳到作品页，认出是哪条作品。
2. 领一个抖音发的匿名访问凭证（不用登录、不用注册，半小时内重复用），带着它打开作品的公开分享页。不带凭证抖音只给空页面。
3. 读出标题文案、作者、时长、点赞、评论、收藏、分享、背景音乐，还有封面图和预览画面的图片地址。
4. 取说的话：作品自带字幕就直接读字幕；没有字幕，只取声音（作者原声只取那段声音，不是原声才临时取视频里的声音），放在临时文件夹里本地听写，听写完连文件夹一起删掉，电脑上不留视频。
5. 空页面或被拒绝时换一个新凭证再试一次；网络断了自动再试两次；先直连，直连不通再按电脑上的代理设置试一次。

只要标题文案和互动数（比如看行情时扫一遍同行），加 `--no-transcript`，不听写，快很多。

## 拿到结果后

- **“文字稿”**：视频里说的话，按“分段”能对上大概第几秒。照常拆解、看行情或打分。对用户只说“正在读这条视频”，不讲怎么读到的。
- **“封面图”“预览画面”**：都是图片地址，不是视频。当前环境能看图时打开看：封面看封面字和人物；预览画面是抖音给拖进度条用的拼图，一张图里按顺序排着很多小画面，能大概看出镜头怎么换。不是每条作品都有预览画面，没有就不看画面，拆解里写一句“这次只看了说的话和封面”。看不了图也一样写明。
- **“提示”**：说明这次缺了什么。没装听写工具，按[环境体检](environment-check.md)带他装（要 Node.js 22.12 以上），装好前标题文案和互动数照样能先用；听写出空，按提示换个网络再发一次，还不行就请他把视频保存下来发过来。
- 图文作品没有视频：文案就是标题文字，图片只给地址，要看图里的字再打开。

## 读不出来时

命令结果里写着“没直接读出来”“连不上抖音”或“拒绝了读取”时，对用户只说一句：“这条链接我直接读没读出来，换个办法：……”，不讲技术原因，然后：

1. 他开着加速器或翻墙软件的，请他关掉再发一次链接。
2. 还不行，请他在抖音里点“分享”、再点“保存本地”，把视频文件发过来；没有“保存本地”（作者关了下载）就用手机自带的录屏，解析时注明“录屏版”。收到文件按[视频解析](video-analysis.md)读。

## 别的平台的链接

直接读只支持抖音。

- 小红书、B站、视频号的视频：请他在App里保存下来或者录屏，把文件发过来。视频号链接照实说读不了。
- 公众号这类文章：用当前环境能打开网页的工具直接读，读不了就请他把文字复制过来。

## 不做的事

- 不下载视频文件留在电脑上；取声音只为听写，听完就删。
- 不用网页下载站，不登录抖音，不读浏览器里的登录信息，不让用户装证书、装下载器、改代理设置。
- 读到的别人的视频只用于这次拆解学习，不帮用户转发、搬运、重新发布。
