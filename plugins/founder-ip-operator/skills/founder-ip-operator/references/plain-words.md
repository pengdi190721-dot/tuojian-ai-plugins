# 行话翻译表

用这个技能的大多是自媒体新手。跟用户说话时，下面这些词能不用就不用；非用不可，第一次出现就在后面括号里跟一句白话，比如“完播率（看完整条视频的人占多少）”。白话可以照搬，也可以换成老板自己行业里的例子。

视频文案按老板本人的说话方式写，不受这张表限制；这张表管的是操盘手对用户说的话。

## 看数据

| 行话 | 白话 |
|---|---|
| 播放量 | 视频被点开看了多少次 |
| 曝光 | 视频出现在别人屏幕上的次数，不一定点开看了 |
| 点击率 | 看到封面以后点进来看的人占多少 |
| 完播率 | 看完整条视频的人占多少 |
| 3秒留存 | 看了3秒还没划走的人占多少 |
| 跳出 | 没看几秒就划走了 |
| 平均播放时长 | 每个人平均看了多少秒 |
| 留存曲线 | 一张图，看视频每一秒还剩多少人在看；哪里往下掉，哪里就没意思了 |
| 互动率 | 看过的人里，点赞、评论、转发、收藏的占多少 |
| 转发率 | 看完愿意转给别人的人占多少 |
| 涨粉、关注转化 | 看完点了关注的人有多少 |
| 粉丝画像 | 关注你的人大概是什么人：男女、多大、在哪 |
| 自然流量 | 没花钱，平台自己推给别人看的 |
| 付费流量 | 花钱买来的观看 |
| 推荐流量 | 平台自己推的 |
| 搜索流量 | 别人搜东西搜到的 |
| 社交流量 | 朋友转发、点赞以后，他的朋友看到的 |
| 数据复盘 | 回头看数据，找出哪里好哪里不好，下一条怎么改 |
| 样本太少 | 才发了几条，数据还说明不了什么 |

## 做内容

| 行话 | 白话 |
|---|---|
| 定位 | 你这个账号是谁、讲什么、讲给谁听 |
| 人设 | 观众心里对你这个人的印象 |
| IP、创始人IP | 一个让人记住、愿意相信的人；创始人IP就是老板本人成了公司的招牌 |
| 赛道 | 你讲的是哪一类内容 |
| 栏目 | 固定的几类内容，像电视台的固定节目 |
| 选题 | 这条视频讲什么事 |
| 对标、对标账号 | 拿来学习参考的同行账号 |
| 拆解 | 把别人的视频一段一段拆开，看人家是怎么拍的 |
| 爆款 | 数据特别好的视频 |
| 钩子 | 开头一下子抓住人、让人想往下看的那句话或那个画面 |
| 黄金3秒 | 开头三秒，决定观众划不划走 |
| 口播 | 本人对着镜头说话 |
| 视频日记（Vlog） | 跟着拍一天或一件事的过程 |
| 脚本、稿子 | 视频里要说的话和要拍的画面，提前写好 |
| 分镜 | 一个镜头一个镜头写清楚拍什么 |
| 空镜、补充画面 | 不拍人脸的画面，比如车间、产品、手在操作 |
| 封面字 | 封面上那几个大字 |
| 网感 | 说话和画面像网上大家爱看的样子，不端着 |
| AI味 | 一看就是机器写的：套话多、像念稿 |
| 节奏 | 多久换一个画面、多久给一个新东西 |
| 信息密度 | 同样的时间里给了多少有用的东西 |
| 关注理由 | 观众为什么要关注你：以后还能从你这得到什么 |
| 转化 | 看视频的人变成客户，比如来问价、加微信、下单 |
| 承接 | 观众感兴趣以后接住他的地方：回私信、主页、加微信、店铺 |
| 私域 | 加到你微信里的客户，你能自己反复联系 |
| 起号 | 新账号从零开始做起来的头一段时间 |
| 冷启动 | 新视频刚发出去，平台先推给一小撮人试试 |
| 流量池 | 平台推视频是一批一批推的，数据好才推给下一批更多的人（行业说法，平台没公开过细节） |
| 限流 | 视频被平台少推或者不推了（很多时候其实是内容本身没人看，不一定真被限） |
| 矩阵 | 一个公司同时做好几个账号 |
| 日更、周更 | 每天发一条、每周固定发几条 |

## 投流

| 行话 | 白话 |
|---|---|
| 投流 | 花钱让平台把视频推给更多人 |
| 加热 | 视频号里花钱推视频，就叫“加热” |
| DOU+ | 抖音里给视频花钱买推荐的工具 |
| 薯条 | 小红书里给笔记花钱买推荐的工具 |
| 千川 | 抖音卖货用的投广告后台，比DOU+复杂 |
| 本地推 | 抖音给实体店拉附近客人用的投放工具 |
| 腾讯广告 | 微信这边投广告的后台 |
| 投放目标 | 花这笔钱想要什么：更多人看、更多人关注、更多人来问，还是更多人买 |
| 定向 | 选推给哪些人看：地区、年纪、男女、兴趣 |
| 预算 | 打算花多少钱 |
| 止损线 | 花到多少还没效果就停 |
| 投入产出比 | 花1块钱，赚回来多少钱 |
| 获客成本 | 来一个客户（来问或加微信）平均花了多少钱 |
| 千次曝光成本 | 视频被看到1000次花了多少钱 |
| 跑量 | 钱花得出去、能推给很多人 |
| 素材 | 拿去投的那条视频或那张图 |

## 平台

| 行话 | 白话 |
|---|---|
| 视频号 | 微信里的短视频，熟人多，朋友转发是主要来源 |
| 抖音 | 陌生人多，平台按每个人的兴趣推 |
| 小红书 | 很多人去那搜东西、找攻略，适合能收藏、能照着做的内容 |
| 推荐算法 | 平台决定把视频推给谁的那套规则 |
| 标签 | 平台给你的账号和视频打的“讲什么、给谁看”的记号 |
| 话题 | 发视频时加的 #某某，方便被归类和被搜到 |
| 企业号、蓝V | 认证过的公司账号 |
| 违规 | 视频内容碰了平台规则，会被删或者被少推 |

## 工具

| 行话 | 白话 |
|---|---|
| 转写、逐字稿 | 把视频里说的话变成文字 |
| 抽帧、关键画面 | 从视频里截几张图出来看 |
| 环境体检 | 检查电脑上哪些功能能用、缺什么 |
| 终端 | 电脑里输命令的那个黑框（苹果电脑叫“终端”，Windows叫“命令提示符”） |
| 代理、VPN的全局模式 | 让电脑所有网络都绕到国外走的那个开关；开着它，抖音这类国内平台会读不出来 |
| 按规则分流 | 代理软件里的一种模式：国内网站直接走，国外网站才绕 |
