# 模拟示例：装修公司老板

> 这是模拟示例：人物、公司、城市、数字全是编的，只用来看格式和说话方式，不能当真实案例引用。

## 老板设定（虚构）

老周，在一个地级市做老房子翻新，干了十二年，手下十来个工人。客户大多是家里有二三十年老房子的业主，四五十岁，最怕被加钱、怕工期拖。以前生意靠老客户介绍，这两年介绍的少了，想做个人账号让本地业主认识他。

他用语音回答了第一次使用的7个问题。下面是操盘手在对话里一步一步给他的东西：定位 → 他回“没问题” → 找对标、出选题 → 他回“就拍1” → 两份文案。

## 一、IP定位（对话里直接给）

**一句话定位**：本地干了十二年老房翻新的周师傅，把工地上拆开墙看到的真东西拍给你看，告诉你翻新钱该花在哪、哪里最容易被坑。

**主要给谁看**：家里有老房子、正在犹豫要不要翻新的本地业主。他们的原话（老周转述）：“最怕装到一半说要加钱。”

**做账号先要什么**：多来本地业主问价。过几周看两件事：有没有人私信问“我家这种情况多少钱”，有没有人约上门看房。不看涨粉多少。

**主平台**：先做抖音，视频号同时发。

- 为什么是抖音：老周要找的是还不认识他的本地业主，抖音会把视频推给附近刷到的陌生人。
- 视频号干什么：发给老客户和朋友，方便他们转给身边要装修的人。视频号来的多是熟人，就当一张会动的名片。

**三个栏目**：

| 栏目 | 占多少 | 拍什么 |
|---|---|---|
| 拆开墙看看 | 四成 | 工地现场，拆开以后看到的水管、电线、防水，讲清问题在哪 |
| 业主常问 | 四成 | 预算怎么算、工期为什么拖、报价单怎么看 |
| 翻新前后 | 两成 | 同一个房间翻新前和翻新后，讲中间改了什么 |

**待确认**：工地上拍到的业主家，业主愿不愿意露门牌和样子；老周说的“十二年没出过返工”要不要公开讲，有没有记录能证明。

**下一步**：定位没问题就回我“没问题”，我存好档，接着去网上找几个跟你同类的博主，看他们最近在拍什么，给你几个选题挑。哪里不对，直接说哪一条。

## 二、老周回“没问题”以后：找对标、出选题

> 定位存好了。我去网上看了看跟你同类的博主最近在拍什么。

### 找到的对标（模拟）

以下账号和数据都是编的，只示范格式：

- **某省会做老房改造的工长**：跟你一样是老师傅本人出镜，客户也是本地老房业主。
- **某县城做水电改造的师傅**：专拍拆开墙以后的水管电线，正好是你最有本钱的现场。

### 行情速览（模拟）

- 他们在讲：“装修避坑”最多，大多是对着镜头讲道理，没有现场。
- 数据最好的一类：带着镜头进工地，拆开墙给人看，原因多半是“看得见的东西比道理好信”（这是推断）。
- 我们可以接：老周天天在工地，现场画面是他最大的本钱。
- 别跟：“全网最低价”“装修公司都是坑”这类拉踩的说法，老周自己也是装修公司。

### 选题

1. **老房子拆开墙，水管锈成这样**（推荐）
   为什么适合你：你说这周正好在拆一套三十年的老房子，现场是现成的，也最贴“钱花在哪”这个问题。
   第1秒拍什么：锯开的旧水管截面，里面全是锈。
   要准备：一截旧水管（现成）、一把钢锯。
2. **报价单上这三项最容易加钱**
   为什么适合你：业主原话就是“最怕装到一半说要加钱”。
   第1秒拍什么：一张真实报价单，业主信息遮住。
   要准备：一张旧报价单，要先遮好信息。
3. **业主最后悔没早做的一件事**
   为什么适合你：来自你讲的那个漏水的老客户。
   第1秒拍什么：那家翻新前漏水的墙角照片。
   要准备：要先问那位业主能不能讲、照片能不能用。
4. **翻新前后，同一个厨房**
   为什么适合你：对上“翻新前后”栏目。
   第1秒拍什么：拆之前的破旧厨房。
   要准备：要等工期做完，先存着。

**下一步**：回我数字就行，比如“就拍1”，我马上写稿。想换方向也直接说。

## 三、老周回“就拍1”：两份文案

### 第一份：拍摄版

**第1秒画面**：老周手里举着一截锯开的旧水管，截面对着镜头，里面全是锈。
**要准备**：从这套房子拆下来的旧水管（现成）、一把钢锯；业主同意拍，不露门牌。
**拍之前确认**：老管子“用二三十年就锈成这样”，按老周自己在工地上见过的说，他见的不一样就照他的改。

（举着锯开的水管，截面对着镜头）你看这根管子，三十年的老房子，里面锈成这样。你家要是还是这种管子，墙刷得再白也没用。

今天我就说一件事：老房子翻新，钱先花在看不见的地方。

我是老周，在咱们这干了十二年老房翻新。拆开墙看看这个系列，就是把工地上拆出来的真东西拍给你看。

（指着管口）这种老管子用上二三十年，里面就是这样。水一开，先流一股黄水；水压也小，楼下一开水龙头，楼上洗澡就没水了。最怕的是哪天在墙里漏了，你根本看不见，等墙皮鼓起来、楼下来敲门，已经晚了。

（放下水管，指墙里露出来的电线）所以很多业主跟我说，预算不够，先换瓷砖、先换柜子。我一般劝他，先换水管、先换电线。瓷砖旧了你天天看得见，啥时候换都行；水管电线埋在墙里，封上了再想换，就得再砸一遍墙。

你家房子多少年了，水管换过没有？评论区说说吧。

开头检查：第一句就是画面和冲突，没有“大家好我是老周”；第二段就说出答案“钱先花在看不见的地方”；系列名放在第三段，告诉大家关注能看到什么；封面字写“三十年的水管”，开头没有重复这句话。

## 这个示例想让你看到什么

- 定位在对话里直接给，用大白话，没有让老周填表；定位一确认，马上找对标、出选题，没有停下来问“要不要继续”。
- 第一轮选题只给4个、标了推荐，回个数字就能往下走；创意拍法等以后每周出选题再给（见宠物店示例）。
- 文案给了两份：拍摄版有画面、提问卡和开头检查，纯文字版只留要念的话，夹在两行标记中间，直接复制进提词器。
- 每一步最后都有“下一步”，告诉老周接下来干什么、说哪句话。
- 拿不准能不能公开、说法对不对的事，都列出来问老周，没有替他编。
