# 常见问题

先说最重要的：大部分功能不用装任何东西，打开对话说“帮我做IP定位”就能用。只有“读视频文件”和“口播体检”要电脑装几个小工具；“发视频链接让它读”要注册个得到大脑免费账号，实在不想注册就把视频保存下来发过去。

## 一、开始用

**1. 第一次该怎么用？**
说“帮我做IP定位”。它会问你几个问题，按住说话用语音回答就行，答完直接给你定位。你回一句“没问题”，它会接着去网上找几个跟你同类的博主，看他们最近在拍什么，给你几个选题；你回个数字挑一个，它就写好两份文案。每做完一步，它都会告诉你下一步干什么、怎么说。

**2. 我什么资料都没有，能用吗？**
能。什么都没有时会问你7个问题，都能用嘴说清楚，不用填表。

**3. 能不能让它一次把一个月的稿子都写完？**
能写，但不建议。先定选题，挑你真想拍的，再一条一条写。一次写太多，拍不完，也没法根据前几条的数据改后面的。

**4. 我说过的话它记得住吗？下次还要重新说吗？**
定位、你的说话习惯、你采纳过的建议，会存在你电脑上的资料文件夹里（默认叫“客户资料／你的代号”），下次自动读。换了电脑或者新对话读不到这个文件夹时，把文件夹再给它就行。

**5. 我是帮别的老板做的，能用吗？**
能。一个老板建一个文件夹，各是各的，说话方式不会串。要去见老板，就说“帮我准备第一次面谈”。

**6. 它会帮我剪视频、做封面图、写正式报告吗？**
不会，2.2.0把这些删了，让技能更轻。剪辑和封面图用你自己的工具（比如剪映）或者交给同事；它会告诉你这条要剪成什么样、封面上写哪几个字。

## 二、装不上、用不了

**7. 哪些功能不用装东西？**
定位、选题、写稿和提问卡、拆对标（发文字稿就行；发视频文件要装下面说的工具）、标题简介和封面字、投流教学、看后台截图复盘、首访准备。

**8. 读视频要装什么？怎么装？**
要装 Node.js（22.12 以上的版本）。

- 苹果电脑：打开 nodejs.org，下载页面上推荐的那个版本，双击安装包，一路点“继续”。
- Windows 电脑：一样打开 nodejs.org，下载推荐版本，双击安装，一路点“下一步”。

装完回到对话说“帮我检查一下”，它会告诉你装好没有。你也可以让它一步一步带你装，它不会背着你自己装。

**9. 发视频链接让它读，要准备什么？**
注册一个得到大脑账号就行，免费的，不用开会员：
1. 点 https://www.biji.com 注册或登录，微信或手机号就行。
2. 回到对话说“帮我连上得到大脑”。它会给你一个链接和一个8位码，你本人打开链接、核对码一样、点确认，就连上了。以后直接发链接就能读。

能读的链接：公众号文章、抖音、小红书、B站、得到App里的内容。电脑上还要有 Node.js，读视频文件本来就要装，看第8条。

实在不想注册：在抖音里打开这条视频，点右边的“分享”，再点“保存本地”，把视频发过去。视频在手机上、对话开在电脑上的，用微信“文件传输助手”传到电脑再拖进去。

**10. 口播体检要装什么？**
要 ffmpeg（处理声音和视频的小工具）和 numpy。装好 Python 以后，打开终端（电脑里输命令的黑框；Windows 叫“命令提示符”），输入：

```
python3 -m pip install numpy matplotlib
```

matplotlib 是画曲线图用的，不装也行，只是没有图。ffmpeg 不会装就说“帮我检查一下”，它带你装。

**11. 第一次读视频特别慢？**
第一次要联网下载一个听写说话内容的组件，网慢时要等一会儿，只下这一次，以后就快了。

**12. 为什么它不自己去抖音下载？**
让AI自己去抖音下载、用网页下载站、装视频号下载器、改代理设置，这些办法实际用下来基本走不通，换个电脑就不灵。所以发链接交给得到大脑读，实在不想注册，就你在抖音里保存好发过来。得到大脑读出来的是带分段的文字稿，拆结构够用；要看画面（比如给自己的成片打分），就把视频文件直接发过来。

**13. 抖音里没有“保存本地”？**
那是作者关了下载。用手机自带的录屏录下来发过去就行，它会注明是录屏版。

**14. 视频号链接为什么读不了？**
得到大脑读不了视频号。视频号的视频，用手机自带的录屏录下来，或者下载以后把文件发过来。

**15. 读出来的字有错，比如“AI”变成“阿姨”？**
机器听写会听错人名和专有名词。关键的地方它会提醒你核对；你发现了直接说“这里是AI不是阿姨”，它会改。

**16. 发了链接没反应，或者提示“用量用完”“连不上”？**
说一句“帮我检查一下得到大脑”，它会看你还连没连着、用量还够不够。实在连不上，就在得到大脑App里自己粘贴链接存好，等文字稿出来整段复制发过来；或者直接把视频文件发过来，不耽误出稿。

**17. 得到大脑是什么？要花钱吗？**
得到大脑是得到出的笔记软件，能把链接存进去转成文字。读链接用免费账号就行，不用开会员。不想注册也行，在抖音里保存视频发过来（看第9条），其他功能都不受影响。它还能顺带把你的资料存到云端，换电脑也不丢。

## 三、做内容

**18. 我没有对标账号怎么办？**
没关系。做完定位它就会自己联网找2到3个跟你同类的账号，看他们最近在拍什么，再给你出选题。你觉得哪个像，说一声，以后出选题就先看它。

**19. 我不想露脸，能做吗？**
能，但老板做个人账号，露脸最容易让人信你。可以先露声音、露手、拍干活的现场，慢慢再露脸。

**20. AI写的稿子不像我说的话？**
把你改过的稿子发回来，说“按我改的更新表达档案”。改几次就越来越像你了。

**21. 为什么每条稿子都给两份？**
一份是拍摄版，有画面提示和提问卡，拍之前看；一份是纯文字版，只留要念的话，夹在“▼”和“▲”两行中间，从“▼”下一行复制到“▲”上一行，直接粘进提词器就能念。改稿时两份一起改。只要纯文字版，就说“给我纯文字版”。

**22. 创意拍法我不想用？**
直接说“按常规拍”，它不会再劝。连着几次都不用，它会自动少推。

**23. 它说我的选题不行，我还是想拍？**
它会说一次为什么，你坚持就照你的拍，不会反复劝。

## 四、平台和投流

**24. 视频号、抖音、小红书先做哪个？**
客户多在微信里、靠熟人介绍的，先做视频号；想让陌生人认识你，先做抖音；客户买之前会去搜攻略的，先做小红书。拿不准就说“我该做哪个平台”，它按你的情况帮你定。

**25. 新号要不要花钱投流？**
看平台：视频号刚起号时可以花一点钱加热，把数据做好看；抖音先不投，等哪条自然数据好了再投；小红书先发几篇，挑最好的一篇再投。投之前它会先教你，钱在后台由你自己花。

**26. 平台规则多久更新一次？**
平台规则经常变。技能里的资料都写了是哪天查的；定平台、正式复盘、你问“最新规则”时，它会联网查最新的。联不上网会告诉你资料是哪天的。

**27. 能保证涨粉、上热门吗？**
不能，谁跟你保证谁在骗你。能做的是每条讲清为什么这么拍，看数据改下一条。

## 别这样用

- 别让它编成果、编数字、编客户案例。没做成的事不能说成做成了。
- 别把别人视频里的原话、经历直接拿来用。只学人家的结构和节奏。
- 别一次要几十条稿子。拍不完，也没法根据数据改。
- 别把几个老板的资料放在一个文件夹里，说话方式会串。
- 别只看播放量判断好坏。还要看看完的人多不多、有没有人留言问具体问题。
- 别让它替你登录、充值、发布。这些你自己点。
- 别把真实客户的资料放进要分享出去的技能包里。
