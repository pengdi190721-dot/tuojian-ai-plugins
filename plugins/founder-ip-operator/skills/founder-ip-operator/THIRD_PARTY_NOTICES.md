# 第三方能力说明

本技能没有复制以下项目源码（2.0.0从原“自媒体作战室”并入）：

- mcp-video-analyzer：视频字幕读取、关键画面、文字识别和时间线解析，MIT。技能锁定调用0.10.0版。
- scrybe：视频没有字幕时的本地中文语音转写，MIT。技能锁定调用0.2.0版和基础多语言模型，不要求账号或接口密钥。
- TrendRadar：热点雷达，GPL-3.0。
- Agent Reach：互联网调研路由，MIT。
- nuwa-skill：人设和思维方式提炼，MIT。
- brand-voice：品牌语言规范，MIT。
- nekro_plugin_media（https://github.com/Healock/nekro_plugin_media ）：2.4.0直接读抖音链接时参考了它公开的思路（先领匿名访问凭证、再读公开分享页里的作品数据）。没有复制它的代码，`scripts/read_douyin_link.py` 是自己写的。
- numpy、matplotlib：口播体检用来计算和画图，BSD类许可。不随技能分发，由用户自行安装。

2.2.0删掉九种风格封面后，技能包里不再随包分发任何第三方素材。2.2.1删掉了自己下载抖音视频的小程序，也不再调用视频号下载器；2.4.0重新加回直接读抖音链接，只读公开分享页，只取说的话（声音听写完就删），不下载视频，不登录、不读浏览器登录信息、不用网页下载站；同时去掉了得到大脑。第一次下载语音识别模型连不上 huggingface.co 时，会改从国内镜像 hf-mirror.com 下载，下载内容按识别组件自带的校验值核对。

视频解析器首次使用时由运行环境按需下载；其源码、模型和传递依赖仍分别遵循上游许可。启用其他外部能力时以其官方仓库、当前版本和许可为准。对外分发修改版或提供联网服务前，需要单独检查相应开源义务。
