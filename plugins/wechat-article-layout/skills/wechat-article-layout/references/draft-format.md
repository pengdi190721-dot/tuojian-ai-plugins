# 文字稿怎么写

文字稿就是一个 `.md` 文件：开头一段文章信息，下面是正文加标记。完整例子看 `assets/sample.md`（里面的 `示意图:1` 是样稿专用的示意截图，正式稿子写真实截图的路径）。

## 开头的文章信息

```
---
标题: 给 WorkBuddy 装一个技能，==三步就够==
栏目: WorkBuddy基础应用
期数: 第 01 篇
副标题: 装之前先想清楚：这件事，你想让 AI 照谁的规矩办。
信息: 耗时=约 5 分钟 | 难度=会打字就行 | 适合=想把 AI 用进公司的老板
看点: 装技能的三步 | 最容易踩的坑 | 装完怎么判断
互动: 你们公司装的第一个技能，是自己写的，还是拿别人的改的？
---
```

| 项 | 必填 | 说明 |
|---|---|---|
| 标题 | 是 | 用 `==` 包住的部分会用主题色突出，一个标题最多突出一处 |
| 栏目 | 否 | 显示在封面角上；不写就用设置里的 |
| 期数 | 否 | 比如“第 01 篇” |
| 副标题 | 否 | 一句话。汇报青主题会把它放进“先说结论”的色块里 |
| 信息 | 否 | 2 到 3 项，`名=内容`，用竖线隔开。只写用户给过的事实 |
| 看点 | 否 | 目录；不写就自动取前三个章节标题（不含“写在最后”） |
| 署名 | 否 | 不写就用设置里的 |
| 互动 | 建议写 | 文末的提问，后面会自动接上“评论区聊聊吧” |

## 正文标记

| 写法 | 排出来是 | 用在哪 |
|---|---|---|
| `## 标题` | 章节（自动编号） | 文章的大块。最后一章叫“写在最后”会用收尾样式 |
| `### 标题` | 步骤（每章从 1 重新编号） | 操作教程的一步 |
| `#### 标题` | 小标题（不编号） | 不是步骤的小段落 |
| 空一行 | 分段 | |
| `![说明](截图/01.png)` | 截图 + 图号 + 说明 | 单独一行。还没图就写 `![说明](待补)` |
| `【待补：……】` | 原样显示 | 写稿时缺的事实先占位，排版会提示还有几处没补 |
| ` ```发给 AI 的话 ` … ` ``` ` | 代码框 | 要用户照着复制的话、命令、网址。第一行后面可以写框的标题 |
| `:::坑` … `:::` | 踩坑提醒 | `:::坑 标题` 可以自定标题 |
| `:::原话 说话的人` … `:::` | 原话卡 | 老板的真实原话，开头最常用 |
| `:::对比 之前 \| 之后` … `:::` | 前后对比表 | 里面每行 `- 之前的情况 \| 之后的情况` |
| `> 一句话` | 金句 | 全文 1 到 2 句，40 字以内 |
| `1. ` 开头的几行 | 编号清单 | |
| `- ` 开头的几行 | 圆点清单 | |
| `---` | 分隔线 | |

行内标记：

| 写法 | 效果 | 用量 |
|---|---|---|
| `[[关键词]]` | 下划线 | **每段 1 到 3 处**，40 字以上的段落必须标 |
| `**重点**` | 主题色加粗 | **全文不超过 5 处** |
| `==高亮==` | 底色高亮 | 尽量不用，全文最多 2 处 |
| `` `文字` `` | 等宽小框 | 按钮名、菜单名、文件名 |

## 你要做的判断

1. **关键词怎么挑**：挑结论、做法、要记住的那半句，4 到 15 个字。不挑“我们”“这个”这类虚词；很短的过渡段可以不标。
2. **加粗留给谁**：全文最想让人记住的几个词，比如界面上的入口名、最关键的一个动作。
3. **金句从哪来**：从用户原文里挑，挑“是A，不是B”这种一听就能记住的。原文里没有就不放，不要自己编。
4. **哪些是步骤**：用户在讲“先……再……然后……”的地方拆成 `###`。一步只讲一个动作。
5. **要不要补小标题**：原文很长没分段时可以补 `##`，补了要在交付时告诉用户补了哪几个。

## 脚本会自动做的事（你不用管）

- 中文里的半角标点改成全角，直引号改成弯引号（代码框和网址不动）
- 章节、步骤、图号编号
- 目录、封面、文末署名和互动
- 粘进公众号的格式限制
