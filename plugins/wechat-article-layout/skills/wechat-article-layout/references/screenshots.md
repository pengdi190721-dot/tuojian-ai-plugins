# 截图规则

操作图文最容易翻车的地方就是截图：顺序乱了、配错了步骤、粘进后台图没了。照下面做。

## 1. 编号和存放

- 在工作文件夹里建一个 `截图` 文件夹，截图按**在文章里出现的顺序**改名：`01.png`、`02.png`……保留原来的格式（jpg 就还是 jpg）。
- 图号（图 1、图 2）由脚本按出现顺序自动编，不用手写。
- 公众号只收 png、jpg、gif 这类图片。用户发来的是 PDF、网页，请他截成图片再发。

## 2. 对位：哪张图放哪一步

按这个顺序判断：

1. 用户说了这张图是哪一步 → 照用户说的。
2. 截图里看得出是哪个界面、点的哪个按钮 → 对到讲这个操作的那一步。
3. 都看不出 → 按用户发图的顺序。

还是拿不准的，先按发图顺序放，**在选主题那条消息里一起问**，比如“图 3 和图 4 我按发图顺序放的，哪张是设置页请你确认”。不要为这个单独停一次。
你看不了图片时，也按发图顺序放，说明先只写“图 N”，在选主题那条消息里请用户每张说一句是什么界面、点了哪里，补上说明再排。

图放在它说明的那一步的正文**后面**，单独一行：

```
### 打开技能管理
先在左侧菜单里找到**技能**入口……

【图】截图/01.png｜左侧菜单里找到“技能”入口
```

## 3. 说明怎么写

- 一句话，20 字以内，说“看哪里”：「左侧菜单里找到“技能”入口」「回复里出现技能名，说明已经生效」。
- 不写“如图所示”“下图”，不写截图里看不到的东西。
- 正文里要提到某张图，写“见图 2”，排完核对一下图号对不对得上。

## 4. 数量

- 一步最多两张。连着三张以上差不多的图，问用户留哪张最关键。
- 某一步该有图但用户没给 → 写 `【图】待补｜说明`，排出来是一个“图 N 待补截图”的空位，交付时列出来让用户补。

## 5. 截图本身

- **打码**：手机号、客户名、订单号、金额、内部数据，提醒用户先打码再用。公不公开由用户定，你只负责提醒。
- **红框标注**：脚本不改图。要标注请用户截图时自己画（微信、QQ 截图都带画框）。
- **大小**：装了 Pillow，脚本会把截图压到宽 1280、1MB 以内；没装就用原图，超过 1MB 会提示。

## 6. 粘进后台以后

- 预览页里的截图是嵌在页面里的。点「复制（带截图）」粘进后台，截图能不能一起进去，要看公众号后台收不收这种图。
- 没进去就点「复制（截图留空位）」重新粘，每张图的位置会留一个空框，下面有图号和说明，照着在后台插图就行。
