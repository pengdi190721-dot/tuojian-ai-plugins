# 画面写法（scenes.html）

画面就是一个普通网页片段。你只管写**有什么、什么时候出来**，位置、动画、字幕、进度条、音效都由引擎处理。不会写的时候，打开 [示例画面](示例画面.md) 找一段相似的照着改。

## 一、整体结构

```html
<section class="sec" data-sec="3">     <!-- 第3段：自动从第3段开始显示，第4段开始时消失 -->
  ……这一段的元素……
</section>
<script>
  cam('cam3a', {...});                  <!-- 这一段的截图镜头设置 -->
</script>
```

一段一个 `<section>`，`data-sec` 跟 `script.txt` 里的段落顺序一致。

## 二、版位（横竖版自动换位置）

| class | 横版位置 | 放什么 |
|---|---|---|
| `R-term` | 左上 | 主讲词：小标题 + 大字 + 一句话比喻 |
| `R-notes` | 左边中下 | 标签，一条条往下排（横版最多4条，竖版最多4条） |
| `R-frame` | 右边大画框 1060×690 | 截图镜头，或者图解 |
| `R-center` | 中间大块 | 片头大字、居中排版 |
| `R-wide` | 整个内容区 | 回顾格子之类的大布局 |
| `quote` | 正中 | 金句卡 |

`R-frame` 里的图解：在 1060×690 的画布上用 `class="a"` + `style="left:..;top:.."` 自由摆放，竖版会自动缩小，不用管。

## 三、时间写法（最重要）

每个要出场的元素加 `class="el"` 和 `data-in`，要提前消失的加 `data-out`：

```html
<div class="note el" data-in="at('3.2','右下角')" data-out="ls('3.5')">……</div>
```

| 写法 | 意思 |
|---|---|
| `S(3)` | 第3段开始 |
| `ls('3.2')` | 第3段第2句开口前0.1秒 |
| `le('3.2')` | 第3段第2句说完 |
| `at('3.2','右下角')` | 第3段第2句说到“右下角”那一刻 |
| `END` | 片尾 |
| `at('3.2','右下角')+0.3` | 往后推0.3秒 |

- 行号一律用 `'段.行'`，对照 `work/行号表.txt`。改了某一段的稿子，只影响这一段。
- `at` 的关键词必须是这句话里**原样有的字**（标点不算）。找不到时 `render.py 检查` 会报“找不到「xx」”。
- 不写 `data-out` 就一直显示到这一段结束。
- 多段显示：`data-show="[[ls('8.1'),ls('8.3')],[ls('8.5'),ls('8.6')]]"`
- 高亮一段时间：`data-hl="[[开始,结束]]"`；变暗一段时间：`data-dim="[[开始,结束]]"`（只写一个时间就是从那以后一直）

**出现方式** `data-a`：`rise` 上浮（默认）｜`pop` 弹出｜`fade` 淡入｜`left` 从左滑入｜`right` 从右滑入｜`zoom` 放大｜`wipe` 从左往右擦出｜`none`

**音效** `data-sfx`：`pop` 啵（卡片、标签）｜`thud` 咚（金句）。圈注自动配“嘀”，换段自动配“嗖”。不是每个元素都要音效，一句话里最多两三个。

**小动作**：`bob` 上下浮动｜`blink` 眨眼（加在角色 svg 上）｜`pulse` 一闪一闪｜`swing` 摆手

## 四、截图镜头（先全貌，再推近，再圈注）

```html
<div class="R-frame cam" id="cam3a" data-img="home.png"></div>
<script>
cam('cam3a', {
  show:  [[S(3)+0.3, at('3.2','点开')+0.3]],
  views: [[0, [260,140,2010,1390]],              // 先给全貌：截图里 x=260,y=140 起，宽2010高1390 的区域
          [at('3.2','输入框'), [430,560,1700,500]]],  // 说到“输入框”时推近到这块
  marks: [{in: at('3.2','右下角'), out: at('3.2','点开')+0.3, r: [1535,845,350,66]}]
});
</script>
```

- `views` 和 `marks` 的坐标都是**截图原图的像素坐标**：`[左边x, 上边y, 宽, 高]`。
- **读坐标的方法**：`python3 scripts/grid.py 项目` → 打开 `work/网格/xxx_网格.jpg`，红线是 x、蓝线是 y，每100一格。一定要看图读，不要猜。
- `kind:'bar'` 是整行高亮条（适合列表一行行扫过去），`nosfx:1` 不响。
- 推近区域的宽高比尽量接近画框（横版约 1.5:1），画面才不会留大白边。
- 写完用 `render.py 项目 抽帧 秒数` 看圈注是否正好圈在按钮上。

## 五、每个词一段的标准写法

1. `R-term`：小标题（第几个词）+ 大字（这个词）+ `eq`（这段口播里有比喻才放，说到比喻那个词时出来；没有就不放）
2. `R-notes`：3–4 条标签，“位置：在哪”一定要有；深色标签 `note`、浅色标签 `note w`、红色警示 `note bad` 交替用
3. `R-frame`：截图镜头（先全貌圈位置 → 推近讲细节）→ 中间穿插一张图解（对比、流程、清单）→ 回到截图
4. 这段有★那句时：`dim` 压暗 + `quote` 金句卡，`<em>` 包住重点词（金句整条 2 到 3 句，不是每段都有）

同一时刻 `R-frame` 里只能有一样东西：几个镜头和图解的显示时间要首尾相接、不能重叠。

## 六、角色和图标

[组件库](组件库.md) 里有：小机器人（会眨眼、天线闪、摆手）、AI员工（戴工牌）、老板（西装领带）、对话气泡、钥匙、电脑、云、对话、文件、门。

- 片头放小机器人挥手，打比方时用 AI员工，讲“老板们”时用老板。
- 角色颜色跟着风格自动变，不要在里面写死颜色。
- 竖版位置不一样的，加 `data-vstyle="left:..;top:.."`。

## 七、写完必做

1. `python3 scripts/render.py 项目 检查` —— 必须显示“检查通过”
2. `python3 scripts/render.py 项目 总览` —— 每句话一张图，一张张看
3. 有问题回来改，再检查、再总览
