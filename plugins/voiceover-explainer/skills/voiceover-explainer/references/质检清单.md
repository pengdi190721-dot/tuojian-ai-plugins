# 质检清单

## A 线（口播剪辑）

### 发方案前
- [ ] 剪辑单每一条都对照听写看过，不是照抄建议；拿不准的写进消息让用户定
- [ ] 打开 `out/四个模版对比.jpg` 看过：人脸清楚、睁着眼，字没挡脸，四种风格都正常

### 渲染全片前（看总览，每句一张）
- [ ] `work/剪辑点检查.txt` 没有“【要听】”
- [ ] `video_build.py` 吻合度 90% 以上，没有报错和提醒没处理
- [ ] 字幕一行放得下，重点词每行最多一处；字幕和这句话一字不差
- [ ] 包装不挡脸、不挡嘴；小窗里人脸居中，小窗不压卡片
- [ ] 要点卡说到哪条亮哪条；三步卡、截图圈注出现的时间对得上嘴里说的
- [ ] 金句卡出来时底下压暗了，那几句没有重复的普通字幕
- [ ] 同一种版式至少 4 秒，没有来回切
- [ ] 片头栏目角标是用户选的，片尾行动卡写对了

### 合成后
- [ ] `video_finish.py` 字幕核对全部对上，或“【要看】”的几条都确认过
- [ ] 抽开头、中间、结尾各看 10 秒：剪辑点没吞字、没跳音量，音效没盖过人声
- [ ] 文件：`out/成片.mp4`、`out/字幕.srt`

## B 线（科普动画）

### 渲染全片之前（看总览图，每句话一张）

- [ ] `render.py 项目 检查` 显示“检查通过”，没有“要改”
- [ ] 每句话的画面和这句话说的是一回事（说“右下角”时，圈注就在右下角）
- [ ] 圈注正好圈住按钮，没有偏、没有圈到空白
- [ ] 字没有被别的东西挡住；标签没有压到字幕上
- [ ] 字幕最多两行，重点词标了颜色
- [ ] 截图推近后看得清字；没有大片空白画框
- [ ] 同一时刻画框里只有一样东西（镜头和图解不重叠）
- [ ] 金句卡出来了，背景压暗了（金句整条 2 到 3 句，不是每段都有）
- [ ] 顶部进度条：讲到哪个词哪个亮
- [ ] 没有任何一处画面超过5秒一动不动
- [ ] 隐私信息（名字、电话、客户、聊天记录）打码了
- [ ] 替老板写的举例，画面上标了“示例”
- [ ] 没有编造的数字、没有说成有的成果

### 合成之后

- [ ] `finish.py` 的字幕核对：最大偏差在0.3秒以内，或者“要看”的几条都确认过
- [ ] 抽开头、中间、结尾各听10秒：声音清楚、音效没盖过人声、没有切掉半个字
- [ ] 成片长度合理（比原录音长10%以内）
- [ ] 文件：`out/成片.mp4`、`out/字幕.srt`

### 交付时告诉老板

- 时长、风格、画幅
- 节奏做了哪些调整（停顿压短/补长，内容没剪）
- 字幕按实际念的出的地方
- 哪些是替他写的示例、哪些地方打了码
- 背景音乐没加，后期加时压低音量
- 可选：标题、话题标签、封面文字
