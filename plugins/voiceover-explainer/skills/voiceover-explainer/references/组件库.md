# 组件库

写画面（scenes.html）时，从这里复制需要的片段，改文字和出现时间就行。颜色全部跟着风格走，不要在组件里写死颜色。完整用法见 [示例画面](示例画面.md)。

## 时间、出场、音效、小动作

```text
时间写法（data-in / data-out / data-hl / data-dim 里都能用）：
S(3)              第3段开始
ls('3.2')         第3段第2句开口
le('3.2')         第3段第2句说完
at('3.2','右下角') 第3段第2句说到“右下角”那一刻
END               片尾
可以加减秒数：at('3.2','右下角')+0.3
出现方式 data-a：rise 上浮（默认）｜pop 弹出｜fade 淡入｜left 从左滑入｜right 从右滑入｜zoom 放大｜wipe 从左往右擦出｜none
音效 data-sfx：pop 啵（卡片、标签）｜ding 嘀（圈注，镜头里自动加）｜thud 咚（金句）｜whoosh 嗖（换段，自动加）
小动作 class：bob 上下浮动｜blink 眨眼（角色外层加）｜pulse 一闪一闪｜swing 摆手
```

## 3. 截图镜头（先给全貌圈出位置，再推近讲细节）

HTML 里只放一个空盒子，镜头的时间、推拉、圈注写在下面的 <script> 里。      坐标是截图原图的像素坐标，用 scripts/grid.py 给截图画上坐标网格再读。

```html
<div class="R-frame cam" id="cam3a" data-img="home.png"></div>
<script>
cam('cam3a', {
  show:  [[S(3)+0.3, at('3.2','点开')+0.3]],             // 什么时候显示，可以写多段
  views: [[0, [260,140,2010,1390]],                      // [从几秒起, [x,y,宽,高]] 先全貌
          [at('3.2','输入框'), [430,560,1700,500]]],      // 说到“输入框”时推近
  marks: [{in: at('3.2','右下角'), out: at('3.2','点开')+0.3, r: [1535,845,350,66]},   // 圈注
          {in: at('3.3','每个模型'), out: ls('3.4'), r: [6,51,666,68], kind: 'bar', nosfx: 1}]  // 横条高亮，不响
});
</script>
```
