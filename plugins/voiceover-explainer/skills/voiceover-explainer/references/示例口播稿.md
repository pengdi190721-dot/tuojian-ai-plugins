# 示例口播稿（WorkBuddy七个词）

这是一条真实做过的片子：横版，4分17秒，清爽薄荷风格。下面是录音以后按实际念的改过的 script.txt，可以对照 [示例画面](示例画面.md) 看每句话配什么画面。

运行 `python3 scripts/example_project.py 目标目录` 可以把整个示例项目（口播稿、画面、时间表、占位截图）放出来，直接跑检查、总览、样片。

```text
# 片头
想把AI或者说WorkBuddy用明白，这几个词老板一定要搞懂。
大模型、上下文、技能、连接器、专家，还有本地和云端。
我们公司现在也在用WorkBuddy，今天就给大家讲一下这几个词的区别。

# 打个比方
老板们，你就把AI当成公司新招的一个员工。
脑子是大模型，手上的资料是上下文，
公司的规矩是技能，进系统的钥匙是连接器。
自带做事方法、叫来就能上岗的，就是专家；让AI在哪儿干活，就是本地和云端这两个地方。

# 大模型【章】
第一个词，大模型。
就在输入框右下角，点开是一排模型。
大模型就是员工的脑子，每个模型都有自己擅长的领域。
写文案、算账、看图，不是一回事，什么活儿就该用什么模型。
后面这个数，就是积分花得有多快。
有限时免费的，也有贵出十几倍的。
★所以选模型，先看活儿，再看价钱。

# 上下文【章】
第二个词，上下文。
你在输入框里交代的每一句话、递给AI的每一份资料，都算上下文。
上下文是AI这一次能看到的东西，不是AI一直记得的东西。
聊得太长，前面交代的事AI就容易忘。
新开一个任务，基本就等于换了个新来的员工。
★所以一个活儿开一个任务，把要求一次性交代清楚，这个道理带过人的都懂。

# 技能【章】
第三个词，技能，也就是Skill。
在顶上“技能”这一栏，有个技能市场，别人写好的技能可以直接装。
装好了，在输入框里打个斜杠，就能叫出来。
每条技能后面这段说明，就是告诉AI什么时候用、怎么干。
说白了，技能就是公司的规矩。
比如我们核对奖杯刻字的名单，名字一个字都不能错。
看着是常识，但AI还真不一定知道。
★所以AI写不好，多半是我们的判断没交给AI，不是AI不行。
我们写的技能，也能传上来。
员工每改一次AI的稿，把为什么改，写进技能里，这就是在训练企业AI。

# 连接器【章】
第四个词，MCP。
在WorkBuddy里找不到叫MCP的菜单，MCP藏在顶上“连接器”这一栏。
MCP你就理解成一把钥匙，可以打开对应的门。
点开一个，比如腾讯文档，点“连接”，就是把钥匙交给AI。
连上以后，AI就能直接在腾讯文档里建表格、查数据。
有的卡片写着MCP，有的写着命令行，老板们不用分那么细，就当成钥匙就行。
★连接器管的是AI能不能进门，技能管的是AI进门以后怎么干活。

# 专家【章】
第五个词，专家。
在顶上“专家”这一栏，电商运营、内容创作、法律咨询，分得清清楚楚。
点开一个，有版本号，有开发者，说白了就是别人带出来的员工。
点“召唤”，就叫来上班了。
我们自己也建了一个，叫企业经营分析助手，说明第一句就是“先核口径再算账”。
这几个字，就是我们自己的判断。
市场上的专家明明都挺厉害，但那是别人带出来的，不懂我们公司的规矩。
★所以专家值钱的不是名字，是里面写进去的判断。

# 本地/云端【章】
最后两个词，本地和云端，说的就是AI在哪儿干活。
本地，就是AI在你自己的电脑上干活。
输入框下面这个“选择工作空间”，就是告诉AI这次在哪儿干活。
“打开本地文件夹”，就是让AI在这个文件夹里干活。
云端，就是AI在外面的电脑上干活。
手机上点“选择设备”，云端和自己的电脑，二选一。
选电脑，电脑就得开着。
用云端，电脑关了也能干活，就是拿不到你电脑里的文件。
★所以本地是请AI来你电脑上干活，云端是让AI随时随地干活。

# 收尾
最后我们回顾一下。
大模型是脑子，上下文是手上的资料，技能是规矩，连接器是钥匙。
专家是带好规矩、能直接上岗的员工，本地和云端说的是在哪儿干活。
这几样里头，最值钱的是技能和专家，里面装的全是判断。
★软件谁都能装，真正拉开差距的，是让AI按你们公司的规矩做事。
```
