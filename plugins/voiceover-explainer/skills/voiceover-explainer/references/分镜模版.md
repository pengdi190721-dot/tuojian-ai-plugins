# 第2步给老板看的稿子：口播稿 + 画面对照 + 截图清单

老板这一步要确认三件事：**讲的顺序和说法对不对、画面能不能对上嘴里说的话、截图够不够。** 所以整份稿子用大白话写，不写代码、不写秒数。直接贴在对话里，或者做成文档发过去都行。

**用户发了文字解释或语音，口播先用他自己的话写**，怎么写见 [写稿要像本人](写稿要像本人.md)。一份回复的顺序：开头四行 → 2 到 3 个开头备选 → 口播稿加画面对照（拍摄版）→ 我补的话 → 截图清单 → 纯文字版（两行标记夹住）→ 要老板确认的事。

## 一、开头四行

```
片名：WorkBuddy七个词
给谁看：试过AI、但没在公司真正用起来的中小企业老板
比喻（可选，真能帮人听懂才用；没有就写“不用”）：把AI当成公司新招的一个员工——大模型是脑子，上下文是手上的资料，技能是公司的规矩，连接器是进系统的钥匙，专家是能直接上岗的员工，本地和云端是在哪儿干活
预计时长：4分钟左右（全稿约1200字，按每秒4–5个字估）
```

## 二、口播稿，每段后面附画面对照

```
【第3段 大模型】
第一个词，大模型。
就在输入框右下角，点开是一排模型。
大模型就是员工的脑子，每个模型都有自己擅长的领域。
写文案、算账、看图，不是一回事，什么活儿就该用什么模型。
后面这个数，就是积分花得有多快。
有限时免费的，也有贵出十几倍的。
★所以选模型，先看活儿，再看价钱。

画面：首页全貌，圈出输入框右下角的模型名 → 点开模型列表，一行行扫过 → 图解“写文案/算账/看图分别交给擅长的模型” → 圈出后面那列倍率 → 金句卡
截图：home.png（已有）、models.png（已有）
```

上面这段是格式示范，说话方式属于这位老板本人，别照搬到别人身上。

写稿规矩：
- 用户自己的讲解顺序优先；段落长短跟着内容走，有的段三句就讲完，不凑句数。
- 一行一句，一句别超过30个字；金句前面标★，**整条 2 到 3 句**，放在真正的结论处，不是每段结尾都要。“是A，不是B”整条最多一两处。
- 比喻真能帮人听懂才用，用一次就够，不每段都扯回比喻。
- 截图里看得见的东西（按钮叫什么、在哪、上面的数字）优先写进口播，少讲空概念。
- 能用截图的一定用截图（老板要的就是“在界面里哪儿”）；讲概念、打比方用图解和小人。
- 你拿不准的地方，在句子后面用括号标出来，比如“（这个倍率含义我是看截图猜的，请确认）”“（这是我替你编的例子）”。

## 四、我补的话和纯文字版

- **我补的话**：列出口播里不是老板原话、是你补上的句子（原话怎么挑、怎么补，见 [写稿要像本人](写稿要像本人.md) 第一节）。老板什么文字都没给时，写一句“没有你的原话，是按默认说法写的”。
- **纯文字版**：只留要念的话，录音时照着念，格式见 [写稿要像本人](写稿要像本人.md) 第五节。

## 五、最后问老板

> 稿子你看一下，顺序、说法有要改的直接改；标了括号的几处请你确认。还缺的几张截图麻烦补一下。稿子定了我把录音要求发你。
