# 第2步给老板看的稿子：口播稿 + 画面对照 + 截图清单

老板这一步要确认三件事：**讲的顺序和说法对不对、画面能不能对上嘴里说的话、截图够不够。** 所以整份稿子用大白话写，不写代码、不写秒数。直接贴在对话里，或者做成文档发过去都行。

## 一、开头四行

```
片名：WorkBuddy七个词
给谁看：试过AI、但没在公司真正用起来的中小企业老板
贯穿全片的比喻：把AI当成公司新招的一个员工——大模型是脑子，上下文是手上的资料，技能是公司的规矩，连接器是进系统的钥匙，专家是能直接上岗的员工，本地和云端是在哪儿干活
预计时长：4分钟左右（全稿约1200字，按每秒4–5个字估）
```

## 二、口播稿，每段后面附画面对照

```
【第3段 大模型】
第一个词，大模型。
就在输入框右下角，点开是一排模型。
大模型就是员工的脑子，每个模型都有自己擅长的领域。
写文案、算账、看图，不是一回事，什么活儿就该用什么模型。
后面这个数，就是积分花得有多快。
有限时免费的，也有贵出十几倍的。
★所以选模型，先看活儿，再看价钱。

画面：首页全貌，圈出输入框右下角的模型名 → 点开模型列表，一行行扫过 → 图解“写文案/算账/看图分别交给擅长的模型” → 圈出后面那列倍率 → 金句卡
截图：home.png（已有）、models.png（已有）
```

写稿规矩：
- 每段 5–10 句，30–45 秒；顺序是**在哪 → 是什么（用比喻）→ 举个例子 → 金句**。
- 一行一句，一句别超过30个字；金句前面标★，每段最多一句，用“是A，不是B”或“先A，再B”这种好记的句式。
- 能用截图的一定用截图（老板要的就是“在界面里哪儿”）；讲概念、打比方用图解和小人。
- 你拿不准的地方，在句子后面用括号标出来，比如“（这个倍率含义我是看截图猜的，请确认）”“（这是我替你编的例子）”。
