# 风格说明

下面四种风格两条线通用，用的是同一套画面，只换颜色、字体、边框，所以**选风格不用重写画面**，改 `project.json` 里的“风格”就行。给老板挑的时候，用他自己的内容出预览：B 线（科普动画）用 `style_preview.py` 出预览图和样片；A 线（口播剪辑）用 `video_templates.py` 拿他视频里的画面出模版图。A 线另外还有四个“全屏口播”模版（模版五到八，见本文后半），一共八个。

挑风格时可以这样问老板：
> 我用你的录音，把片头和第一个词做了四种风格的样片，你看哪种顺眼？投大屏的话黑金最有质感，日常发视频号清爽薄荷最耐看，想要冲击力就选大字报。

## 横版和竖版

- 横版 1920×1080：投大屏、电脑看。左边主讲词和标签，右边截图画框，下面字幕。
- 竖版 1080×1920：视频号、抖音。上面主讲词，中间截图画框，下面标签和字幕。
- 同一份 `scenes.html` 横竖版都能用（版位是自动的）。个别自己摆位置的元素，用 `data-vstyle="left:..;top:.."` 写竖版位置。
- 临时出另一种画幅：`render.py 项目 样片 0 20 --竖`。

## 想加新风格

在项目里新建一个 css 文件（比如 `my.css`），写一段 `:root{...}` 只改颜色变量，然后在 project.json 里加 `"自定义样式": "my.css"`，它会在所选风格之后加载、覆盖颜色。变量名可以在 `scripts/engine_assets.py` 的风格里查到。主要变量：
- `--bg / --stage-bg` 背景；`--ink` 正文字色；`--acc` 主色；`--acc-d` 主色文字；`--acc-s` 主色浅底；`--acc-m` 划重点底色
- `--card / --card-bd / --shadow / --radius` 卡片
- `--note-*` 标签；`--q*` 金句卡；`--sub-*` 字幕；`--bot-*` 小机器人配色；`--mk` 圈注颜色

## 口播剪辑的八个模版

A 线叫“模版”，一共八个。一到四就是上面四种风格：讲要点、步骤、软件界面时，人缩到圆角小窗，卡片在旁边。五到八只有 A 线有：**人一直全屏、不缩小**，主要靠常驻标题和字幕动效，讲要点时卡片浮在人旁边、不挡脸，适合以说为主的口播。

挑的时候可以这样跟老板说：
> 讲要点多、要放软件截图的，选一到四，讲要点时你会缩到小窗；以说为主、想让你一直在画面里的，选五到八。要高级感选五，突出讲师身份选六，要电影感选七，要热闹选八。

- 五到八的片头会从头挂到尾当常驻标题；包装单里写“身份”，名字和头衔显示在标题下面。
- 双语字幕：字幕稿每行后面加“ | 英文”，八个模版都能显示，五最搭。
- 还没视频想先看看：`video_templates.py 项目 --示例` 用示意人像出八个模版的总览图。
