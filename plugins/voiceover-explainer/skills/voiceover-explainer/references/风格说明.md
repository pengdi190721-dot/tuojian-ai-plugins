# 风格说明

四种风格用的是同一套画面，只换颜色、字体、边框，所以**选风格不用重写画面**，改 `project.json` 里的“风格”就行。给老板挑的时候，用 `style_preview.py` 拿他自己的内容出四种风格的预览图和样片。

挑风格时可以这样问老板：
> 我用你的录音，把片头和第一个词做了四种风格的样片，你看哪种顺眼？投大屏的话黑金最有质感，日常发视频号清爽薄荷最耐看，想要冲击力就选大字报。

## 横版和竖版

- 横版 1920×1080：投大屏、电脑看。左边主讲词和标签，右边截图画框，下面字幕。
- 竖版 1080×1920：视频号、抖音。上面主讲词，中间截图画框，下面标签和字幕。
- 同一份 `scenes.html` 横竖版都能用（版位是自动的）。个别自己摆位置的元素，用 `data-vstyle="left:..;top:.."` 写竖版位置。
- 临时出另一种画幅：`render.py 项目 样片 0 20 --竖`。

## 想加新风格

在项目里新建一个 css 文件（比如 `my.css`），写一段 `:root{...}` 只改颜色变量，然后在 project.json 里加 `"自定义样式": "my.css"`，它会在所选风格之后加载、覆盖颜色。变量名可以在 `scripts/engine_assets.py` 的风格里查到。主要变量：
- `--bg / --stage-bg` 背景；`--ink` 正文字色；`--acc` 主色；`--acc-d` 主色文字；`--acc-s` 主色浅底；`--acc-m` 划重点底色
- `--card / --card-bd / --shadow / --radius` 卡片
- `--note-*` 标签；`--q*` 金句卡；`--sub-*` 字幕；`--bot-*` 小机器人配色；`--mk` 圈注颜色
