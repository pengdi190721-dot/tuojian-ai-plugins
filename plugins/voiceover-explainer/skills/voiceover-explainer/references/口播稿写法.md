# 口播稿写法

## 一、文件格式（script.txt）

```
# 片头
想把AI用明白，这几个词老板们一定要搞懂。
大模型、上下文、技能、连接器、专家，还有本地和云端。

# 大模型【章】
第一个词，大模型。
就在输入框右下角，点开是一排模型。
★所以选模型，先看活儿，再看价钱。
```

- `# 段名` 开始新的一段。段名后加 `【章】`，这一段会出现在画面顶部的进度条上（片头、比方、收尾一般不加）。
- **一行就是一句**，也是视频里的一句字幕。一句别超过 30 个字，太长就拆成两行。
- `★` 开头是金句：画面会压暗、弹出金句卡，前面会多停一下。每段最多一句。
- `//` 开头是备注，不念、不出字幕。
- 录音以后，`script.txt` 要改成**老板实际念的**（字幕跟声音一致）。改完要重新跑 `align_edit.py`。

## 二、写稿规矩（老板本人的说话方式）

1. 开头用真人原话或一个直接的判断，不用“你可能会说”这种假设。
2. 用“我们”跟老板站一边；说自己公司用“我们公司现在也在……”。
3. 句子别压太短，保留“明明、肯定、一定要、吧、啊”这些语气词，像人说话。
4. 金句用“是A，不是B”或“先A，再B”。
5. 指AI就写“AI”，少用“它”——口播里听不出“它”指谁。
6. 讲清背后的原因，别堆示范；往“训练企业AI”上拔一层。
7. 老板跟老板说话，点到为止，比如“这个道理带过人的都懂”。
8. 不要把员工当风险源；没有的成果不说成有；没验证过的数字不写。
9. 全程简体中文，除了 AI、产品名、人名，不出现英文单词。
10. 每段的顺序：**在哪 → 是什么（用比喻）→ 举个例子 → 金句**。

## 三、录音要求（发给老板）

- 每念完一句停半秒（帮助对齐，停长了没关系，会自动压短）。
- 念错了整句重来就行，后面能剪。
- 手机录就行：找安静的地方，嘴离手机一拳远，别开空调大风。
- 一段一个文件或整篇一个文件都可以；分段的话文件名带段号。
- mp3、m4a、wav，或者直接录视频发过来都行（会自动提取声音）。
