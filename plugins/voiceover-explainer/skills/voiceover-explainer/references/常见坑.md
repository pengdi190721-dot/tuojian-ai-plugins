# 常见坑（都是真踩过的）

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 一口气做完整片，老板说风格不对、顺序不对，全部重来 | 该停的地方没停 | 口播稿（第2步）、录音（第3步）、风格和横竖版（第4步）都要等老板回复 |
| 画面比声音早或晚 | 时间写死了秒数 | 全部改成 `at('段.行','关键词')` |
| `检查` 报“找不到「xx」” | 关键词和这句话的字不一样（录音后稿子改过） | 打开 `work/行号表.txt`，用这句话里原样有的字 |
| `build` 报“口播稿和录音时间表对不上” | 录音对齐以后又改了 script.txt | 重新跑 `align_edit.py` |
| 圈注圈歪了 | 坐标是猜的 | 用 `grid.py` 画网格，打开图读坐标；再用 `抽帧` 核对 |
| 有个角色的眼睛在别的段落里飘着 | 眨眼元素没放在 `.el` 里面 | 角色外层要有 `class="el"` 的容器，`blink` 加在 svg 上 |
| 字幕和声音差一截 | 录音里有念错重来的部分没剪 | 看 `对稿报告.txt` 第二部分，写 `剪掉.txt` 重新听写 |
| 对稿报告里全是错字 | 英文名、产品名被听成同音字 | 正常现象，不用改稿子；只管真念得不一样的句子 |
| 有一句话尾字被切掉半个 | 两句话连着说，没有停顿 | 已在脚本里处理（切点放在下一句开口前）；成片仍要抽听 |
| 竖版画面挤在一起 | 自己摆位置的元素只写了横版位置 | 加 `data-vstyle="left:..;top:.."` |
| 画框里两张图叠在一起 | 两个镜头/图解显示时间重叠 | 前一个的结束时间 = 后一个的开始时间 |
| 片头一排词跑出画面 | 词太多一行放不下 | 放在 `chips` 容器里会自动换行；词别超过8个 |
| 浏览器打不开 | 没装谷歌浏览器 | `check_env.py --install` 自动装（用国内镜像） |
| 模型下载失败 | GitHub 在国内慢 | `check_env.py --download` 会自动换镜像；还不行就手动下载放到 models 文件夹 |
| 成片里音效太吵 | 一句话里放了太多 `data-sfx` | 一句最多两三个；或改 `scripts/mix.py` 开头的 `VOL` |
| 金句卡出来时底下的字还在晃 | 金句前没压暗 | 金句卡前面加一个 `<div class="a dim el">`，时间一样 |
| 【A 线】剪辑点把字尾切掉一截 | 手机视频的声音比画面晚零点几秒开始，按声音算的剪辑点落到画面时间上就早了 | `video_prepare.py` 已经把声音补齐到和画面同一个起点；不要绕过它自己用 ffmpeg 剪 |
| 【A 线】4K 视频一剪就卡死、报内存不够 | 直接拿 4K 原片剪，几段一起解码 | 一律先跑 `video_prepare.py` 转成 1080 的工作视频，后面都用它 |
| 【A 线】小窗边上有一条黑边 | 脸太大，小窗要截的范围超出画面 | 已在引擎里限制；还出现就说明人脸检测框错了，看 `work/抽帧/` |
| 【A 线】`video_build.py` 说金句落在小窗段里 | 金句前后紧挨着要点卡 | 把要点卡的“从”往后挪一行，或金句少放一行 |
| 【A 线】要点卡把小窗挤住了 | 要点太多或字太长 | 最多 4 条、每条不超过 9 个字 |
| 【A 线】报“人脸检测文件找不到” | 装的是 opencv 5.x，去掉了人脸检测文件 | `check_env.py --install` 会装 4.x 版 |
| 【A 线】“念错重来”建议有误判 | 脚本只看字像不像，问句后面接答案也会被当成重来 | 建议只是参考，每条都要对照听写自己判断 |
