# 口播科普动画 v1.0.0

一句话：**老板录口播，AI用代码做动画。** 画面里的每个圈注、标签、卡片，都卡在老板说到那个词的那一刻出现。

这个技能里已经有一套做好的动画引擎、四种风格、一个完整示例（讲 WorkBuddy 七个词，4分17秒：[示例口播稿](references/示例口播稿.md)、[示例画面](references/示例画面.md)）。你的活儿是：**按五步走、该停的地方停下来等老板、写画面、跑脚本、自己检查。**

下面写的 `scripts/xxx.py` 都指**本技能目录里的 scripts**，运行时用完整路径；`项目` 指这条视频的项目文件夹（放在用户指定的位置，没指定就在当前工作目录下建一个）。

---

## 一、先记住这五条（做不好多半是违反了其中一条）

1. **该停就停。** 口播稿（第2步）、录音（第3步）、风格和横竖版（第4步），每一样都要等老板回复才往下做。不要一口气做完整片再给人看。
2. **画面跟着声音走，不跟着感觉走。** 所有时间都用 `at('段.行','关键词')` 写，绝对不要写死秒数。
3. **每个词的画面套路固定：** 先给软件全貌、圈出这个词在界面哪儿 → 再推近讲细节 → 中间插一张图解 → 最后一句金句弹黑卡。
4. **做完自己先看。** 每句话截一张总览图，一张张看完、改完，才能渲染全片。成片要重新听写一遍核对字幕。
5. **不编东西。** 没验证过的数字不写；你替老板写的举例，画面上要标“示例”；截图里有名字、电话、客户信息要打码。

---

## 二、五步流程

```
第1步 收想法和截图
第2步 确认口播稿（每段附画面对照，缺的截图让老板补）【停：等老板改稿、补截图】
第3步 老板录音上传【停：等录音】
第4步 听写对稿 → 做片头和第一个词 → 四种风格样片 + 横竖版预览【停：等老板选】
第5步 写全部画面 → 逐句自查 → 渲染全片 → 核对字幕 → 交付
```

所有脚本在 `scripts/` 里，用法：`python3 scripts/脚本名.py 项目目录 …`。需要在用户电脑上运行（WorkBuddy 选本地模式），第一次用先跑 `python3 scripts/check_env.py --install` 和 `python3 scripts/check_env.py --download`（装程序、下语音识别模型，模型约230MB，只下一次）。可以在第1、2步等老板回复的时候顺手装好。

想先看看做出来什么样：`python3 scripts/example_project.py 示例目录` 放出示例项目，再跑 `render.py 示例目录 样片 36 60`。

### 第1步 收想法和截图

- 老板会发：想讲的大致内容（一段话、语音转文字、提纲都行），可能还有一些截图。
- 新建项目：`python3 scripts/new_project.py 项目目录`，截图放进 `项目/assets/`（文件名改成能看懂的英文或拼音，比如 home.png、models.png）。
- 内容里没说清的，只问最关键的一两个：**给谁看**（老板？员工？）、**投哪儿**（大屏用横版，视频号用竖版，不确定就第4步再定）。能自己判断的不要问。

### 第2步 确认口播稿【停】

按 [分镜模版](references/分镜模版.md) 写一份给老板看，包括：

1. **贯穿全片的比喻**（示例里是“把AI当成公司新招的员工”：大模型＝脑子，技能＝规矩……）。有比喻，观众才记得住。
2. **口播稿**，按段写，格式和说话规矩见 [口播稿写法](references/口播稿写法.md)。每段 5–10 句，最后一句金句。
3. **每段后面附一行画面对照**：这段配哪张截图、圈哪里、插什么图解。老板一看就知道画面能不能对上。
4. **截图清单**：哪些已经有了、**还缺哪些**（写清楚截哪个页面、要不要点开下拉）。
5. **标出你拿不准的地方**：没验证过的说法、你替他编的例子。

**停。等老板改稿、补截图。** 老板改完，按他的版本写进 `script.txt`（每行一句、一句别超过30个字、金句标★），补来的截图放进 `assets/`。缺的截图没到齐，就继续请他补，到齐了再往下。

稿子定了，把录音要求发给老板：**每念完一句停半秒；整篇一个文件或一段一个文件都行；念错了整句重来；手机录就行，安静、离一拳远；mp3、m4a、wav 或直接发视频都行。**

### 第3步 收录音【停】

**停。等老板发录音。** 收到后放进项目目录，在 `project.json` 的“录音文件”写上文件名（分段录的，按顺序拼成一个文件再用）。

### 第4步 听写对稿 → 风格样片 → 老板选风格和横竖版【停】

1. **听写对稿**：
   - `python3 scripts/transcribe.py 项目`，再 `python3 scripts/align_edit.py 项目`。
   - **打开 `work/对稿报告.txt` 认真看**：
     - 英文名、产品名被听成同音字（WorkBuddy 听成“乌克巴德”）不用管；老板真念得不一样的，把 `script.txt` 改成他实际念的（字幕要跟声音一致），重新跑 `align_edit.py`。
     - 多出来的话（念错重来、口误）：把要剪掉的时间段写进 `work/剪掉.txt`，重新跑 `transcribe.py` 和 `align_edit.py`。
     - 提示“这几句好像没念”：要么删掉这句，要么请老板补录，不要硬做。
   - `align_edit.py` 会自动调节奏：内容一句不剪、语速不动；句间停顿压到 0.22–0.55 秒；换段前停 1.05 秒；★金句前至少停 0.55 秒；音量拉平。成片会比原录音长一点，这是给画面留进场时间。
2. **做片头和第一个词**：`python3 scripts/new_project.py 项目 --画面骨架` 生成 `scenes.html` 骨架，先只把**第1段和第一个词那段**写完整（写法见 [画面写法](references/画面写法.md)，照着 [示例画面](references/示例画面.md) 写；圈注坐标的读法见下面第5步）。跑 `python3 scripts/render.py 项目 检查`，必须“检查通过”。
3. **出样片**：
   - 横版四种风格预览图：`python3 scripts/style_preview.py 项目 --秒 3到4个关键时刻`
   - 竖版四种风格预览图：同上加 `--竖`
   - 四种风格动态样片（带老板自己的声音）：`python3 scripts/style_preview.py 项目 --秒 1个时刻 --片段 开始秒 结束秒`（选第一个词里最热闹的10秒左右；老板说过投视频号就加 `--竖`）
4. **停。把 `out/风格预览.jpg`、`out/风格预览_竖版.jpg`、`out/风格样片.mp4` 发给老板，问：选哪种风格？横版还是竖版？哪里不喜欢？** 四种风格怎么介绍见 [风格说明](references/风格说明.md)。顺便用一两句话告诉他：哪几处字幕按他实际念的出。
5. 老板选定后写进 `project.json` 的“风格”和“画幅”。他提的修改意见（颜色、字大小、某个动画）先改好再往下。

### 第5步 制作和交付

1. **写全部画面**：
   - 照第2步的画面对照把每段写完，规矩见 [画面写法](references/画面写法.md)，组件从 [组件库](references/组件库.md) 复制，参考 [示例画面](references/示例画面.md)。
   - 圈注坐标先跑 `python3 scripts/grid.py 项目` 给截图画网格，打开 `work/网格/` 里的图读坐标。**必须打开图看，不要猜坐标。**
   - 写画面时对照 `work/行号表.txt`（每句话的“段.行”编号和时间）。每写完一段就跑一次 `render.py 项目 检查`，直到“检查通过”。
2. **逐句自查（不能跳过）**：
   - `python3 scripts/render.py 项目 总览` → `work/抽帧/总览_xx.jpg`，每句话一张截图。
   - **一张一张打开看**，对照 [质检清单](references/质检清单.md)：字有没有被挡、圈注圈没圈对地方、画面和这句话说的是不是一回事、有没有空白太久的画面、字幕有没有超过两行。
   - 有问题改 `scenes.html`，再出总览，直到全部过关。拿不准的地方用 `render.py 项目 抽帧 秒数` 单独看，或 `render.py 项目 样片 开始秒 结束秒` 看动起来的效果。
3. **渲染全片 + 核对**：
   - `python3 scripts/render.py 项目 全片`（逐段渲染，4分钟的片子大约10分钟）
   - `python3 scripts/finish.py 项目`：配音效、合成 `out/成片.mp4`，再把成片重新听写一遍，逐条核对字幕。出现“【要看】”的字幕，去对应秒数看一眼。
4. **交付**：
   - 发 `out/成片.mp4` 和 `out/字幕.srt`（老板后期剪辑能改字）。
   - 一段话说清楚：多长、什么风格、做了哪些调整（节奏、字幕按实际念的、打码）、**哪些是你替他写的示例**、背景音乐没加（要他后期自己加，并压低别盖过人声）。
   - 可以顺手给：标题、话题标签、封面文字。
