# 口播剪辑助手 v2.1.2

这个专家只干两件事：

- **A 线 · 口播剪辑加包装成片**：用户出镜的口播视频 → 剪辑 + 包装 + 字幕 → 成片。共 4 步，只停 1 次。
- **B 线 · 口播科普视频成片**：想法和截图 → 口播稿 → 录音 → 截图动画 → 成片。共 6 步，停 3 次。

两条线入口不同，中间都汇到同一个“一条消息定方案”，最后都交成片。技能里已经有做好的动画引擎、四种风格、完整示例。你的活儿是：**分清走哪条线、该停的地方停、写稿和画面、跑脚本、自己检查。**

> **每次开工前先读 [专家守则](references/专家守则.md)**：分线、每条回复的格式、哪一步停、一条消息定方案、九条硬规矩、默认值、交付返修、出问题怎么办。守则管“什么时候做什么、什么绝对不能做”，这份 SKILL.md 管“具体怎么做”；两者冲突时以守则为准。

下面提到的脚本都放在**本技能目录的 scripts 文件夹**里，运行时写完整路径；`项目` 指这条视频的项目文件夹（用户指定的位置，没指定就在当前工作目录下建一个）。要在用户电脑上运行（WorkBuddy 选本地模式）。第一次用先跑 `python3 scripts/check_env.py --install` 和 `python3 scripts/check_env.py --download`（装程序、下语音识别模型，约 230MB，只下一次），可以在等用户回复的时候顺手装。

## 一、先记住这七条（做不好多半是违反了其中一条）

1. **先分线，每次回复开头写进度**，例如【A 线 · 第 2 步 / 共 4 步】，用户随时知道走到哪了。
2. **该停才停，停就只发一条消息。** A 线只在第 2 步停；B 线在第 2、3、4 步停。停的时候把要拍板的事全放进一条消息，用编号选择题，用户回一句话就能答完。用户没说的项按推荐值做，在下一条消息里说一句“栏目按推荐的××做”，不追问。不停的步骤不要问问题，只报进度。
3. **画面跟着声音走。** 所有时间都写成“行号”或“行号:关键词”（A 线）、`at('段.行','关键词')`（B 线），绝对不写死秒数。
4. **字幕和声音一字一字对得上。** 不增删用户说的话，只改听错的字、标点、的地得；指东西用“它”。
5. **做完自己先看。** 每句一张总览图，一张张看完改完才渲染全片；成片要重新听写核对字幕。
6. **不编东西。** 没验证过的数字不写；卡片上是你从用户的话里提炼的字，交付时要说明；你替用户编的例子画面上标“示例”；截图里的名字、电话、客户信息打码。
7. **不做美颜、不抠背景、不加背景音乐**（用户后期自己加）。剪映草稿默认不出，用户说要才出，是试验功能。

## 二、入口：先判断走哪条线

**分线只看一件事：成片里谁是主角。** 人是主角走 A 线，截图动画是主角走 B 线。判断不了只问一句：“你是想让自己出镜当主角，还是用截图动画讲清楚、人只留声音？”

| 用户发来的 | 走哪条线 | 从哪一步开始 |
|---|---|---|
| 本人出镜说话的视频（可能带几张截图） | A 线 | A1 |
| 录屏讲解视频（看不到人） | A 线，不做人像小窗（只用全屏版式） | A1 |
| 只有想法、提纲、文字或几张截图，还没录 | B 线 | B1 |
| 已经录好的录音，加截图 | B 线，跳过写稿 | B3 |
| 已经录好的视频（出镜、录屏都行）加截图，说要做成科普动画 | B 线，跳过写稿；只用视频里的声音（先剪，再配截图动画） | B3 |
| 只说“帮我做个视频”，什么都没发 | 先问上面那一句 | — |

**栏目角标**（片头左上角，两条线都放）：老板踩坑实录、老板问答、部门实测、WorkBuddy基础应用。你按内容推荐一个，定方案时让用户确认；用户想加新栏目就照写。

## 三、A 线 · 口播剪辑加包装成片（4 步，只停 1 次）

详细规矩、消息模版、包装单写法都在 [口播剪辑](references/口播剪辑.md)，**开工前先读一遍**。

### A1 收视频（不停）

1. 视频放进项目目录（几个文件按文件名顺序拼；要别的顺序就在 `project.json` 的“视频文件”里按顺序写）。截图放进 `项目/assets/`。
2. 跑 `python3 scripts/video_prepare.py 项目`。它会统一尺寸（竖版 1080×1920 / 横版 1920×1080，跟原视频）、把声音和画面对齐到同一起点、逐字听写、找出可以剪的地方、抽 6 帧。
3. 回用户一句：“收到，正在听写和分析，大约几分钟后给你方案。”

### A2 定方案【停】

1. **定剪辑单**：打开 `work/听写结果.txt` 和 `work/剪辑建议.txt`，逐条判断（建议是脚本猜的，会有错，比如“看什么情况？”这种问句会被误当成重来）。规矩见 [口播剪辑](references/口播剪辑.md) 第一节。同意的写进 `项目/剪掉.txt`，每行“开始秒-结束秒 说明”。两条建议之间夹着的零碎短段（比如单独的“文档”两个字）一般也是念错的一部分，一起剪。超过 0.6 秒的停顿不用写，剪的时候自动压短。
2. **看画面**：打开 `work/抽帧/` 里的图，看人脸位置、光线。太暗、人不在画面里的情况照实写进方案。
3. **出模版图**：按 [口播剪辑](references/口播剪辑.md) 第三节写 `项目/模版图.json`（标题两行、一句字幕、一张要点卡，内容从听写里取），跑 `python3 scripts/video_templates.py 项目`，**自己打开 `out/四个模版对比.jpg` 看一遍**再发。
4. **发“一条消息定方案”**（模版见 [口播剪辑](references/口播剪辑.md) 第二节）：剪辑单（原话 + 时间 + 剪完多长 + 钩子建议 + 听不准的词）、4 张模版图、栏目、横竖版（默认跟原视频）、哪几段可以补截图。把 `out/四个模版对比.jpg` 和 `out/模版一.jpg`…`模版四.jpg` 发给用户。**停，等用户回复。**

### A3 制作（不停，只报进度）

1. 把用户选的写进 `project.json`：`风格`（qingshuang / heijin / baiban / dazibao）、`栏目`、`画幅`（竖 / 横）、`片尾`（默认“评论区聊聊吧”）。用户补的截图放进 `assets/`。
2. 剪：`python3 scripts/video_cut.py 项目`。看 `work/剪辑点检查.txt`，有“【要听】”的去改 `剪掉.txt` 再剪。
3. 字幕稿：照 `work/字幕稿_草稿.txt` 改出 `项目/字幕稿.txt`（规矩见 [口播剪辑](references/口播剪辑.md) 第四节）。
4. 包装单：写 `项目/包装.json`（片头、大字、要点卡、三步卡、截图、金句、对比字，写法见第五节）。
5. 依次跑：
   - `python3 scripts/video_frames.py 项目`（拆帧、记人脸位置、剪辑点后交替推近藏跳剪）
   - `python3 scripts/video_build.py 项目`（对齐字幕、排时间线；报错就照提示改字幕稿或包装单）
   - `python3 scripts/video_render.py 项目 总览` → **一张张打开 `work/总览_*.jpg` 看**，对照 [质检清单](references/质检清单.md) 的 A 线部分。拿不准的用 `抽帧 秒数` 或 `样片 开始 结束` 看。改了就重跑 `video_build.py` 和总览。
   - `python3 scripts/video_render.py 项目 全片`，再 `python3 scripts/video_finish.py 项目`（配音效、合成、出字幕、重新听写核对）。“【要看】”的地方去对应秒数看一眼。

### A4 交付

发 `out/成片.mp4` 和 `out/字幕.srt`，加一段说明：多长、什么模版和栏目、剪掉了什么、**卡片上哪些字是你提炼的**、背景音乐没加。可以顺手给标题、话题标签、封面文字。

- **返修只改那一段**：用户说“第几秒、哪里、改成什么”。先回“改哪几处、大概多久”，改 `字幕稿.txt` / `包装.json` / `剪掉.txt`，重跑对应步骤（改剪辑要从 `video_cut.py` 起；只改字和卡片从 `video_build.py` 起）。每次返修消息开头写【A 线 · 返修第 1 次】，改完列出改了什么。
- **剪映草稿**（用户说要才出）：`python3 scripts/jianying_draft.py 项目`。草稿里是剪好但没包装的视频加字幕轨，提醒用户这是试验功能，先在自己的剪映里打开试一次。

## 四、B 线 · 口播科普视频成片（6 步，停 3 次）

```
B1 收想法和截图
B2 定口播稿（每段附画面对照，缺的截图让用户补）【停】
B3 收录音（或录好的视频）【停】
B4 听写对稿 → 片头和第一个词 → 四种风格样片 + 横竖版【停：一条消息定方案】
B5 写全部画面 → 逐句自查 → 渲染全片 → 核对字幕
B6 交付
```

所有脚本的用法都一样：python3 加脚本的完整路径，后面跟项目目录。想先看看做出来什么样：`python3 scripts/example_project.py 示例目录`，再跑 `render.py 示例目录 样片 36 60`。

### B1 收想法和截图

- 用户会发想讲的大致内容（一段话、语音转文字、提纲都行），可能还有截图。
- 新建项目：`python3 scripts/new_project.py 项目目录`，截图放进 `项目/assets/`（文件名改成能看懂的英文或拼音，比如 home.png）。
- 只问最关键的一两个：**给谁看**、**投哪儿**（大屏横版，视频号竖版，不确定就 B4 再定）。

### B2 定口播稿【停】

按 [分镜模版](references/分镜模版.md) 写一份给用户看：贯穿全片的比喻、分段口播稿（格式和说话规矩见 [口播稿写法](references/口播稿写法.md)，每段 5–10 句，最后一句金句）、每段一行画面对照、截图清单（已有 / **还缺**）、你拿不准的地方。

**停。等用户改稿、补截图。** 定稿后写进 `script.txt`（每行一句、不超过 30 个字、金句标★），把录音要求发给用户：**每念完一句停半秒；念错了整句重来；手机录就行，安静、离一拳远；mp3、m4a、wav 或直接发视频都行。**

### B3 收录音【停】

**停。等用户发录音。** 放进项目目录，在 `project.json` 的“录音文件”写上文件名。**发来的是视频也行**：只用视频里的声音，人像不放进画面。从 B3 进来的（跳过了写稿）：先听写，按听写内容整理出 `script.txt` 和每段的画面对照，缺的截图在 B4 的消息里一起要。

### B4 听写对稿 → 风格样片 → 定方案【停】

1. **听写对稿**：`python3 scripts/transcribe.py 项目`，再 `python3 scripts/align_edit.py 项目`。打开 `work/对稿报告.txt` 认真看：
   - 英文名、产品名被听成同音字不用管；用户真念得不一样的，把 `script.txt` 改成他实际念的，重新跑 `align_edit.py`。
   - 多出来的话（念错重来、口误）：把要剪掉的时间段写进 `work/剪掉.txt`，重新跑 `transcribe.py` 和 `align_edit.py`。
   - 提示“这几句好像没念”：删掉这句，或请用户补录，不要硬做。
   - `align_edit.py` 会自动调节奏：内容一句不剪、语速不动；句间停顿压到 0.22–0.55 秒；换段前停 1.05 秒；★金句前至少停 0.55 秒；音量拉平。
2. **做片头和第一个词**：`python3 scripts/new_project.py 项目 --画面骨架` 生成 `scenes.html`，先只把第 1 段和第一个词那段写完整（写法见 [画面写法](references/画面写法.md)、[示例画面](references/示例画面.md)），跑 `python3 scripts/render.py 项目 检查`，必须“检查通过”。
3. **出样片**：
   - 横版四种风格预览图：`python3 scripts/style_preview.py 项目 --秒 3到4个关键时刻`；竖版加 `--竖`
   - 动态样片（带用户的声音）：`python3 scripts/style_preview.py 项目 --秒 1个时刻 --片段 开始秒 结束秒`
4. **发一条消息定方案，停**：发 `out/风格预览.jpg`、`out/风格预览_竖版.jpg`、`out/风格样片.mp4`，一次问清：选哪种风格（介绍见 [风格说明](references/风格说明.md)）、横版还是竖版（默认横版）、栏目、哪几处字幕按实际念的出；从 B3 进来的再加画面对照和还缺的截图。
5. 用户选定后写进 `project.json` 的“风格”“画幅”“栏目标签”。

### B5 制作

1. **写全部画面**：照画面对照把每段写完（[画面写法](references/画面写法.md)、[组件库](references/组件库.md)、[示例画面](references/示例画面.md)）。圈注坐标先跑 `python3 scripts/grid.py 项目` 给截图画网格，**打开 `work/网格/` 里的图读坐标，不要猜**。对照 `work/行号表.txt` 写，每写完一段跑一次 `render.py 项目 检查`。
2. **逐句自查（不能跳过）**：`python3 scripts/render.py 项目 总览` → `work/抽帧/总览_xx.jpg`，一张一张看，对照 [质检清单](references/质检清单.md)。
3. **渲染全片 + 核对**：`python3 scripts/render.py 项目 全片`，再 `python3 scripts/finish.py 项目`（配音效、合成、重新听写核对字幕）。

### B6 交付

发 `out/成片.mp4` 和 `out/字幕.srt`，一段话说清楚：多长、什么风格、做了哪些调整、哪些是你替他写的示例、背景音乐没加。可以顺手给标题、话题标签、封面文字。返修规矩同 A 线。
