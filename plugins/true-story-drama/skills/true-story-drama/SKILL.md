# 真实故事短剧化

把真实素材变成有戏的故事，但不把戏剧化变成造谣、硬造反转或消费当事人。

## 默认交付

信息足够时直接完成，不反复追问。只有缺口会改变事实边界、人物身份暴露、核心结局或改编尺度时，
才一次询问一个问题。

用户未指定时，默认：

- 单集、竖屏、60—90秒；
- 中等戏剧化，人物与机构匿名；
- 给出三个机制不同的简短方向，选出推荐方向并继续写完整稿；
- 交付可编辑脚本、分镜与AI视频提示词，不宣称已经拍摄、生成或发布。

## 四条硬规则

1. **先分事实，再写戏。** 写作前读取[事实与改编边界](references/truth-contract.md)，区分已核实事实、当事人记忆或感受、转述或争议信息、可创作空白。
2. **冲突从真实压力中长出来。** 使用目标冲突、制度限制、关系边界、时间压力、艰难选择和选择代价；不得为了“有戏”凭空制造坏人、秘密或恶意动机。
3. **反转不是必选项。** 没有真实反转时，可以通过信息重排、观众理解变化、人物选择变义或情绪回收形成转折；不得硬造身份、罪行、背叛、疾病、债务或其他可核验事件。
4. **所有改动可追溯。** 压缩、调序、合并人物、重构对白、补过场和虚构演绎都写入改编台账；不能把重构对白冒充逐字原话。

## 工作流

### 1. 建立事实底稿

保留用户原始材料，不覆盖原文。列出：

- 不可改变的事实、人物关系、关键选择和结局含义；
- 当事人的主观感受与记忆；
- 尚未证实、存在争议或仅为转述的信息；
- 用户明确允许压缩、合并、调序或重构的范围；
- 需要匿名、模糊或取得确认的身份信息。

未得到用户确认时，不保留真实姓名、公司名、精确地址、联系方式和足以单独识别普通人的组合信息。

### 2. 找到真正的戏剧发动机

读取[戏剧化开发](references/dramatic-development.md)。先判断原故事为什么平，再寻找最值得进入的时刻：
人物原有做法开始付出代价、必须作选择，或一个旧事实改变当前关系的地方。

三个候选方向必须改变冲突机制，例如：

- 人物目标与制度/现实限制冲突；
- 两个都可以理解的关系目标冲突；
- 人物旧信念与眼前选择冲突。

不能只换标题、职业、语气或把同一场争吵写得更大声。

### 3. 写成可拍剧本与AI视频执行稿

读取[脚本与分镜格式](references/script-and-shot-format.md)。让每场至少改变信息、权力、关系、情绪、风险或物理状态之一，并用以下因果链组织：

```text
因为已有事实 -> 人物采取行动 -> 产生可见结果 -> 形成下一股压力
```

对白用于争取、回避、试探、拒绝、逼迫或重新定义关系，不用所有人物轮流解释背景。
分镜和提示词只实现剧本已有事实，不新增人物、台词、证据、奇观或结局。

### 4. 交付前静默三检

读取[审查标准](references/review-rubric.md)，依次检查：

1. 事实、隐私、名誉和改编台账；
2. 因果、人物选择、冲突升级、局部回报与结尾；
3. 口语、人味、可表演性、可拍性和AI生成连续性。

发现硬伤时直接修正；只有真实剧情分叉或身份暴露需要用户决定。最终明确标记为“可编辑待确认”，
不能把脚本、提示词或项目文件说成已经生成的成片。

## 默认输出顺序

1. 一句话判断；
2. 事实底稿；
3. 原故事平铺直叙的原因；
4. 三个戏剧化方向与推荐方向；
5. 故事发动机：人物目标、阻力、选择、代价、转折、局部回报；
6. 完整可拍短剧脚本；
7. 角色一致性卡与逐镜分镜；
8. 每个镜头的AI视频提示词；
9. 原故事与改编内容对照台账；
10. 事实、隐私、名誉、因果和制作审查结论。

用户只点名其中一项时，只交付点名范围。用户已有明确方向时，不为凑数重复生成三个方向。

## 保存到项目时

只有用户要求保存、继续做系列或生成可编辑项目时才落盘。使用技能自带模板，保存为：

```text
真实故事短剧化/<项目名>/
├── 01-事实底稿.md
├── 02-改编方案.md
├── 03-短剧脚本.md
├── 04-分镜与AI提示词.md
├── 05-改编台账.md
└── 06-审查报告.md
```

模板位于 `assets/`：

- `story-intake-template.md`
- `adaptation-ledger-template.md`
- `script-package-template.md`
- `review-template.md`

## 边界

- 不替用户确认未经证实的信息，不替当事人授权公开身份。
- 不因为“基于真实故事”就假设所有细节真实；证据不足时保留未知。
- 不直接生成图片、视频、配音或发布内容；用户另行明确要求后，再调用相应能力。
- 涉及未成年人、医疗健康、亲密关系、犯罪指控、重大财务纠纷或可识别普通人时，默认提高匿名等级；无法安全改编时说明风险并暂停公开版输出。
