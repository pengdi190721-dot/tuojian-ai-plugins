# GPT Image 2与Seedance图生视频工作流

核验日期：2026-09-01

本工作流默认把用户所说的“image2”理解为OpenAI的GPT Image 2，模型标识为 `gpt-image-2`。若用户所在平台把“image2”用于另一款模型，先确认具体模型，再改写模型专用规则。

## 一、总原则

每个镜头分两步：

1. GPT Image 2负责确定人物、服装、场景、构图、光线、物件和镜头起始状态；
2. Seedance负责让已确认的图片动起来，控制动作、镜头、节奏、声音和结束状态。

不要用一条提示词同时承担“重新设计画面”和“让画面运动”两个任务。

## 二、GPT Image 2图片提示词

OpenAI官方建议使用清楚、具体的自然语言，说明用途、主体、动作、场景和风格；构图、光线或限制重要时直接写明。迭代时一次只改一个问题，并反复声明必须保持不变的内容。

### 每个镜头的提示词结构

```text
用途：这是竖屏真实故事短剧第【镜号】镜的图生视频首帧。
场景：【地点、时间、稳定空间关系和关键物件】。
主体：【角色化名＋稳定外观锚点＋服装】。
起始状态：【视频开始前一刻的可见姿势、视线、手部和物件状态】。
构图：【景别、机位、主体位置、前中后景、为后续动作预留的空间】。
光线与色彩：【光源方向、明暗关系、色温和情绪】。
视觉风格：【写实、纪实、电影或用户指定风格】。
连续性：严格保持【人物脸型、发型、服装、道具数量、场景布局】与已确认参考图一致。
限制：不要出现【多余人物、字幕、水印、标识、畸形手指、重复肢体、错误道具和剧情外信息】。
```

最终交付时把字段替换成一段可直接复制的自然语言，不保留空占位。

### 生成参数建议

参数与提示词分开列出：

- 竖屏短剧优先使用9:16；界面支持自定义尺寸时，可使用 `1152x2048`；不支持时选择最接近的竖版尺寸，并把人物与关键动作放在中央安全区；
- 快速试构图可以使用低质量；人物近景、身份一致性和最终首帧优先使用中等或高质量；
- 有已确认角色图时，把它作为人物参考，并明确“只控制脸部、发型和服装”，不要让参考图背景覆盖当前场景；
- 同一镜头返修时，写“只修改一个问题，其他内容保持不变”，避免整张图漂移。

### 图片要为运动服务

- 使用动作发生前或动作刚开始的稳定状态，不用已经完成动作的终点图；
- 主体周围为移动、转身、抬手或推拉镜头预留空间；
- 关键手部、道具和视线尽量清楚可见；
- 同一角色跨镜重复完全相同的稳定外观锚点；
- 没有授权还原真实人物时，生成虚构化外观，不声称像本人；
- 视频首帧默认不嵌入字幕、对白和复杂屏幕文字，准确文字留给后期；
- 多张参考图只保留必要的小集合，明确“图1控制人物、图2控制场景、图3控制风格”，不要让参考职责互相冲突。

### 图片验收

生成图片后至少检查：

1. 人物身份、数量、服装和脸部是否一致；
2. 手指、四肢、道具数量和持有关系是否正确；
3. 场景布局、镜头方向和光线是否能接前后镜；
4. 是否有多余文字、标识、水印或剧情外信息；
5. 当前姿势是否给后续动作留出了真实运动空间；
6. 是否暴露真实人物或机构的敏感信息。

图片没有通过验收时，只改图片提示词，一次修一个主要问题，不急着进入视频。

## 三、Seedance图生视频提示词

Seedance的首帧模式把已确认图片作为精确起始状态。视频提示词不重复长篇描述图片已有内容，重点告诉模型“接下来发生什么”。

### 最终提示词结构

```text
@Image1（已确认的镜头图）是精确首帧，保持其中的人物身份、服装、场景布局、道具数量和光线方向不变。

主体动作：【谁先做什么，动作速度、幅度、路径和因果顺序】。
细微表演：【视线、呼吸、停顿、手部、姿态和表情变化】。
环境运动：【只写需要运动的头发、衣料、窗帘、雨、灯光或背景元素】。
摄影机：【起始景别＋一个主要运动＋结束景别，说明拍摄对象和方向】。
声音：【明确对白说话人、原声旁白策略、环境声、音效、音乐或静音】。
结束状态：【人物、道具、视线和画面最终停在哪里，用于连接下一镜】。
连续性限制：不增加人物和道具，不交换人物位置和台词，不改变脸部、服装和场景，不生成字幕或水印。
```

### Seedance写法要求

- 一个短镜头只安排一个主要动作和一个主要摄影机运动；动作密度过高时拆镜；
- 动作必须按时间和因果顺序写，不把多个互相冲突的镜头运动堆在一句里；
- 抽象情绪改成可观察表演，例如“她害怕”改成“她看向门口，手停在发送键上，呼吸变浅”；
- 只有逐字稿或录音能支撑的对白才可标为原话；重构对白仍需进入改编台账；
- 如果后期使用主人公采访原声，视频提示词默认写“无人物对白，只保留自然环境声，不生成字幕，为后期原声旁白留空间”；
- 如果由Seedance生成对白，写明说话人和准确台词，其他人物保持自然沉默；
- 使用首帧和尾帧时，分别明确 `@Image1` 和 `@Image2` 的职责，并只描述两个状态之间的连续变化；
- 生成参数单独列出，不把模型版本、画幅、清晰度和接口参数混入创作提示词。

### 生成参数建议

- 模式：使用已确认图片作为首帧的图生视频；
- 时长：单镜头通常先用4—8秒验证动作，动作确实需要时再加长；
- 画幅：跟随已确认图片，竖屏项目保持9:16；
- 清晰度：动作测试可先用720p，确认后且平台支持时再用1080p；
- 模型版本：用户明确Seedance版本时按该版本能力输出；未明确时只使用Seedance 2.0与2.5都能理解的通用图生视频写法，不冒充版本专属参数。

## 四、草案与最终版的区别

在图片尚未生成或尚未确认时，可以按分镜输出“Seedance视频提示词草案”，但必须标明：

> 这是基于分镜的动作草案。图片确认后，需要根据实际姿势、构图和运动空间重新定稿。

用户上传或确认图片后：

1. 先复述实际首帧状态；
2. 判断图片是否适合图生视频；
3. 有硬伤时先让图片返修；
4. 图片通过后，再输出一条干净、可直接复制的Seedance最终提示词；
5. 默认一次先验证一个镜头，用户明确要求批量时再批量。
