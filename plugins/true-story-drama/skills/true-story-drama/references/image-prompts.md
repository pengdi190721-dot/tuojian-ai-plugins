# 图片提示词：人物定妆图、场景图、定帧图

剧本确认后才出图片提示词。三类图按顺序出，后面的图要用前面的图做参考：

```text
人物定妆图（锁住人长什么样）
        ↓
场景图（锁住地方长什么样）
        ↓
定帧图（每段视频的第一帧，人放进场景里）
        ↓
视频提示词（让定帧图动起来）
```

## 一、统一写法：每张图分两步

**第一步：参考素材及用途。**列清楚这张图要连哪些参考图、每张参考图管什么、不照搬什么、冲突时听谁的。上传、连线、存进主体库这些操作说明，全放在这一步。

**第二步：能整段复制的提示词。**只写给模型看的内容，放进一个单独的文本块。块里不放操作说明、不提问、不写验收项。所有占位内容替换完再交。

## 二、给每张图起素材名

素材名全项目统一，后面的定帧图和视频提示词都用这个名字点名：

| 类别 | 素材名示例 |
|---|---|
| 人物定妆图 | 人物-老周-三视图 |
| 人物表情图（可选） | 人物-老周-表情 |
| 场景图 | 场景-车间-夜 |
| 定帧图 | 定帧-03（对应视频第3段的开头） |

## 三、人物定妆图

每个有台词或反复出镜的人物一张三视图：正面、侧面、背面全身，并排在一张图里。

- **用横版16:9出三视图**，其他比例三个视图容易挤或变形；
- 外形描述**一字不改地照抄人物小传里的外形锁定串**；
- 纯色浅背景，光线均匀，不带场景；
- 三个视图同一个人、同一套衣服、同样比例；
- 生成满意后，在LibTV里存进主体库，名字用素材名，有需要时一并设好音色（这句是操作说明，放第一步）；
- 同一个人有不同年龄段、不同服装，每一套单独出一张，素材名标清楚（人物-老周-年轻时-三视图）。

**主角情绪戏多时**，可以加一张表情图：同一个人的九个表情（平静、皱眉、强忍、松口气、笑、哭、愣住、生气、疲惫）排成九宫格，每格编号。后面定帧图需要某个表情，就写“只参考人物-老周-表情第5格的表情，不带格子里的其他东西”。

提示词样子（替换成实际内容）：

```text
人物设定三视图，横版16:9，浅灰色纯色背景，同一个人物的正面、侧面、背面全身像从左到右并排，三个视图大小一致，站姿自然，双手自然下垂。
人物：五十多岁的中国男性，身材偏瘦，短寸头两鬓花白，脸窄、颧骨明显，眼角皱纹深，穿深蓝色旧工装外套，袖口磨得发白，里面是灰色圆领毛衣，深灰色工装裤，黑色劳保鞋。
风格：写实电影质感，柔和均匀的棚拍光，面部和衣服纹理清晰。
限制：画面里不出现任何文字、标注、水印；三个视图是同一个人、同一套衣服；不添加设定里没有的配饰。
```

## 四、场景图

每个场景一张空景，不放人。场景图锁住的是：空间布局、关键家具和道具的位置、光线方向和颜色。

- 写清楚左、中、右，前、中、后各有什么；
- 关键物件写清楚状态（刻字机开着、桌上一块奖牌、墙上钟的位置）；
- 光源方向写死（左侧一盏台灯、头顶日光灯），后面所有定帧图都沿用；
- 年代、地区对得上：九十年代的乡镇不能出现智能手机和新式招牌；
- 场景里的字（招牌、标语、文件）默认不出，后期再加。

提示词样子：

```text
竖版9:16，写实电影质感。小型奖牌加工车间，深夜，空景，画面里没有人物。
布局：画面左侧靠墙一台刻字机，机器前一张铁皮工作台，台面上放着一块金色奖牌和一副老花镜；画面中间是过道，地上有少量金属屑；画面右后方是一扇关着的卷帘门。
光线：只有工作台上方一盏黄色吊灯亮着，光从上往下打，车间其余地方偏暗，冷暖对比明显。
限制：不出现人物、文字、招牌字、水印；陈设是普通小作坊的样子，不要高档厂房。
```

## 五、定帧图

定帧图是每段视频的第一帧。一段视频一张，视频怎么动，就从这张图开始动。

- 用人物定妆图锁人，用场景图锁地方，在第一步里写清楚“图几管什么”；
- **只画一个瞬间**，而且是**动作开始前一刻**，不画动作做完的样子；
- **给动作留空间**：人要转身，身后得有地方；镜头要推近，主体不能已经顶满画面；
- 人物外形照抄锁定串，不重新描述；
- 关键的手、物件、视线要清楚可见；
- 默认不出字幕、对白和复杂的屏幕文字；
- 定帧图之间要能接上：上一段视频的结束状态，就是下一张定帧图的起始状态。

提示词样子：

```text
竖版9:16，写实电影质感，短剧第1段的开头画面，单一瞬间。
场景：沿用图2的车间布局和光线，镜头在工作台正前方略偏右，吊灯在画面上方。
人物：图1里的人物，五十多岁的中国男性，身材偏瘦，短寸头两鬓花白，脸窄、颧骨明显，眼角皱纹深，穿深蓝色旧工装外套，袖口磨得发白，里面是灰色圆领毛衣，深灰色工装裤，黑色劳保鞋。他坐在工作台前，上身前倾。
起始状态：他右手拿着那块金色奖牌凑到吊灯下，左手扶着老花镜，眼睛盯着奖牌上的字，嘴唇微微张开，手还没放下。
构图：中近景，平视，人物在画面右侧三分之一处，左侧留出刻字机和台面，人物头顶上方留出空间。
情绪：愣住，眉头刚开始往中间拧。
限制：画面里只有他一个人；不出现文字和水印；人物外形、服装与图1一致；车间陈设与图2一致；奖牌上的字留给后期，不生成可读文字。
```

## 六、参考图怎么分工

- 一张图只管一件事：人物图管长相和衣服，场景图管空间和光线，表情图管表情；
- 写明白“只参考什么、不参考什么”：比如“图1只参考人物的脸、发型和衣服，不参考它的浅灰背景”；
- 参考图越少越稳。一张定帧图一般挂两到三张参考就够；
- 多个人同框，每个人的参考图都要挂上，并写清谁站在哪；两个人长得容易混的，先单独出各自的定帧图，再出同框；
- 没有反打角度的场景图，先补一张反方向的空景，不要把原图左右镜像当反打。

## 七、出图后先验收再往下走

用户发来实际成图，逐张看：

1. 人数、是谁、衣服、脸，和人物定妆图一样吗？
2. 手指、胳膊、道具的数量和谁拿着，对吗？
3. 场景布局、光线方向，能和前后的图接上吗？
4. 有没有多出来的字、标志、水印？
5. 姿势有没有给后面的动作留出空间？
6. 有没有露出不该露的真实信息？

每张记“能用 / 要改 / 没看”。要改的，只改一处主要问题，写“只改……，其他保持不变”，别整张重来。图片没过关，不进视频。

## 八、真人照片

用户想用本人或家人的真实长相：

- 必须是当事人本人同意的；
- 在LibTV里，先对真人照片做Seedance 2.0的真人素材合规校验，通过了再当参考；
- 照片尽量清晰、正脸、多角度、不开美颜；
- 用真人参考时，提示词少写长相细节，多写场景、动作和光线，长相交给参考图。
