# 剧本格式与统一标准

## 一、统一标准（全技能只认这一张表）

别的资料里提到的数字，跟这张表不一样的，以这张表为准。用户另有要求的，按用户的。

| 项目 | 标准 | 脚本查不查 |
|---|---|---|
| 单集时长 | 默认60到90秒 | 查（按语速估算） |
| 画幅 | 默认竖屏9:16；用户要横屏就16:9 | 不查 |
| 出事 | 开头3秒内 | 不查，靠自查 |
| 主角要什么 | 开头10秒内观众能说出来 | 不查，靠自查 |
| 新变化 | 每10到15秒至少一个新信息、新动作或新反应 | 不查，靠自查 |
| 压的部分 | 不超过全片一半 | 不查，靠自查 |
| 回报落地后 | 留2到3秒给人物反应 | 不查，靠自查 |
| 有台词的人 | 5个以内 | 查 |
| 地点 | 3到5个（同一个地方的多场算一个） | 查 |
| 场次 | 一集一般不超过8场 | 查 |
| 台词单句 | 一般不超过20个字，超过30个字必须拆 | 查 |
| 语速 | 每秒4到5个字，估算按4.5 | 查 |
| 旁白 | 字数不超过全部台词和旁白的三成，每句都过删除测试 | 查占比 |
| 动作描写 | 一段不超过80个字 | 查 |
| 套话词 | 目标是0处，超过3处必须改 | 查 |
| 金句 | 每集最多1句 | 不查，靠自查 |
| 视频单段 | 不超过15秒 | 查（提示词校验） |
| 段内时间段 | 2到4个，从0秒开始，连续、不重叠 | 查（提示词校验） |

## 二、剧本格式

```markdown
# 第1集　集名

> 目标时长：75秒　画幅：9:16　主回报：被看见　改编程度：轻 / 中 / 重
> 公开提示：本片根据真实经历改编……（需要时才写）

## 第1场　内·车间·凌晨

能看见、能演出来的动作，现在时，一段不超过80个字。

老周（不抬头）：机器热了没有？
小林：刚开。
【旁白】老周：那天离典礼还剩七个小时。（必要性：时间跳跃，画面交代不清）
【画外】老板：人呢？
【音效】刻字机启动的嗡声，越来越响。
【画面文字】陈静　十五年服务奖
【连续性】奖牌左上角有一道划痕，后面几场都要在。
【转场】嗡声延续到下一场。
```

写法要点：

- **场头**：场号、内外、地点、时间，一行写清；
- **动作行**：只写看得见、听得见、演得出来的。“他很崩溃”“她意识到了一切”不是动作，要换成表演、物件、空间里的移动或沉默；
- **台词行**：`人物：台词`，需要提示表演的放在人物名后的括号里，提示要具体（“不抬头”“把话咽回去”），不写“生气地”；
- **旁白**：`【旁白】人物：……`，每句后面括号写必要性，说不出必要性的删；
- **画面文字**：观众必须看清的字才写，写准确内容。默认这些字后期加，不让视频模型生成；
- **连续性**：下一场要接着用、容易丢的状态，比如手上的伤、衣服湿了、东西拿在谁手里。

## 三、每场写完问五句

1. 为什么必须有这一场？
2. 谁在争取什么？
3. 什么在挡他？
4. 哪个事实、筹码或选择让他原来的办法不灵了？
5. 离场时具体变了什么？

安静的场、仪式的场、只有动作没台词的场，不用硬塞一个对手，但也要让知道的事、关系、压力或节奏发生一点变化。

## 四、时长怎么估

- 台词和旁白：总字数除以4.5，得出说话需要的秒数；
- 动作和停顿：每个没有台词的动作，按1到3秒估；回报后的反应，留2到3秒；
- 两样加起来，就是估算时长。剧本体检脚本会帮你算说话的部分；
- 超时了，先删重复的解释，再合并不改变状态的过场，最后才考虑删场。不靠加快语速硬塞；
- 没有可靠的语速和动作时间时，写“估算”，不冒充精确秒数。

## 五、交付时的结构

剧本这一步交给用户的，按这个顺序：

1. 一句话：这一版主打哪种情绪、从哪一刻开场；
2. 人物小传（主角和主要配角）；
3. 完整剧本；
4. 改编台账；
5. 剧本体检结果和自查结论；
6. 一句确认请求：剧本确认后，开始出图片提示词。
