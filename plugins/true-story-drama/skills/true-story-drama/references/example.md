# 示范：一个平故事怎么改

> 这是教学用的虚构例子，人物、单位、细节都是编的，不是任何用户的项目设定。用它看清楚每一步怎么做，不要把里面的人和事搬到用户的故事里。

## 原故事（用户发来的样子）

> 我们厂有个老师傅姓周，干了十几年刻字。去年年底有一单，是一家物业公司年会的奖牌，前一天晚上发现有一块名字刻错了一个字，老周连夜重刻，第二天一早自己开车送过去，赶在年会开始前送到了。那个奖是发给他们公司一个干了十五年的保洁阿姨的。后来那家物业一直在我们这订。老周平时话很少，那天也没说什么。

## 第一步　故事确认（节选）

**我理解的故事**：一个话少的刻字老师傅，在交货前一晚发现奖牌上的名字错了一个字，连夜重刻，第二天一早自己开车送到，赶上了年会。奖是给一位干了十五年的保洁阿姨的。

**主题候选**：
1. **一个字的分量**：突出老周对名字的较真。会把片子拍成“匠心”，容易显得说教；
2. **两个不起眼的人**：一个是凌晨刻字没人看见的师傅，一个是扫了十五年地没人注意的阿姨。突出他们隔着一扇门的那一下。情绪最足；
3. **小厂靠什么留住客户**：突出后来一直合作。偏生意，观众情绪弱。

**推荐**：第2个。两个普通人，观众最容易代入，结尾有“被看见”的回报，而且不需要编任何东西。

用户回复：“对，按第2个。补充几句：名单是客户发来的，我们这边录的时候把陈静打成了陈晶，具体谁录的记不清了。老周是夜里自己核对发现的。路上大概一个半小时，年会九点开始。老周后来跟我说，他在后门站着看了一眼阿姨上台才走。物业经理后来发了张阿姨捧着奖牌的照片给我们。”

## 第二步　事实底稿（节选）

| 编号 | 内容 | 等级 | 能不能改 |
|---|---|---|---|
| F01 | 名单录入时“陈静”错成“陈晶”，谁录的不清楚 | 实 | 不能改；**不能编成某个人的错** |
| F02 | 前一天夜里，老周自己核对时发现 | 实 | 不能改 |
| F03 | 老周连夜重刻 | 实 | 不能改 |
| F04 | 第二天一早自己开车送，路程约一个半小时 | 实 | 不能改 |
| F05 | 年会九点开始，赶在开始前送到 | 实 | 不能改 |
| F06 | 获奖人是干了十五年的保洁阿姨 | 实 | 化名 |
| F07 | 老周在后门站着看了阿姨上台才走 | 感（老周自己说的） | 保留，按他自述来演 |
| F08 | 阿姨捧着奖牌的照片 | 实 | 可用作依据 |
| F09 | 老周那天什么也没说 | 实 | **不能给他安排大段台词和金句** |
| 空01 | 夜里车间的细节、路上的细节 | 空 | 可以补，进台账 |
| 空02 | 阿姨领奖时的具体动作 | 空 | 可以补，不能改变“她很珍惜”以外的含义 |

用户：“事实底稿确认。”

## 第三步　为什么平，往哪改

**一句话判断**：故事是好故事，但你把它当成“一件工作”按顺序讲完了。最打动人的那一眼——老周站在后门看阿姨上台——只是最后半句“也没说什么”。

**最要命的三条**：
1. 按时间顺序平铺，最紧的那一刻（凌晨发现错字）一句带过，观众等不到；
2. 老周看起来只是“照章返工”，看不出他的选择：他本可以早上交给别人送、本可以送到就走；
3. 阿姨只有半句话的戏份，可她是这个故事的另一半。

**被一句话带过的戏**：“自己开车送过去”“那天也没说什么”“干了十五年的保洁阿姨”。

**三个方向**：

| | A　倒计时 | B　隔着一扇门（推荐） | C　一个字 |
|---|---|---|---|
| 开场 | 凌晨两点，台灯下的错字 | 年会后门，门缝里一只满是金属屑的手 | 刻刀落下前，老周的手停住 |
| 主角要什么 | 九点前把对的奖牌送到 | 把名字还给它的主人 | 不让自己经手的东西出错 |
| 挡他的 | 时间、路程 | 时间，还有“没人会注意这一个字” | 他心里的坎 |
| 最难的选择 | 熬夜重刻还是早上再说 | 送到了，走还是留下看一眼 | 错不在他，要不要扛 |
| 主回报 | 熬出头 | 被看见（副：暖） | 心疼 |
| 制作量 | 2人、3景 | 3人、4景 | 1人、2景 |
| 事实风险 | 低 | 低 | **高：老周心里怎么想的需要你确认** |

**推荐B**：开场的那只手，到结尾才知道它熬了一夜，这是不用编任何东西的“意思反转”；老周一句话不多，正好守住F09；阿姨有了正面戏，观众得到“两个人都被看见了”的回报。

用户：“按B写。”

## 第四步　剧本

**人物**（节选）：
- 老周：五十多岁，刻字十几年。想要的：名字一个字都不能错。怕的：经手的东西出岔子。不会说的话：任何超过十个字的道理。
- 陈姨（就是奖牌上的陈静，化名）：保洁，十五年。这一集她只要一件事：上台领奖，不出错。
- 小赵（化名，合并角色）：物业行政，负责收奖牌。原故事没写谁接的货，合并为一个人，进台账。

```markdown
# 第1集　陈静的名字

> 目标时长：75秒　画幅：9:16　主回报：被看见（副：暖）　改编程度：中
> 公开提示：本片根据真实经历改编，人物为化名，部分过场和对白经过改写。

## 第1场　内·礼堂后门·上午

后门开着一条缝，台上的掌声隔着门透出来。一只手扶在门框上，指甲缝里嵌着细细的金属屑。
【画外】主持人：下面，颁发十五年服务奖——
那只手往门缝里又挪了半步。

## 第2场　内·车间·深夜

【画面文字】前一天夜里
吊灯下，老周把一块奖牌凑到眼前，老花镜推上去，又拉下来。
【画面文字】奖牌上：陈晶
他拉开抽屉翻出名单，手指顺着往下划，停在一行。
【画面文字】名单上：陈静
他抬头看墙上的钟：两点十分。
老周把奖牌放回台上，起身，按下刻字机的开关。
【音效】刻字机启动的嗡声，从小到大。

## 第3场　内·车间·深夜到清晨

刻刀走过金属，碎屑落在他手背上，他没擦。
新奖牌刻好。他用袖口擦了一遍，凑到灯下又看了一遍。
窗外天开始发白。他把奖牌放进盒子，拿起桌上的车钥匙。

## 第4场　内·老周的车里·清晨

副驾驶上放着奖牌盒，老周把安全带拉过来，扣住盒子。
【画面文字】导航：预计到达 8:41
他挂挡。

## 第5场　内·礼堂侧门·上午

小赵接过盒子，看了一眼手机上的时间，八点四十三。
小赵：师傅您亲自跑一趟啊。进去坐会儿？
老周（摆手）：不了，你们忙。
他转身往外走，走到后门，停住。

## 第6场　内·礼堂后门·上午

回到开场的门缝。台上，陈姨穿着洗得发白的保洁服，双手接过奖牌。
她低头看了很久，用拇指在刻字上摸了一下。
【画外】主持人：陈静阿姨，在咱们公司，十五年。
掌声。
门缝外，老周看着。他把手上的金属屑在裤子上蹭了蹭，转身走了。
【连续性】老周手上的金属屑从第3场一直带到这一场。
```

**改了什么**：老周全片只说一句话，守住了F09；开场那只手是结尾的伏笔，观众最后才知道它熬了一夜；阿姨摸刻字的动作是补的（空02），依据是F08的照片，进台账；“谁录错的”全片不提，守住F01。

## 第七步　自查（节选）

- 事实：F09守住了，老周全片只有一句短话；F01没有编成任何人的错。能交；
- 大众：开头3秒有“只手和掌声”的反常；10秒内知道“名字刻错了”；主回报“被看见”在第6场落地，有见证（老周），留了反应时间。能交；
- 提示词：老周和陈姨的外形锁定串和人物小传一字不差；第6段时间段0—4、4—8、8—12连续，12秒未超限。脚本校验通过。
