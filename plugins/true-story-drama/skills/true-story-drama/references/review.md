# 交付前自查

先查事实和安全，再查好不好看。能修的直接修好再交，不能只丢一句“AI味有点重”“不够有戏”给用户。

自查和写作是同一轮做的，结论里写明“本轮为自查”，不装成别人审过。

## 一、六项检查

### 1. 事实

- 两道确认（故事和主题、事实底稿）都过了吗？没过就不该有剧本；
- 剧本里每一个客观说法，能不能指回事实底稿？
- “感”和“传”级的信息，有没有被写成了“实”？
- 改写台词有没有冒充原话？
- 调序、合并、删减、补过场，都进台账了吗？
- 不能改的事实，在片子里看得见、听得见吗？
- 有没有新加原故事没有的坏人、秘密、疾病、债务、结局？
- 普通人的真名、单位、地址、能认出人的组合，处理了吗？

### 2. 戏

- 主角想要什么，观众看得出来吗？
- 挡他的力量是一直顶着，还是说没就没了？
- 冲突往上走的时候，真的改变了时间、代价、关系、信息中的某一样吗？
- 关键选择是主角亲手做的吗？
- 转折来自前面出现过的事实，还是凭空掉下来的？
- 有没有每一场都发生了变化？什么都没变的场删了没有？
- 回报落地了吗？有人见证吗？留了反应时间吗？

### 3. 大众

- 开头3秒有没有出事？
- 10秒后能不能一句话说出主角要什么？
- 主回报是哪一种，看完能不能感受到？
- 没开声音能看懂一半吗？只听不看能听懂吗？
- 有没有说教、有没有卖惨？
- 有没有一个能截图转发的瞬间？
- 一个陌生人看完，会想转给谁？

### 4. 台词

- 出声读一遍，每句都能一口气说完吗？
- 有没有书面腔、总结腔、连续的金句？
- 遮住名字，能听出是谁吗？
- 台词在争取、躲闪、试探、拒绝，还是在交换背景资料？
- 动作已经演清楚的，有没有又补一句解释？
- 每句旁白都过了删除测试吗？
- 有没有故意加“嗯、啊”、结巴、网络热词冒充口语？

### 5. 可拍

- 动作在估算时长里做得完吗？
- 有台词的人数、地点数、场次，在统一标准以内吗？
- 有没有拍不出来、生成不了的画面（大场面群演、复杂特效、精确的文字特写）？
- 人物在不同场次的衣服、伤、手里的东西，接得上吗？

### 6. 提示词

- 人物外形锁定串，每次出现都一字不差吗？
- 定帧图是不是动作开始前一刻、给动作留了空间？
- 视频的时间段从0开始、连续、不重叠、结束在总时长吗？每段不超过15秒吗？
- 正文里提到的图几，参考里都交代了吗？
- 图片没确认的视频提示词，标了“草案”吗？
- 有没有在提示词里加了剧本没有的人、台词、证据、奇观？
- 写了“不出现文字”“不要背景音乐”吗（用户另有要求除外）？

两个脚本能查的部分先跑脚本，脚本查不了的靠这张表。

## 二、有这些问题，不能交

- 没确认故事和主题，就出了整套方案；
- 没确认事实底稿，就出了方向、剧本或提示词；
- 编了会伤害真人名誉的重大事实；
- 没确认就公开了能认出普通人的身份；
- 把有争议的说法写成了确定的事实；
- 把改写台词标成了原话；
- 关键转折靠一个原材料里没有的新秘密；
- 提示词改了原故事的结局、关系或谁对谁错；
- 图片没确认，就把视频提示词标成了定稿；
- 时长明显装不下核心动作和台词，还说能直接拍；
- 用户没要口播式，却写成了从头到尾的旁白。

## 三、结论三档

- **能交**：没有上面的问题，可以请用户确认；
- **改完能交**：有明确问题，已经改好，改了什么写清楚；
- **先别公开**：事实、身份授权或高风险信息没落实，只能交内部讨论版。

## 四、问题怎么写

每个问题写五样：

```markdown
### 严重程度 · 问题
- 在哪：第几场、第几段
- 证据：一小段原文，或冲突的事实编号
- 影响：会让观众在哪里看不懂、出戏，或者会伤到谁
- 改成：要达到什么样（不替用户写整段漂亮话）
- 别丢：改的时候不能丢掉什么
```

严重程度分四档：不能交、主要、次要、建议。个人口味只能算“建议”。
