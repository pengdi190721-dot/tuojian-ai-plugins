# 人物

观众记住一个短剧，往往是因为记住了一个人。真事改编的人物，难在“既要立得住，又不能编”。人物小传是后面台词、定妆图、表演、声线的共同依据，先写小传，再写剧本。

## 一、主角四问

动笔前必须答得上来，答案都要能指到事实底稿：

1. **他想要什么？**这一集里一个具体的、能拍出来的目标；
2. **他怕失去什么？**工作、面子、一个人的信任、一个承诺；
3. **他的底线在哪？**碰到就会爆发、就不会再忍的那一点；
4. **观众凭什么喜欢他？**一个让人心软或佩服的地方，通常藏在一个小动作里。

四问答不上来，人物就是纸片人，后面写再多场都立不起来。

## 二、反差：人物的钩子

没有反差的人，观众记不住。真事里的反差必须是事实，不能为了好看安一个身份。常见的真反差：

| 表面 | 里面 | 效果 |
|---|---|---|
| 话少、木讷 | 关键时刻一个人扛下来 | 心疼、佩服 |
| 嘴硬、爱抱怨 | 一直默默在帮 | 暖、原来如此 |
| 看着很普通 | 在一件事上极其较真 | 被看见 |
| 平时很强势 | 在一个人面前软下来 | 遗憾与和解 |
| 年纪小、被看轻 | 做成了大人做不成的事 | 扬眉吐气 |

反差靠演出来，不靠介绍出来。别让旁白说“他看起来话少，其实很重情义”，让观众先看见他话少，再看见他做了什么。

## 三、配角：每个人都要有自己想要的

有台词的配角，至少要有一句话能说清“他要什么”。没有自己想要的，就是递话的工具人。常见几种功能：

| 功能 | 干什么 | 注意 |
|---|---|---|
| 对手 | 跟主角想要的不一样，制造压力 | 真事里通常不是坏人，给他一个站得住的理由 |
| 见证 | 看见主角做了什么，替观众做出反应 | 名场面里最不能省的人 |
| 帮手 | 提供信息、工具、一点善意 | 帮的方式和力度不能超出事实 |
| 镜子 | 和主角面对同样的事，做了不同的选择 | 用得好能让主题不用说出口 |

有台词的人尽量控制在五个以内。没有独立作用的路人，合成一个化名角色，进台账。

## 四、真人的外形怎么处理

- **用户提供了本人照片、并同意用**：定妆图以照片为参考，外形描述写照片里看得见的，不添加；提醒用户在LibTV里先做真人素材合规校验；
- **没有照片，或者当事人没同意**：设计一个虚构化的外形，不声称像本人；
- **不从职业、性格、地域猜长相**：“东北人”“老师傅”不等于某种长相。外形按剧情需要和用户意愿来定；
- **年龄段要对**：同一个人在不同年代出场，每个年龄段单独一套外形，用错年龄是最常见的翻车。

## 五、外形锁定串

每个主要人物写一段**外形锁定串**：年龄段、脸型、发型、主要服装和颜色、标志性的配件。写好后：

- 人物定妆图、定帧图、视频提示词里，凡是这个人出现，都**一字不改地照抄**这段；
- 不缩写、不换近义词、不“优化”。少一个字，模型就可能画成另一个人；
- 剧情里换衣服，就单独写一段新的锁定串，标清从哪一场开始用。

提示词校验脚本会检查同一个人的锁定串是不是每次都一样。

## 六、声线

小传里写一段声线：性别、年龄感、音色、语速、说话的劲。比如“男，五十岁上下，嗓音低、有点哑，语速慢，句子短，说完常停一下”。这是给配音和视频生成用的，实际声音没选定前标“待验证”。

## 七、人物小传的格式

用 [人物小传](../assets/character-bible.md)。字段和AI短剧导演台的人物小传对得上，用户想把人物带到导演台继续做，可以直接用。

多人故事先给一张人物关系总表，再逐个写详细小传，别一次全倒出来。
