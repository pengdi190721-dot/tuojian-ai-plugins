# 台词与旁白

短剧观众是“听着看”的。一句台词书面了、太长了、像在念稿，观众立刻出戏。这份资料管三件事：台词怎么写得像人话、旁白什么时候能用、AI腔怎么去。

## 一、台词五条

1. **每句都有目的。**要么推事情往前走，要么露出这个人是什么样的，要么制造冲突。三样都不占的，删；
2. **说给场里的人听，不说给观众听。**人物不会对着熟人解释双方都知道的背景；
3. **一口气说得完。**一句台词一般不超过二十个字，长了就拆开，中间插一个动作；
4. **遮住名字也认得出是谁。**每个人的句子长短、用词、语气不一样；
5. **不说也是台词。**停顿、转身、低头扒饭、把手机扣在桌上，很多时候比说出来更重。

## 二、台词要带着任务

真人说话，几乎每句都在干点什么：催、求、推、躲、试探、拒绝、改口、找台阶。写台词前先想这句在干什么：

| 只交换信息（不好） | 带着任务（好） |
|---|---|
| “典礼是明天上午九点。” | “九点，人家九点就上台了。” |
| “我们必须重新刻一块。” | “机器热了没有？” |
| “我觉得你这样做不对。” | “你先别急着发，等我看一眼。” |
| “谢谢你这么多年的照顾。” | “……饭在锅里，你自己热。” |

## 三、允许不完整

真人对话里有打断、有答非所问、有半句话、有沉默。别让每个人都把话说圆满。但不完整不等于乱：观众该知道的信息，一定要在某一句里清清楚楚地说出来一次。

## 四、AI腔：一眼就露馅的写法

写完初稿，逐句过一遍下面这张表。这张表和剧本体检脚本里的词表是同一套。

| 类型 | 露馅的样子 | 改成 |
|---|---|---|
| 书面词 | 进行、实现、赋能、基于、从而、予以、值得我们思考 | 直接的动词：做、弄、改、交、干完 |
| 总结腔 | 这一刻他终于明白了……、原来这就是……的意义 | 删掉，让动作自己说 |
| 金句腔 | 不是……而是……、真正的……往往……，连着出现 | 一集最多留一句，其余拆成大白话 |
| 模板表情 | 眼中闪过一丝、嘴角勾起、深吸一口气、瞳孔骤缩 | 写这个人独有的动作：搓手、把烟按灭、不停看表 |
| 情绪直说 | 他感到非常愤怒、她心中五味杂陈 | 他把杯子放下，放得很重 |
| 比喻堆砌 | 仿佛、宛如、如同……一般 | 删，或者换成一个具体的东西 |
| 排比 | 三句一样结构的话连着说 | 留一句，其余拆散 |

改的时候别矫枉过正：故意加“嗯、啊、那个”、加结巴、加网络热词，冒充口语，同样是假的。要的是“这个人在这个处境里真会这么说”。

## 五、说话方式从人物来

给每个有台词的人定好四样，写在人物小传里：

- **句子长短**：有人说话短促，有人絮叨；
- **用词**：书面还是口语，有没有口头禅、方言味；
- **态度**：爱怼人、爱讲理、闷着不说、什么都往好里想；
- **不会说的话**：一个不善表达的人，就不该突然说出一段漂亮话。

同一个人在不同处境里语气会变（对老板和对孩子不一样），但底子不变。

## 六、真人原话怎么用

录音里本人说过的有辨识度的话，是宝。优先留下来，标成“原话”。但：

- 只有能在录音、逐字稿里原样找到的才叫原话；
- 为了节奏改过的，标“改写台词”；
- 原话里重复的口头禅可以删，不影响人物的就删；
- 别把采访时的回顾性话语（“我那时候其实挺害怕的”）直接塞进当时的场景里当台词。

## 七、旁白：最后才补，能删就删

默认把片子写成“人在现场经历”，不写成“一个人把过去讲一遍、画面配合着放”。

先写完不带旁白的纯动作和对白版，再看哪里非补不可。旁白只用在三种情况：

1. 跨过一段拍不出来的时间，不交代因果就断了；
2. 一个影响关键选择的心里话，动作、停顿、物件都演不出来；
3. 一件必须保留的背景事实，场里没有任何人能自然地说出来。

每一句旁白都做**删除测试**：删掉以后，观众还能不能看懂他为什么这么做、时间怎么变了、结果意味着什么？能看懂，就删。留下的旁白只补缺的那一点信息，不总结主题、不重复画面、不替人物下结论。

用户明确要口播式（本人出镜讲述、画面配合）的，按用户的来，但开场和结尾仍然优先用画面和现场声。

## 八、交付前读一遍

把台词出声读一遍，每句问自己：

1. 这句话本人能一口气自然说完吗？
2. 删掉这句，画面是不是已经说清楚了？
3. 这句在争取、躲闪、判断、行动，还是只在替作者总结？
4. 连着三句是不是都像海报上的文案？
5. 遮住名字，能听出是谁在说吗？

答案不对，直接改好再交，不把“建议口语化”这种话留给用户自己去改。
