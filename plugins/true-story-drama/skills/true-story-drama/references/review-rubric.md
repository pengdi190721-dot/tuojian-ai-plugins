# 审查标准

审查先看事实和安全，再看戏剧和口味。能修的明确修订结果，不能只说“AI味重”“不够电影感”。

## 一、结论

- **通过**：没有阻断问题，可以进入用户确认；
- **修改后通过**：存在明确问题，修订后再确认；
- **暂缓公开**：事实、身份授权或高风险信息不足，不能安全交付公开版。

若作者和审查者是同一轮工作，标明“本轮为自检”，不伪装成独立审查。

## 二、八项检查

### 1. 理解与确认关卡

- 是否先回传故事大意、事件链和主题候选；
- 用户是否明确确认或纠正故事大意；
- 用户是否选定或明确认可要突出的主题；
- 主题确认后，是否单独回传事实底稿供用户删除、修改、补充和确认；
- 用户是否明确确认最终事实底稿；
- 后续脚本是否偷换已确认的故事含义和主题；
- 主题或事实底稿未确认时，是否越过关卡直接生成了完整方案。

### 2. 事实与改编台账

- 每项客观断言能否回到事实底稿；
- M、U类信息是否被错误写成F类；
- 情境化对白是否冒充逐字原话；
- 调序、合并、删减和新增是否进入台账；
- 不可改事实是否真的在画面或声音中兑现。

### 3. 隐私与名誉

- 是否暴露普通人的真实姓名、单位、地址、联系方式或独特身份组合；
- 是否新增或强化犯罪、出轨、债务、疾病、诊断、恶意动机等高风险内容；
- 是否需要公开提示、匿名化或用户再次确认；
- 未成年人、客户、咨询对象和家庭纠纷是否采用更高匿名等级。

### 4. 因果

- 关键转折是否来自已建立事实或人物选择；
- 人物是否因为某个原因行动，并承担可见结果；
- 资源、证据、权限和外部救援是否凭空出现；
- 调序和压缩是否删断“人物为什么相信、如何得知、东西如何到手”。

### 5. 戏剧

- 主角现在想要什么，观众能否从剧本看懂；
- 阻力是否持续反制，而不是对手突然闭嘴；
- 升级是否改变权力、信息、关系、暴露、资源、时间或代价；
- 本集是否先给局部回报，再留下余波；
- 反转若存在，是否让计划或关系真正改变；不存在时是否避免硬造。
- 故事是否主要由场内人物行动和对话推进，而不是由旁白讲完、画面只做说明；
- 每处旁白是否标明必要性，并通过“删除后是否仍能看懂”的测试；
- 能用试用失败、消息、物件、停顿或人物反应表达的信息，是否仍被旁白重复解释。

### 6. 人物与对白

- 主角是否亲自作出关键选择，而不是等人救；
- 主要配角是否有自己的目标、判断或策略；
- 不同人物是否都用同一种解释腔、质问腔或金句腔；
- 台词是否在争取、回避、试探、拒绝或改变关系；
- 动作已经表达清楚时，是否又补一句道理翻译。
- 旁白是否充满“进行、实现、赋能、基于、从而、值得思考”等书面词；
- 是否连续使用整齐排比、“不是……而是……”“真正的……往往……”和主题金句；
- 一句话是否太长、意思太多，真实人物很难一口气说完；
- 是否为了显得口语化，机械添加“嗯、啊、那个”、结巴或网络热词。
- 台词是否带着催促、争取、试探、拒绝、推责或改口等现场目的；
- 是否所有人物都把话说得过分完整、轮流输出背景和道理；
- 是否允许真实对话中的打断、半句、沉默和动作回应，同时保持信息清楚。

### 7. 可拍与可生成

- 动作能否在目标时长内完成；
- 场景、人物和关键物件是否超过当前制作能力；
- 分镜是否准确承载剧本的动作、文字与声音；
- 镜头起止、角色外观、服装、持物和空间方向是否连续；
- GPT Image 2图片提示词是否把人物、场景、起始状态、构图、光线和不可变化项写清；
- 图片起始姿势是否为后续动作留出空间；
- Seedance提示词是否把已确认图片作为首帧，只重点描述动作、镜头、声音和结束状态；
- 图片未确认时，Seedance提示词是否错误标成最终版；
- 图片或视频提示词是否新增剧本没有的事实、人物、对白或奇观。

### 8. 去模板感

只有能指出至少两个具体位置并说明损失，才能判定“模板感”：

- 因果重复：每轮都靠巧合、陌生人、对手自曝或同一种证据；
- 策略重复：所有人只会质问、否认、提高音量；
- 表达重复：攥拳、眼神一冷、全员金句、每场都总结；
- 镜头重复：每句台词都特写加推进，摄影机不跟信息变化。

有意的仪式重复、人物口癖、喜剧回环和固定视觉风格不自动算问题。

## 三、阻断问题

出现以下任一项，不能直接标记“通过”：

- 未经用户确认故事大意和主题，直接生成完整短剧方案；
- 未经用户确认事实底稿，直接生成戏剧化方向、剧本、分镜或提示词；
- 捏造会伤害真实人物名誉的重大事实；
- 没有确认便公开可识别普通人的身份；
- 将争议信息写成确定事实；
- 将重构对白标成逐字原话；
- 关键反转依赖来源中不存在的新秘密；
- 分镜或提示词改变原故事结局、人物关系或责任归属；
- 图片未确认就把Seedance提示词标为最终可复制版本；
- 目标时长明显无法容纳核心动作与对白，却仍声称可直接制作。
- 用户没有明确要求口播式叙事，却把本可用行动和对话演出的故事写成连续旁白，并仍标记为通过。

## 四、问题写法

每个问题包含：

```markdown
### 严重程度 · 问题标题
- 位置：文件、场景或镜号
- 证据：必要短引文或冲突事实
- 影响：对事实、观众理解、连续性或制作的影响
- 修订结果：必须达到什么，不代写整段漂亮话
- 保留项：修改时不能丢掉什么
```

严重程度分为：阻断、主要、次要、建议。审查问题必须可复核，创作偏好只能作为建议。
