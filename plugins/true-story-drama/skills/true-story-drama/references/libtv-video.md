# LibTV视频提示词写法

核验日期：2026-10-31。LibTV界面和模型更新很快，按钮名字、参数上限以你当天看到的为准，有出入时改这份资料。

## 一、在LibTV里怎么连

LibTV是节点式的无限画布。做短剧的一段视频，一般这样连：

1. 把这一段要用的图拖到画布上：本段的**定帧图**、出场人物的**定妆图**（三视图）、本段的**场景图**；
2. 把这些图连到一个视频节点，模型选**Seedance 2.0**，模式选**全能参考**；
3. 在视频节点里贴提示词，设好时长、画幅、清晰度；
4. 提示词里按连线顺序把参考图叫作**图1、图2、图3**。你的界面如果显示成“@图片1”这种写法，就把提示词里的叫法统一换成界面上的样子。

用真人照片做参考的，先在图片上做Seedance 2.0真人素材合规校验，通过后再连。

## 二、一段多长

- **一段不超过15秒**，常用5到12秒；
- 按剧情节拍切段，不是一张图一段：一个完整的小动作、一轮对话、一个情绪转折，放进同一段；
- 一段里塞不下的，拆成两段，不靠加快动作硬塞；
- 一段里的台词总字数，不超过“秒数×4.5”。

## 三、提示词结构（照这个顺序写）

```text
【总设定】时长__秒，竖屏9:16，__风格。整体情绪：__→__。一镜到底（或：第__秒切到__）。画面连贯，人物不跳变。
【参考】图1是本段第一帧，人物位置、服装、光线从这张图开始；图2是__的三视图，只用来锁定长相和衣服；图3是__的空景，只用来锁定布局和光线。
【人物】__：外形锁定串（照抄人物小传，一字不改）。
【0—__秒】景别，机位，镜头怎么动。人物做什么，眼睛看哪、手怎么动，情绪的可见表现。台词：__（语气）：“……”，口型同步。
【__—__秒】……
【__—__秒】……最后停在：__。
【声音】环境声：__。音效：__。不要背景音乐。
【结束状态】人物、手里的东西、视线、镜头最后停在哪。
【禁止】不出现字幕、文字、水印；不增加人物；人物长相、服装、场景陈设不变；画面不抖动；手指和肢体正常。
```

## 四、时间段的规矩

- 从0秒开始，一段接一段，**连续、不重叠、不留空**，最后一段结束在总时长；
- 一段视频分**2到4个时间段**，每个时间段只放一个看得清的动作重点；
- 每个时间段都写：**景别**（远景、全景、中景、中近景、近景、特写）、**机位**（正面、侧面、过肩、俯拍、仰拍）、**镜头状态**（固定，或推、拉、摇、移、跟、环绕中的一种，写清方向和速度）；
- 一段视频整体只安排**一个主要运镜**，其他时间段用固定镜头或焦点变化；
- 情绪不写“他很难过”，写一串看得见的东西：先看到什么 → 视线怎么变 → 手停住或动起来 → 呼吸和肩膀 → 表情 → 最后的动作；
- 最后一个时间段必须写“最后停在”什么样，下一段从这里接。

## 五、台词和声音

- 台词写清**谁说、说什么、什么语气**，加“口型同步”；不说话的人写他在干什么、有什么反应；
- 两个人对话写清先后：谁先说，谁听完停了半拍才接；
- 台词只写剧本里有的，不让模型自己加对白；
- **默认写“不要背景音乐”**，单段自动配的音乐拼起来很突兀，配乐留给后期；
- 环境声要写：车间的机器声、饭桌上的碗筷声、医院走廊的脚步声，这些让画面活起来；
- 后期要配本人原声或旁白的段落，写“人物不开口说话，只有环境声，为后期旁白留空”；
- 屏幕上需要的字（片名、时间、奖牌上的名字），一律写“不出现文字”，后期再加。模型生成的中文字经常错。

## 六、段和段怎么接

- 上一段的“最后停在”，就是下一段定帧图的起始状态，两张图要对得上；
- LibTV可以把上一段视频的最后一帧导出来，直接当下一段的图1，接得最顺；
- 切场景的地方，用新的定帧图开头，不要求一镜接上；
- 人物从屋外走进屋里这种空间变化，拆成两段，不指望一段视频里完成换地方。

## 七、草案和定稿

- 图片还没生成或者没确认，视频提示词标“草案”：只是按剧本写的动作安排；
- 用户发来实际的定帧图后，先看图：人在哪、朝哪、手里拿着什么、身后有没有空间，再按图改成定稿；
- 图上的姿势和草案对不上，以图为准改提示词，或者先返修图，不硬写；
- 默认先定稿一段，生成看效果，满意了再批量。

## 八、一段完整的样子

```text
【总设定】时长12秒，竖屏9:16，写实电影质感。整体情绪：愣住→不服气→下定决心。一镜到底。画面连贯，人物不跳变。
【参考】图1是本段第一帧，人物位置、服装、光线从这张图开始；图2是老周的三视图，只用来锁定长相和衣服；图3是车间夜景空景，只用来锁定布局和光线。
【人物】老周：五十多岁的中国男性，身材偏瘦，短寸头两鬓花白，脸窄、颧骨明显，眼角皱纹深，穿深蓝色旧工装外套，袖口磨得发白，里面是灰色圆领毛衣，深灰色工装裤，黑色劳保鞋。
【0—4秒】中近景，正面略偏右，固定镜头。老周把奖牌凑到吊灯下，盯着上面的字，左手推了一下老花镜，眉头慢慢拧紧，拿奖牌的右手停在半空。
【4—7秒】特写，侧面，固定镜头。他的拇指在奖牌刻字的位置来回摸了两下，停住，喉结动了一下。
【7—12秒】镜头从特写缓慢拉到中景。老周把奖牌放回工作台，起身转向左边的刻字机，伸手按下开关，机器指示灯亮起。最后停在：老周背对镜头站在刻字机前，右手还按在开关上，吊灯在他头顶。
【声音】环境声：深夜车间的安静，远处一声狗叫。音效：刻字机启动的嗡声，从小到大。没有人说话。不要背景音乐。
【结束状态】老周背对镜头站在刻字机前，右手按在开关上，奖牌留在工作台上，镜头停在中景。
【禁止】不出现字幕、文字、水印；奖牌上不生成可读文字；不增加人物；老周长相、服装和车间陈设不变；画面不抖动；手指正常。
```

## 九、交付前用脚本查一遍

```bash
python3 scripts/prompt_check.py 视频提示词.md --max-seconds 15
```

它会查：时间段是不是从0开始、连续、不重叠、结束在总时长；有没有超过15秒；正文里提到的图几，参考里有没有交代；同一个人物的外形锁定串，各段是不是一字不差。
