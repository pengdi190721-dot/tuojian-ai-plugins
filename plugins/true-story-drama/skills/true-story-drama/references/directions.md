# 改编方向与故事发动机

诊断完为什么平，下一步是给三个改编方向让用户选。三个方向必须是三种不同的“戏的来路”，不是同一个故事换三个标题。

## 一、先选从哪一刻进去

开场那一刻决定了整个片子的劲。从下面几种时刻里挑最有分量的一个：

- 他原来的办法第一次不管用了；
- 一个现实限制逼他必须现在决定；
- 两件他都想守住的事撞在一起，只能选一个；
- 一件旧事被重新看懂，眼前的关系跟着变了；
- 他必须开口、拒绝、认错、放弃或者扛下后果；
- 结果已经发生了，但观众还不知道他为此付出了什么。

别为了“黄金三秒”把结局直接剧透。开场只承诺片子会兑现的东西：一个压力、一个反常、一个要做的选择。

## 二、三个方向从三种压力里找

| 压力 | 戏从哪来 | 例子 |
|---|---|---|
| **现实的压** | 时间、钱、规矩、距离、权限、机器 | 典礼九点开始，现在凌晨两点，奖牌名字刻错了 |
| **关系的拧** | 两个人想要的不一样，但都有道理 | 老板要先交货保住客户，师傅要返工保住手艺 |
| **心里的坎** | 面子、承诺、怕丢人、不想欠人情 | 一辈子没出过错的人，这次错在自己手上 |

不是每个故事都能三种压力各出一个方向，但三个方向至少要在“谁在挡他”“他最难的选择”上明显不一样。只换了职业、语气、片名，等于只有一个方向。

## 三、每个方向写清七样

1. **从哪一刻开场**：第一个画面是什么；
2. **主角现在要什么**：一句话，具体到能拍；
3. **谁或什么在挡他**：人、规矩、时间，还是他自己；
4. **他为什么不能撒手不管**：撒手会失去什么；
5. **他最难的那个选择**：选了什么，放弃了什么；
6. **观众最后得到什么情绪**：对照 [大众为什么爱看](mass-appeal.md) 里的七种回报，选一种主的；
7. **制作量**：几个有台词的人、几个场景、有没有难拍的画面。

另外每个方向标一句**事实风险**：这个方向有没有需要原材料撑但目前没撑住的地方。有就写“需要你确认：……”，不能先写进剧本再说。

## 四、推荐时说人话

推荐一个，理由写两三句，说清：

- 为什么这个最抓人；
- 为什么这个最不容易偏离事实；
- 拍起来难不难。

## 五、故事发动机

用户选定方向后，先用下面这张表把发动机装好，再动笔写剧本。每一格都要能指到事实底稿的编号，或者标明是台账里的“空”。

```text
主角：谁被这件事卡得最狠
要什么：他现在具体要完成什么
挡他的：哪个力量一直在顶着他
撒不了手：撒手会失去什么
老办法：他平时遇到事怎么应付
老办法失灵：这一次，老办法开始伤到什么
选择：他必须亲手决定什么
转折：哪个已有的事实，让原计划不成立了
回报：这一集真正完成了、失去了、或者改变了什么
余波：这个结果留下了什么还没结清的事
```

冲突往上走，必须真的改变点什么：时间更少了、钱更紧了、知道的事变了、两个人的关系变了、暴露的风险更大了、代价更高了。只是吵得更大声，不算升级。

## 六、揭晓、反转、回报、钩子，别混着用

- **揭晓**：人物或观众知道了一件本来就存在的事；
- **反转**：一件已有的事，让原来的计划、理解或关系翻了个面；
- **回报**：前面承诺的情绪——心疼、暖、出气、释然——真的落地了；
- **钩子**：一个没做完的决定、一个没解除的危险、一个没结清的后果，让人想看下去。

只是把一句话藏着不说，不叫钩子；突然冒出一个陌生人宣布秘密，不叫反转。

能用的反转长这样：

```text
因为前面已经出现过的事实或选择，原来的计划不成立了，他现在必须做一个新的、代价更大的选择。
```

真事里没有反转，用“意思反转”：同一个动作、物件、一句平常话，在结尾因为观众知道了代价，变了意思。这是真事改编最好用的一招。

## 七、单集还是系列

**单集**（默认）：完成一个完整的“压—扬”，给一个实打实的回报，再留一点余波。不能把回报砍掉，只用“下集揭晓”冒充结尾。

**系列**：用户要系列时，每集记下：
- 开场时的状态；
- 这一集他要什么、谁挡着；
- 他做的选择；
- 看得见的结果；
- 这一集放出了什么信息；
- 还没结清的代价；
- 下一集必须接着用的事实。

集数由真实材料撑得起多少变化决定。一个薄故事，不硬拉成十集。
