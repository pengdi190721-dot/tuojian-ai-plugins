# 冲突、节奏与回报

开场把人留住，靠的是节奏把人留到最后。这份资料管三件事：一集怎么排、冲突怎么往上走、回报和结尾怎么落。所有数字以 [剧本格式与统一标准](script-format.md) 里那张表为准。

## 一、一集的骨架：先压，后扬

默认一集60到90秒，走一个完整的“压—扬”，五拍：

| 拍 | 位置 | 做什么 |
|---|---|---|
| ① 出事 | 开头10秒内 | 压力、反常或坏消息砸下来，观众知道他要什么 |
| ② 加压 | 到三分之一左右 | 老办法不管用，处境更糟一点：时间更少、钱更紧、人更不信他 |
| ③ 选择 | 中段 | 他亲手做一个有代价的选择，或者一个旧事实让计划翻面 |
| ④ 回报 | 五分之四左右 | 前面承诺的情绪落地：心疼、暖、出气、松口气、原来如此 |
| ⑤ 落点 | 最后10秒 | 一个画面、一个动作、一句平常话收住，留一点余波 |

**压的部分不过半。**真事的苦往往很长，剧本要压缩苦、放大选择和回报。观众憋太久会走。

## 二、每一场都要有变化

每一场离场的时候，至少有一样东西和进场时不一样：

- 知道的事变了；
- 两个人的关系变了；
- 手里的筹码、时间、钱变了；
- 风险更大了，或者解除了；
- 他的决定变了。

什么都没变的场，删掉或合并。观众每隔十到十五秒就要看到一个新变化：新信息、新动作、新反应都算。

## 三、冲突怎么往上走

真事里的冲突一般不是越吵越凶，是越逼越紧。往上走的办法：

- **收紧时间**：本来还有一天，现在只剩一夜；
- **抬高代价**：本来只是丢一单生意，现在是丢掉一个人的信任；
- **堵死退路**：本来可以找人帮忙，现在只能自己来；
- **拉近关系**：这件事原来跟一个陌生人有关，后来发现关系到他最在乎的人；
- **翻出旧事**：一个早就存在、观众前面见过的事实，这时候显出了分量。

不算升级的：只是嗓门更大、哭得更凶、多加一个吵架的人。

## 四、回报怎么落

回报是观众留到最后的理由。落回报的四个要点：

1. **前面要有承诺**：观众得先知道他要什么、有多难，回报才有分量；
2. **回报要看得见**：落在一个动作、一个表情、一个物件上，不靠旁白宣布“他成功了”；
3. **要有人见证**：不一定是一群人，一个关键的人看见就够——那个曾经不信他的人、那个被他帮过的人；
4. **要留反应的时间**：回报落地后，给观众两三秒看清人物的反应，别急着切走。

## 五、名场面五拍

全片最重的那个瞬间，按五拍来：

1. **压到底**：处境最难的那一刻；
2. **转折**：一个信息、一个选择、一个动作改变了局面；
3. **释放**：他做出那个动作，画面要清楚、具体；
4. **见证**：在场的人的反应，这一拍最容易被省掉，但它是把情绪放大的那一下；
5. **余韵**：一句平常话或一个安静的画面收住，不说道理。

## 六、结尾和集尾钩子

**单集的结尾**，优先用“意思反转”收：前面出现过的一个物件、一句话、一个动作，在结尾因为观众知道了代价，换了意思。不要用旁白总结道理。

**系列的集尾**，留一个真的钩子：

| 钩子 | 结构 | 真事里的例子 |
|---|---|---|
| 没做完的选择 | 他必须二选一，镜头停在他还没开口 | 两个电话同时打进来，他看着屏幕 |
| 没解除的危险 | 期限、风险还在往前走 | 车开出去，导航显示还有一百公里，离典礼还有一个半小时 |
| 没结清的代价 | 他做成了，但有一件事要还 | 他借来的钱，明天就要还 |
| 一个留下的物件 | 一个还没打开、没交出去的东西 | 那封信，他放进了抽屉 |
| 一句没说完的话 | 话到嘴边被打断，或者咽了回去 | “其实那天……”电话断了 |

两条铁律：钩子必须是新东西，不是重复前面的疑问；下一集必须真的回应它，钩子骗了观众一次，后面就没人信了。

## 七、节奏要有快有慢

- 吵和静交替：一场争执之后，接一场安静的、只有动作没有台词的戏；
- 长场和短场交替：别每场都一样长；
- 台词有长有短：一句长的后面跟一句很短的，或者干脆不接话；
- 关键时刻放慢：名场面和回报，给足时间；过场和交代，能压就压。

## 八、套路重复的信号

出现两处以上，就要换写法：

- 每次转机都靠巧合、靠陌生人、靠对方突然认错；
- 所有人遇事只会质问、否认、提高嗓门；
- 每场都有人攥拳、眼神一冷、说一句金句；
- 每句台词都给特写加推镜，镜头不跟着信息变化走。
