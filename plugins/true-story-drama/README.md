# 真实故事短剧化｜学员使用说明

版本：0.2.1

“真实故事短剧化”先理解本人经历、客户案例、采访录音或逐字稿，让用户确认故事大意和主题；再单独生成事实底稿，让用户逐条删改确认；最后才把素材改成以人物行动和自然对话推进、旁白只在必要处出现的中文AI短剧脚本。

它不会为了“有戏”凭空制造坏人、出轨、犯罪、疾病、债务或幕后秘密。所有压缩、调序、人物合并和对白重构都会进入改编台账。

## 安装后会获得什么

- 故事理解确认单：先还原录音或文字中的故事，再让用户确认主题；
- 事实底稿确认单：区分已核实事实、个人记忆、转述争议和创作空白，用户删改确认后才继续；
- 三个戏剧化方向：从现实压力、关系压力和内在压力中寻找不同机制；
- 完整可拍脚本：用动作和人物对话推进，旁白通过删除测试后才保留；
- 角色一致性卡、逐镜分镜和GPT Image 2图片提示词；
- 每张图片的验收重点和Seedance图生视频提示词；
- 视频提示词按连续秒数分段，逐段写清景别、机位、运镜、可见情绪和结束状态；
- 原故事与改编内容对照台账；
- 事实、隐私、名誉、因果、可拍性和AI生成连续性审查。

本插件默认先交付文本方案，不会自动生成图片、视频、配音或发布内容。图片未确认前，Seedance提示词只能标为草案。

## 新版工作顺序

1. 上传真实故事、采访录音或逐字稿；
2. 系统只整理故事大意、事实边界和主题候选，状态为“待主题确认”；
3. 用户确认或纠正故事，并选定要突出的主题；
4. 系统只生成事实底稿，状态为“待事实确认”；
5. 用户逐条删除、修改、补充并明确确认事实底稿；
6. 系统生成短剧方案，先用人物行动和对话演出故事，最后只在必要处补旁白；台词改成真人说得出口的短句，再生成分镜和GPT Image 2图片提示词；
7. 用户先生成图片并确认；
8. 系统根据实际图片定稿Seedance图生视频提示词，并按连续秒数写清每段动作、景别、机位、运镜、情绪变化和结束状态。

## 视频提示词固定格式

8秒镜头默认按下面的结构输出：

```text
0—3秒：景别＋机位＋固定机位或具体运镜；触发信息、人物动作和可见情绪。
3—4秒：景别＋机位＋焦点变化或过渡；情绪转折。
4—8秒：景别＋机位＋主要运镜＋结束景别；主要动作、情绪落点和结束状态。
声音：准确对白或无对白；环境声、音效、音乐或静音。
连续性限制：人物、服装、场景、道具、字幕和水印限制。
```

其他时长会按照动作节奏重新连续拆分，不能出现时间断档或重叠。情绪不只写“焦虑、失落、开心”，而要落实到眼神、手部、呼吸、姿态、表情和最终动作。

## Codex学员安装

打开终端，依次运行：

```bash
codex plugin marketplace add pengdi190721-dot/tuojian-ai-plugins
codex plugin add true-story-drama@tuojian-ai
```

安装后重启ChatGPT桌面端，新建任务，复制首次使用口令：

```text
请使用真实故事短剧化。我接下来会提供真实故事、采访录音或逐字稿。第一步只理解材料，给我故事大意、事实边界和主题候选；主题确认后只生成事实底稿，等我删改确认；事实确认后用人物行动和自然对话演出故事，旁白只在删不掉的地方出现，再输出逐镜GPT Image 2图片提示词和Seedance图生视频提示词。
```

检查是否安装成功：

```bash
codex plugin list
```

列表中应出现 `true-story-drama@tuojian-ai`。

## 最简单的用法

```text
请先理解这个真实故事。默认人物和公司匿名，不要马上写剧本。先告诉我你理解的故事大意、人物选择、事实缺口和三个主题候选；主题确认后只生成事实底稿，等我删改确认后再生成短剧方案。

真实故事：
【把原始故事粘贴在这里】
```

## 三个常用口令

### 1. 上传故事或采访后先确认主题

```text
理解我上传的故事、采访录音或逐字稿。第一轮不要生成短剧方案，只输出故事大意、人物与事件链、事实边界、信息缺口和主题候选，等待我确认。
```

### 2. 主题确认后生成事实底稿

```text
故事大意和主题确认。现在只生成事实底稿，把不可改变的事实、个人感受、转述争议、信息缺口、可创作范围和隐私处理分开列出，等我逐条删改确认，不要继续生成剧本。
```

### 3. 事实确认后生成完整稿

```text
事实底稿确认，采用我选定的主题继续。输出三个戏剧化方向、推荐版完整剧本、角色一致性卡、逐镜分镜、GPT Image 2图片提示词、图片验收项、Seedance视频提示词草案、改编台账和审查结论。剧本必须以人物行动和自然对话推进，旁白只在删除后会导致时间、因果或关键内心断裂时保留；不要写成整段口播配画面。视频提示词按连续秒数分段，逐段写清景别、机位、运镜、人物动作、可见情绪和结束状态。
```

### 4. 图片确认后定稿视频提示词

```text
这是我用GPT Image 2生成并确认的镜头图片。请先检查它是否适合图生视频，再根据图片中的真实姿势、构图和运动空间，输出Seedance最终可复制提示词。
```

## 建议提供的信息

故事不需要提前写得漂亮，但最好说明：

- 可以直接上传采访录音或粘贴逐字稿；
- 录音里分别是谁在说话；
- 哪些是绝对不能改的事实；
- 哪些人物必须匿名；
- 哪些采访内容允许作为原声或逐字原话；
- 是否允许压缩时间、合并场景和重构对白；
- 目标平台、时长和画面形式；
- 不能出现的内容。

插件内置 `story-intake-template.md`，需要长期做系列时可以让系统复制一份真实故事采集表。

## 公开前注意

- 只提供你有权使用的故事和素材；
- 不粘贴身份证号、手机号、住址、账号密码等敏感信息；
- 客户案例、咨询案例、未成年人、健康经历和家庭纠纷默认匿名；
- 逐字稿只能证明“某人说过什么”，不能自动证明全部内容为客观事实；
- 真实姓名、企业名和可识别细节只有在确认拥有公开权限后再保留；
- “提示词完成”不等于“已经生成图片或成片”，生成后仍要复核人物一致性、字幕、口型、声音和隐私。
