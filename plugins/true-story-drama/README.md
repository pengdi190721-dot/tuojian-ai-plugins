# 真实故事短剧化

**把平平无奇的真实故事，改成大众爱看的短剧；再把剧本变成能直接贴进LibTV的图片和视频提示词。**

版本：1.0.0 · 作者：彭迪 · 技能标识：true-story-drama

[公开仓库](https://github.com/pengdi190721-dot/tuojian-ai-plugins) · [查看完整技能](skills/true-story-drama/SKILL.md)

## 这是干什么的

很多人手里都有一个想讲的故事：自己创业时的一个晚上、爸妈的一件往事、一个老员工、一个难忘的客户。可一讲出来就是“流水账”，自己都觉得没意思。

问题不在故事不够大，在讲法。真实故事短剧化做的事情就一件：**不改事实，只改讲法**，把它改成一个陌生人刷到了会停下来、看完了会有感觉的短剧。剧本定了，再出人物、场景、每段第一帧的图片提示词，和按秒分段的视频提示词，你拿去LibTV里直接生成。

## 适合什么故事

- 本人的亲身经历；
- 家人、朋友的往事；
- 员工故事、客户案例、创业经历；
- 采访录音、采访逐字稿，或者几样混着来。

从零原创、没有原始故事的群像短剧，用同一个市场里的“AI短剧导演台”。

## 一共七步，每一步都等你点头

| 步骤 | 你会拿到什么 | 什么时候往下走 |
|---|---|---|
| 1 读故事 | 我理解的故事大意、两三个主题候选、推荐哪个 | 你确认大意，选好主题 |
| 2 事实底稿 | 哪些不能改、哪些是感受、哪些是听说的、哪些可以补、谁要化名 | 你逐条删改，回一句“事实底稿确认” |
| 3 找戏 | 这个故事为什么平（最要命的两三条），三个不同的改编方向，推荐一个 | 你选一个方向 |
| 4 写剧本 | 人物小传、完整剧本、改编台账、剧本体检结果 | 你确认剧本 |
| 5 图片提示词 | 人物定妆图（三视图）、场景图（空景）、定帧图（每段视频的第一帧） | 你生成图片，发回来确认 |
| 6 视频提示词 | 按段落、按秒写好的LibTV提示词，每段不超过15秒 | 按实际成图定稿 |
| 7 自查 | 事实、戏、大众、台词、可拍、提示词六项检查结论 | 能交才交 |

已经做过的步骤直接接着来，不用每次从头走。只想要其中一步也行。嫌问得多，可以说“按推荐的直接写”，但结局、主人公亲手做的关键选择、谁对谁错这三样，一定会先跟你确认，这三样错了，片子就是在造谣。

## 剧本靠什么抓人

- **从最要命的那一刻开场。**不从“我出生在……”讲起。前3秒出事，10秒内观众知道主人公想要什么；
- **先想清楚观众得到什么情绪。**扬眉吐气、被看见、心疼、暖、熬出头、原来如此、遗憾与和解，每个方案先说清楚主打哪一种；
- **没有坏人也有戏。**真事里大多没有坏人。戏从时间不够、钱不够、规矩卡着、两个人都有道理、心里那道坎里来，不靠编反派；
- **人在现场演，不靠旁白讲。**先写纯动作和对白，最后才补旁白，每句旁白都要过“删掉还看不看得懂”这一关；
- **台词像人说的话。**一句一般不超过二十个字，删掉书面腔、总结腔和连着的金句；
- **一个能截图转发的瞬间。**每集设计一个观众会想转给别人看的画面；
- **结尾不讲道理。**让前面出现过的一个物件、一句话、一个动作，在结尾换了意思。

技能里带了一个完整的示范：一个刻字师傅连夜重刻一块奖牌的故事，原来是五句话的流水账，怎么一步步改成一集75秒的短剧，图片和视频提示词怎么写。

## 图片和视频提示词长什么样

**每张图、每段视频都分两步交给你：**

1. 参考素材及用途：要连哪几张图、每张管什么、不照搬什么。上传、连线、存主体库这些操作说明都在这一步；
2. 能整段复制的提示词：只放给模型看的内容，放在一个文本块里，复制就能用。

**图片按顺序出三类：**人物定妆图锁住人长什么样（横版16:9三视图），场景图锁住地方长什么样（不放人的空景），定帧图把人放进场景，作为每段视频的第一帧。

**视频提示词按LibTV里Seedance 2.0全能参考的写法：**总设定、参考图分工、人物外形、按秒分段（每段写景别、机位、镜头怎么动、动作、看得见的情绪、台词）、声音、结束状态、禁止项。默认不让模型生成字幕和背景音乐，这两样后期加更稳。

同一个人物的外形描述，在所有图片和视频提示词里一字不改，人才不会越拍越不像。

## 两个检查脚本

脚本只查量得准的东西，不假装能判断好不好看：

- **剧本体检**：台词单句长度、旁白占比、动作描写长度、套话词、有台词的人数、地点数、场次，按语速估算时长；
- **提示词校验**：时间段是不是从0开始、连续、不重叠、结束在总时长；单段有没有超过15秒；提到的图几有没有交代；同一个人物的外形描述是不是每段都一样。

## 安装

### Codex

在电脑终端依次运行：

```bash
codex plugin marketplace add pengdi190721-dot/tuojian-ai-plugins
codex plugin add true-story-drama@tuojian-ai
```

已经添加过这个市场的，先运行 `codex plugin marketplace upgrade tuojian-ai` 再安装。装好后新建任务，看不到技能就重启一下。

### WorkBuddy

在WorkBuddy的对话或命令输入框中运行（不是电脑终端）：

```text
/plugin marketplace add pengdi190721-dot/tuojian-ai-plugins
/plugin install true-story-drama@tuojian-ai
```

## 第一次用，复制这句

```text
请用真实故事短剧化。我接下来发一个想讲的真实故事，你先只给我故事大意和主题候选，等我确认后再往下走。
```

常用的几句：

```text
主题确认了，按第二个来。请整理事实底稿，等我删改。
```

```text
事实底稿确认。告诉我这个故事为什么平，给我三个改编方向，推荐一个。
```

```text
按推荐的方向写完整剧本，竖屏，75秒左右。
```

```text
剧本确认。出人物定妆图、场景图和定帧图的提示词，再出LibTV的视频提示词草案。
```


## 从旧版升级

1.0.0是重写版。原来的事实确认、改编台账、旁白删除测试都保留了，又加上了“为什么平”的诊断、大众情绪回报、统一标准，图片和视频提示词改成了LibTV的写法。

技能标识没变，还是 `true-story-drama`。按上面的步骤再装一次就是升级，新版直接替换旧版，不会装出两个。项目目录里的旧稿还在原处，接着做的时候会先读旧文件，缺的补上，旧的不删。

## 版本规则

版本号三位数，从1.0.0起：

- 大更新，流程或产出变了，升第一位：1.0.0 → 2.0.0；
- 中等更新，加了新能力、新模板，升第二位：2.0.0 → 2.1.0；
- 小更新，修错、调说法，升第三位：2.1.0 → 2.1.1。

前面一位升了，后面的归零。

## 几点说明

- 只出文字和提示词，不会自动生成图片、视频、配音，也不会替你发布；
- 想用本人或家人的真实长相做参考，要当事人同意，并在LibTV里先做真人素材的合规校验；
- 普通人默认化名，单位、城市、能认出人的细节都会模糊处理；
- 不承诺播放量。能保证的是：讲法更抓人，事实没被偷换；
- LibTV界面更新很快，按钮名字和参数上限以你当天看到的为准。
