# 真实故事短剧化｜学员使用说明

版本：0.1.0

“真实故事短剧化”把本人经历、客户案例、人物访谈、事件复盘和口述素材，改成有目标、有阻力、有选择代价、有观看回报的中文AI短剧脚本。

它不会为了“有戏”凭空制造坏人、出轨、犯罪、疾病、债务或幕后秘密。所有压缩、调序、人物合并和对白重构都会进入改编台账。

## 安装后会获得什么

- 事实底稿：区分已核实事实、个人记忆、转述争议和创作空白；
- 三个戏剧化方向：从现实压力、关系压力和内在压力中寻找不同机制；
- 完整可拍脚本：动作、对白、声音、画面文字和连续性；
- 角色一致性卡、逐镜分镜和AI视频提示词；
- 原故事与改编内容对照台账；
- 事实、隐私、名誉、因果、可拍性和AI生成连续性审查。

本插件交付的是“可编辑待确认”的文本方案，不会自动生成图片、视频、配音或发布内容。

## Codex学员安装

打开终端，依次运行：

```bash
codex plugin marketplace add pengdi190721-dot/tuojian-ai-plugins
codex plugin add true-story-drama@tuojian-ai
```

安装后重启ChatGPT桌面端，新建任务，复制首次使用口令：

```text
请使用真实故事短剧化。我接下来会提供一段真实经历，请先守住事实边界，再给我三个戏剧化方向，并直接完成你最推荐的一版，包括完整剧本、逐镜分镜、AI视频提示词和改编台账。
```

检查是否安装成功：

```bash
codex plugin list
```

列表中应出现 `true-story-drama@tuojian-ai`。

## WorkBuddy学员安装

下面两条指令要在WorkBuddy的对话或命令输入框中运行：

```text
/plugin marketplace add pengdi190721-dot/tuojian-ai-plugins
/plugin install true-story-drama@tuojian-ai
```

安装后新建对话，复制上面的首次使用口令。也可以输入 `/plugin`，查看并安装“真实故事短剧化”。

## 最简单的用法

```text
把这个真实故事短剧化。默认做成60—90秒竖屏单集，中等戏剧化，人物和公司匿名。不要硬造反转，冲突必须来自真实目标、阻力、选择和代价。

真实故事：
【把原始故事粘贴在这里】
```

## 三个常用口令

### 1. 一次完成完整稿

```text
把这个真实故事短剧化。先判断原故事为什么平，再给三个机制不同的方向，直接完成推荐版。输出事实底稿、完整剧本、逐镜分镜、AI视频提示词、改编台账和审查结论。
```

### 2. 改成系列

```text
把这个真实故事开发成系列短剧。不要先定集数，先按真实材料能支撑的选择、代价和状态变化判断适合几集；每集都要先给局部回报，再留下精确余波。
```

### 3. 审查已有剧本

```text
审查这份真实故事短剧脚本。重点检查是否偷换事实、硬造反转、暴露真实身份、把重构对白当原话，以及分镜和AI提示词是否新增了剧本没有的内容。
```

## 建议提供的信息

故事不需要提前写得漂亮，但最好说明：

- 哪些是绝对不能改的事实；
- 哪些人物必须匿名；
- 是否允许压缩时间、合并场景和重构对白；
- 目标平台、时长和画面形式；
- 不能出现的内容。

插件内置 `story-intake-template.md`，需要长期做系列时可以让系统复制一份真实故事采集表。

## 公开前注意

- 只提供你有权使用的故事和素材；
- 不粘贴身份证号、手机号、住址、账号密码等敏感信息；
- 客户案例、咨询案例、未成年人、健康经历和家庭纠纷默认匿名；
- 真实姓名、企业名和可识别细节只有在确认拥有公开权限后再保留；
- “剧本完成”不等于“已经生成成片”，生成后仍要复核人物一致性、字幕、口型、声音和隐私。
